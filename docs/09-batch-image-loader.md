# 09 · 批量图片加载节点

`Feng · 批量图片加载`（分类 `Feng/图像`）：把多张图片攒在面板里，按面板顺序输出成 IMAGE 批次，
同时提供 `图像1..图像10` 独立输出口、遮罩、数量和文件名。第一张还可以用内置画笔涂遮罩；
遮罩口只有一个，固定取第一张，其他图片不参与遮罩。

## 1. 界面

```
┌─ Feng · 批量图片加载 ─────────────────────────────────┐
│ [＋ 上传图片] [📁 选择已有] [全选] [反选] [清空] 已选 2/3 │
│ 把图片拖到这里，或点「＋ 上传图片」…                    │
│ ┌────────┐┌────────┐┌────────┐                        │
│ │①◐ ◀▶✕ ││② ◀▶✕  ││③ ◀▶✕  │  ← ① 才有遮罩按钮 ◐     │
│ │  1:1 图 ││  1:1 图 ││  1:1 图 │                        │
│ │ 文件名  ││ 文件名  ││ 文件名  │                        │
│ └────────┘└────────┘└────────┘                        │
└───────────────────────────────────────────────────────┘
```

| 操作 | 说明 |
| --- | --- |
| **拖拽上传** | 把图片文件拖到面板上，松开即上传（可多张） |
| **＋ 上传图片** | 文件选择框，支持多选 |
| **📁 选择已有** | 从 ComfyUI 的 `input` / `output` 里挑已有图片：可切换 input/output、点 📁 进子目录、⬆ 上级返回，每层只列当前目录，可多选；缩略图走 WEBP（320px） |
| **🔍 放大预览** | 鼠标移到缩略图右下角的放大镜上，停 0.12 秒弹出 768px 的 WEBP 大图，移开即消失；预览层不挡点击 |
| **🗑 删除** | 窗口右上角切换删除模式，每张图右上角出现 ✕；点 ✕ 把文件移到 ComfyUI 根目录的 `delltemp`（与 `input` / `output` 同级），保留原目录和文件名，同名自动加 `_1`、`_2`，可手动移回 |
| **点击缩略图** | 单选；再点一次取消 |
| **Shift + 点击** | 多选增删 |
| **全选 / 反选 / 清空** | 批量操作（清空不删文件） |
| **① 上的 ◐** | 给第一张图画遮罩（内置画笔，白 = 遮罩区域） |
| **⇄ 替换** | 缩略图右上角，打开「选择已有」窗口（单选，点一张就换），**原地替换**该格、清空其遮罩 |
| **拖拽缩略图** | 拖到另一格上即插入到该位置，输出顺序跟着变 |
| **◀ ▶ / ✕** | 微调顺序 / 移除 |

缩略图上：**尺寸贴在右下角**（如 `2974 × 1440`），**文件名单行显示**（超长省略），一眼能看出哪些图尺寸不一致。
网格 3 列，图片多了在面板内滚动，节点高度可手动拉伸。

## 2. 输出（共 14 个）

| # | 端口 | 类型 | 说明 |
| --- | --- | --- | --- |
| 1 | `图像组` | IMAGE | 批次 `[B,H,W,3]`，顺序 = 面板顺序 |
| 2 | `次数` | INT | 已选张数 |
| 3 | `文件名` | STRING | 按顺序换行拼接，带 `input:` / `output:` 前缀 |
| 4 | `遮罩` | MASK | 单张 `[1,H,W]`；只取第一张（画笔优先，其次 alpha），没有就全 0。不是批次，其他图片不参与 |
| 5–14 | `图像1..图像10` | IMAGE | 单图口，行为受「单张接口」开关控制 |

> `遮罩` 特意放在 `图像1` 正上方，方便和「图像1」配对连线。
> 它只对应 `图像1`：无论选了几张，这个口都只输出一个遮罩 `[1,H,W]`；其他图片既不读取 mask，也不会产生遮罩输出。
> 原先单独的 `mask1` 和 `输出图片` 都已去掉：前者和 `遮罩` 重复，后者由「图像1」兼任。
> **一张图只进一个口**：第 N 张固定从 `图像N` 输出。选的张数少于 10 时，多出来的口输出 None（没有图可给），
> 不会重复最后一张。所以只连自己真正需要的口；把线连到空口上，下游会因为拿到 None 而跳过执行。

### 「单张接口」开关（默认开）

| 状态 | `图像1..图像10` 的输出 |
| --- | --- |
| 开（默认） | 严格一一对应：第 N 张 → `图像N`，共 N 个口有输出，其余口为 None；「统一尺寸」开时是缩放后的图，关时是各图原图 |
| 关 | **`图像1` 输出图片列表** `[张量1, 张量2, …]`；`图像2..图像10` 不输出内容（None） |

`图像组` 永远是张量批次，`图像1` 在关闭时提供**列表**形式——两者互补。

**列表元素的形状是 `[H, W, 3]`（不含批维）**，这一点很关键：核心 `PreviewImage.save_images`
会先迭代列表、再把每个元素当"一张图"处理，所以去掉批维后它正好能逐张转成 PIL。
如果列表里放 `[1,H,W,3]`，迭代出来就是 4 维数组，会直接崩在
`Image.fromarray`（`Cannot handle this data type: (1,1,W,3)`）。

所以：

- `图像1`（关闭单张接口）→ 可以接 `PreviewImage` 逐张预览，也能接自己的列表型消费者
- 需要"能直接进模型"的标准批次 → 用 `图像组`

两个开关：

- **统一尺寸**（默认开）：
  - 开 = 所有图**等比缩放 + 居中补边**到第一张尺寸（不裁切，RGB 补黑 / RGBA 补透明），单图口也统一尺寸；
  - 关 = **各图保持原始尺寸**：单图口 `图像1..图像10` 输出原图、完全不缩放；批次口只在尺寸全同时直拼，
    尺寸不同时仅把原图居中放到**最大画布**上（只补边，不缩放）。
- **用 Alpha 作遮罩**（默认开）：只对**第一张**生效（有画笔遮罩时画笔优先，否则用它的 alpha）；
  其余图片不参与遮罩——遮罩口始终只有一个 `[1,H,W]`，不会按张数变长。

> 硬限制：ComfyUI 的 IMAGE 批次是同尺寸张量，混尺寸没法直接拼。所以「关闭统一尺寸 + 尺寸各不相同」时，
> 批次口只能靠留白对齐；要拿到**真正的原始尺寸**请用单图口 `图像1..图像10`。

## 3. 遮罩画笔

点第一张图上的 **◐** 打开画笔：

- 笔刷大小可调，画笔 / 橡皮切换，「清除」清空；
- 画完点「保存遮罩」，会导出一张黑白 PNG 上传到 `input/`，文件名记在列表条目里；
- 遮罩只作用于**第一张**（后端只读第一条记录的 `mask`）；
- 文件记录在面板 JSON 里：`{"name": "...", "mask": "feng_mask_123.png", ...}`。

尺寸对齐：画笔导出的遮罩和原图同比例，后端会把它缩放到批次的目标尺寸。

## 4. 想拿「单张」

三种方式：

1. 直接用 `图像1..图像10` 独立口；
2. 用 `图像组` 批次 + 核心 `ImageFromBatch`（`batch_index` 从 0 开始）；
3. 只选一张再输出。

> 为什么不做成"数量可变"的输出口：ComfyUI 0.42.3 的 `io.DynamicOutput` 还只是占位抽象，
> 端口数量在节点注册时定死。所以固定 10 个 + 批次是当前最优解。

## 5. 实现要点

- **上传**复用核心 `POST /upload/image`；缩略图 / 放大预览走新增的 `GET /feng_images/preview`
  （参数 `source` / `subfolder` / `name` / `max`，服务端按需转 WEBP，quality 80；缩略图 `max=320`，放大 `max=768`）。
  转码结果按「路径 + mtime + 大小 + 尺寸」缓存 64 条，并带 `Cache-Control: private, max-age=86400`；
  转码放在独立线程池（最多 4 个并发），JPEG 先用 `draft` 降采样解码，不阻塞 ComfyUI 的事件循环；
  WEBP 失败时前端自动回退 `GET /view` 原图。列表接口同时返回 `mtime_ns`，前端拼进预览 URL 让旧缓存失效。
- **列目录**新增接口 `GET /feng_images/list?source=input|output&subfolder=<相对路径>`：
  **只列当前这一层**——返回 `files`（图片，按修改时间倒序）和 `folders`（子目录名），
  前端用「⬆ 上级 + 📁 子目录」逐层浏览，避免一次把整棵树铺出来导致卡顿。
  非法 source、越界 subfolder、不存在的目录都返回 400。
- **删除**新增 `POST /feng_images/delete`（JSON：`name` / `subfolder` / `type`）：
  只接受 `IMAGE_EXTENSIONS` 里的图片；`_deletion_path()` 把文件映射到
  `delltemp/<input|output>/<原子目录>/<原文件名>`（并校验源路径仍在 input/output 内），
  `_unique_destination()` 遇到同名加 `_1`、`_2`，最后 `shutil.move` 原文件（移动不是复制），返回 `moved_to` 供前端提示。
  `delltemp` 与 `input` / `output` 同级，ComfyUI 不会扫描它。
- **路径安全**：所有文件名都经 `_resolve_file()` 解析，用 `os.path.commonpath` 做目录包含校验，
  越界直接报错；不接受绝对路径。
- **状态**存隐藏控件 `images` 的 JSON，随工作流保存。
- **缓存**：`fingerprint_inputs` 带每个文件的 mtime、大小，以及第一张的遮罩名；重传、换遮罩都会重跑。
- 空列表直接报错，不会静默出空批次。

## 6. 已知限制

- 清空列表不删 `input/` 文件；画笔遮罩会累积在 `input/` 里，需手动清理。
- **删除是移动不是复制**：文件被移到 `delltemp/<input|output>/...`，不在 `input` / `output` 里，
  ComfyUI 的图片列表和 `/view` 都看不到；要找回，按删除提示里的 `moved_to` 路径手动移回原目录。
- 列表上限 200 张（防工作流 JSON 过大）。
- 上传逐张进行（不并发），一次拖太多会逐张提示。
- 尺寸统一以**第一张**为基准，先放进去的那张决定输出分辨率。
- 遮罩只能画第一张；其他图片没有遮罩。需要给别的图加遮罩时，用单独的遮罩编辑节点处理。

## 7. 验证情况

后端断言覆盖：条目解析、14 个输出口顺序、批次顺序、input/output 混用、画笔遮罩覆盖、
尺寸不一致不报错（补边 / 留白两种模式）、列表输出可混合尺寸、遮罩固定单张 `[1,H,W]` 且只取第一张（其他条目的 mask 被忽略）、空列表报错、越界路径拒绝、列目录接口（200 / 400 / 不含目录项）、删除路径保留来源与子目录、越界源路径拒绝、同名文件自动加序号。

前端只做静态检查（`tools/check_js.py`）；**拖拽上传、画笔、目录选择器、WEBP 放大预览与删除模式需在浏览器里人工确认**（本机没有 torch / PIL / aiohttp，`/feng_images/preview` 的转码只能静态检查）。
