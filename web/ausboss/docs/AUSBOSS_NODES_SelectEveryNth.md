# 每隔 N 帧选取 🆎

在一个 `IMAGE` 批次里每隔 n 帧保留一帧 —— 在昂贵的阶段之前把视频的帧数减半，
或者把一长串扫描抽成样本。

## 控件

- **images**：要抽稀的 BHWC 批次。
- **每 N 帧**（`nth`，起始为 `2`）：每 `nth` 帧保留一帧。`2` 保留隔一帧，
  `1` 全部保留（单独配合**偏移**用，可以丢掉开头几帧）。
- **偏移**（`offset`，起始为 `0`）：第一帧保留之前跳过的帧数。`nth` 为 2 时，
  偏移 `0` 保留第 1、3、5 帧，偏移 `1` 保留第 2、4、6 帧
  （从 1 开始数，和本包其他地方数帧的方式一致）。
- **fps**（可选插槽）：批次的帧率，例如 加载视频 🆎 的 `fps` 输出。

## 输出

- **images**：保留下来的帧，顺序不变。
- **fps**：接入的帧率除以 `nth`，所以保留的帧仍然覆盖同样的时间；没有接 fps
  时为 `0`。

偏移等于或超过批次末尾时，节点会用批次的尺寸停下，而不是返回一个空批次 ——
下游任何节点都用不了空批次。
