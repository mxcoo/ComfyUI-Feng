# 图像尺寸

读取图像的尺寸，以 INT 形式给出：**宽度**、**高度**、**最长边**、**最短边**和**数量**。

把它们接到工作流里那些必须与实际图像一致的数值上 —— 按源图尺寸设定的空 Latent、
以最长边为准的缩放、按最短边做的考虑比例的计算。因为这些数值来自连线，
永远不会像手填的数字那样过期。

运行后，节点会在每个输出旁显示对应的数值，例如 `width: 1024`，
不接任何线也能读到尺寸。

## 输出

- **宽度** / **高度**：以像素为单位的帧尺寸。
- **最长边**：`max(width, height)` —— 缩放以适配的逻辑所依据的数值。
- **最短边**：`min(width, height)` —— 裁剪填满和许多预处理流程所依据的数值。
- **数量**：批次中图像的数量 —— 单张图为 `1`，视频帧为帧数。

## 说明

批次报告的是各帧共有的尺寸（IMAGE 批次按构造就是统一的）。节点不做值得缓存或取消的工作
—— 它只是从张量的形状读出数值。

输出旁的数值来自上一次运行。它们随工作流一起保存，所以重新打开工作流时还在；
接入另一张图时会被清除。如果节点在一次运行中量的是多个批次的列表，它不显示数值，
因为没有任何一个数值对全部批次都成立。
