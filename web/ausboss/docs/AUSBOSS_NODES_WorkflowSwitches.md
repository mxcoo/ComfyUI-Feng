# 工作流开关 🆎

用一张小卡片把工作流的各部分打开、关掉。每一行是一个带名字的开关。**off** 跳过那部分，**on** 让它重新运行。

工作流会做出不止一个结果、而你不总是全要时用它；或者一个很长的工作流里有你偶尔想跳过的步骤，比如最后那步放大。

## 做一个开关

1. 在画布上选中某一部分的节点。例如一个框（子图）和它的保存图像。
2. 点卡片上的 **+ Switch from 2 selected**。
3. 输入一个名字并按回车。

点 **off** 就跳过你选的所有节点，点 **on** 就让它们重新运行。点已选中的那一半会保持选中。

组也可以。画布上每个组都会有自己的开关，除非你在 **Settings** 里改掉。一个组也可以成为你做的某个开关的一部分：把它和节点一起选中。

## 在保存好的设置之间挑

同一个节点该按几种方式之一来设、而你想按名字挑的时候用它：8 步还是 20 步，或者跑哪条分支。

1. 把节点按第一个选择该有的样子设好，并选中它。
2. 点 **+ Choice**，输入名字并按回车。
3. 把节点按第二种方式设好，再点 **+ Choice**。这次不用选中它。

卡片现在成了一个带你的选项的药丸。点一个，节点就回到你保存它的样子。只改动你各选项之间不同的设置，其余保持你的。第三个照同样方式加。

要跑两条分支中的一条，把两条都接到 ComfyUI 的 **If/Else Switch**（它们会合的地方），做一个选择，让它的开关为 true 和 false 各一次。只有你挑的分支会跑。两条分支的末尾必须是同一类型。

缺失的模型或图片会停掉运行，哪怕在你没挑的那条分支里，因为 ComfyUI 会检查每个处于开启状态的节点。要避开这点，只选中某一个选择需要的节点，打开该选择的三点菜单，选 **The selected run only with this choice**。挑中别的选择时它们会关掉。每条分支都做一遍，两条分支共用的节点不要选进去。

一张卡片要么装选择、要么装开关，所以在还没有开关的卡片上，选中节点后才会显示 **+ Choice**。两者都要，就用两张卡片。

以后要改某个选择，把节点设好，打开该选择的三点菜单，选 **Save how it is set now**。

## 改设置的开关

开关也可以改数值，而不是关掉节点。一次点击可以把 **Steps** 设为 8 并打开某个加速 LoRA 的那一行，下一次点击把两者都恢复。

1. 用那些设置该变化的节点做一个开关。
2. 把这些节点按开关为 **on** 时该有的样子设好。选中它们，打开开关的三点菜单，选 **Save the 2 selected as on**。
3. 把它们按 **off** 时该有的样子设好，再选中，选 **Save the 2 selected as off**。

开关现在只改两者之间不同的数值。这些节点不再被它关掉。

在 LoRA 加载器里，它按文件名找到单独的行，并且只改每一行是否开启。强度仍归你：把某行降到 0.6，无论开关怎么切它都留在 0.6。只有当你在 on 和 off 时给那一行存了不同强度，强度才会变。开关不改的行保留你给它的任何值。子图框上的 LoRA 行也一样（LoRA 加载器的齿轮，**Rows on the box**）：选中框本身，保存它的 on 和 off。

一个 LoRA 加载器组同理。组开着存一次开关，组关着再存一次，开关就开关整个组。组里每个 LoRA 保持自己的开关状态，所以你仍能手动漏掉一个；之后加进组里的 LoRA 也跟着它走。

被开关接管的 LoRA 行或组会在 LoRA 加载器里显示一把锁。点锁可以收回控制：这个开关此后就不碰它。

## 有两侧的开关

有时一个选择同时意味着"用这个"和"不要那个"。修图时，图决定尺寸，所以设尺寸的节点该歇着。做新图时，正好相反。

一个开关可以两头兼顾。给它一个 **off 侧**：只在**开关关闭时**运行的节点。假设开关叫 **Edit a picture**，它持有节点 *Your picture*，而 *Latent Size* 在它的 off 侧：

- **on**：*Your picture* 运行。*Latent Size* 被关掉，所以看起来像被绕过了。
- **off**：*Your picture* 被关掉。*Latent Size* 运行。

这样设置：

1. 用那些在它开启时该运行的节点做开关，这里是 *Your picture*。
2. 选中那些只在它关闭时才该运行的节点，这里是 *Latent Size*。
3. 打开开关的三点菜单，选 **The 1 selected runs only while this is off**。

标签旁边一个两个箭头的小标记表示这个开关有 off 侧。指着它可以看到是哪些节点。要把某个节点从这个侧拿下来，选中它并选 **Take the 1 selected off that side**。

## 只用一枚药丸来挑

有时卡片上的开关是若干选择，而同时只该用一个：按文字取遮罩还是按点击取遮罩，或者三个放大器中挑一个。卡片可以把它们显示成一枚药丸。每个开关是药丸的一部分，正在用的那个是实心的，点另一个就切过去。

1. 为每个选择做一个开关。
2. 打开 **Settings**，把 **One at a time** 设为 **on**。
3. 把 **Show as** 设为 **one pill**。

总有一个选择被挑中。点实心的那个没有反应，所以没人能把它们全关掉、也没人能同时开两个。

最多四个短名字并排显示。选择更多、或者名字太长时，卡片改为显示一个挑选列表。名字需要空间时卡片会变宽。

编辑视图里药丸在各行上方。你在药丸里挑，各行保留它们的取景按钮和三点菜单。按 **Done** 之后只剩药丸。要再编辑，右键节点并选 **Edit switches**。

工作流可以被保存成所有选择都关、或者同时开着好几个的状态。药丸就照实显示，边缘是琥珀色。点你想要的那个，其余被关掉。

## 小视图

按 **Done**，卡片缩成标签和它们的开关。这就是保存完成工作流时该用的视图。

要再改它，双击一个标签，或者右键节点并选 **Edit switches**。

## off 做了什么

- **bypass**（默认，紫色节点）：每个节点把输入直接传下去。把链条中间的一步关掉，画面仍会到达它之后的步骤。
- **mute**（灰色节点）：节点不运行，需要它们输出的东西也不运行。

在 **Settings → When off** 下二选一。

把一个部分的保存或预览放进与该部分同一个开关。保存关掉后，没有东西要那个结果，于是 ComfyUI 跳过这部分工作，也根本不会加载只有这部分需要的模型。

## 编辑视图

- **off | on**：点 **off** 关掉这一行的所有节点，点 **on** 让它们全部运行。点已选中的那一半保持选中。一次改动是一步撤销。
- **Mixed**：一行里只有部分节点在运行（比如有一个被手动绕过）时，药丸是斜纹的，并显示运行的数量，例如 **1/2**。点你想要的那一半，off 或 on，把它们统一设好。设置开关的某个值被手动改成了别的值时显示 **changed**，只保存了一侧时显示 **half set**。
- **取景按钮**（四个角）：把那部分带进视野。对有 off 侧的开关，它把两侧都带进视野。
- **三点菜单**（在你做的开关上）：
  - **Rename**。双击标签效果相同。
  - **Select its nodes** 在画布上显示这个开关都管些什么。
  - **Add the selected** 和 **Take out the selected** 改变它管的内容。先选中节点或组。
  - **The selected run only while this is off** 与 **Take the selected off that side** 给开关加 off 侧，见上文。
  - **Save the selected as on** 与 **Save the selected as off** 把它变成一个改设置的开关，见上文。
  - **Move up** 和 **Move down** 改变顺序。
  - **Delete this switch** 删掉这一行。节点保持原样。
- 右键节点可以 **Switch everything on** 和 **Switch everything off**。

## 设置

打开编辑视图底部的 **Settings**。

- **When off**：bypass 或 mute，见上文。
- **Groups**：哪些组各自有开关，列在你做的开关下面。**No groups**、**Every group**、**Numbered groups**（标题以数字开头，例如 *1 · Load*）或 **Titles matching…**，后者接受 **Match** 里的逗号分隔词。
- **Group order**：**canvas** 按工作流的读法来，从左一列一列地读，每列内从上到下。**title** 按标题排序，数字按数值顺序（*2 · …* 在 *10 · …* 之前）。
- **One at a time**：打开一行会关掉其他行。用于若干备选，比如两个放大器。在多行都开着时打开它，最上面那行保持开启。在另一行开着时新建的开关从关闭开始。
- **Show as**（One at a time 打开时才有）：**rows** 给每个开关一行，各自带 off | on。**one pill** 把它们显示成一枚可挑的药丸，见上文。

## 让 AI 智能体来设置

AI 智能体可以把开关写进工作流文件来替你加上。把它指向本包文件夹里的 `js/docs/agents/workflow_switches.md`。那一页告诉它该写什么。

## 技术细节

- **bypass 传过去的是什么。** 被绕过的节点或框，会把与输出同类的第一个输入传下去。对有两个画面输入的步骤，把该穿过去的那张图接到第一个上。没有这种输入的节点（解码器：Latent 进、画面出）什么都不传，所以读它的节点要放进同一个开关里。
- **开关按 id 找它的节点。** 被删掉的节点会从它的开关里消失。节点的副本不在开关里。卡片与它的节点和组一起复制时，开关的是那些副本，所以整个工作流粘到新标签页里，开关仍然好用。单独复制一张卡片，开关的还是原文件里的那些节点。
- **开关旁边的 "empty"** 表示它的节点都不在这个工作流里，所以没有东西可开。在 2.20.3 之前的版本上粘贴并保存的工作流会一直这样。重新打开原文件，或者在编辑视图里从开关的菜单添加节点。
- **同时在两个开关里的节点** 被任一开关改动。另一行随后显示 mixed。两个部分共用的节点不需要开关：ComfyUI 只运行结果需要的东西。
- **On 会把行里的一切都打开**，包括你手动绕过过的节点。
- 从不运行的节点，例如便签、工作流说明卡或运行计时器，会随它们所在的行切换，但从不使该行显示 mixed。
- 框作为整体切换，与 Ctrl+B 一样。它关着时里面什么都不运行。
- 当组的框包含节点的中心时，该节点属于这个组，这也是 ComfyUI 用来决定什么随组移动的规则。
- 卡片列出它所处那张图的各个部分。在框里，它列出那个框的节点和组。它从不切换自己或另一个工作流开关节点。
- **设置开关记住什么。** 保存一侧会按控件名存下所选节点的每个文本、数字和开关值。只会写入 on 与 off 之间不同的那些。超过 20,000 字符的值不保存。一个开关最多记住 40 个节点。
- **LoRA 行的强度。** 只有当保存的 on 与 off 给那一行不同强度时，开关才会设它的模型或 CLIP 强度。否则它只设该行是否开启，所以手动改过的强度永远不会让这一行显示 changed 或 partly on。该行的触发词永不被碰。
- **Switch everything on** 和 **off** 也会移动每个设置开关和每个 off 侧。
- **带 off 侧的开关怎么读。** 它自己的节点在运行、off 侧不在运行时是 on；反过来是 off；其余是 mixed。mixed 行上的计数，例如 **2/3**，计的是两侧的节点。
- **一个节点只在某一侧。** 把它放到一侧就会从另一侧拿走；保存的工作流若把它列在两侧，它留在 on 侧。你手动挑的节点留在你为它挑的那一侧，即使另一侧的某个组也包含它。两侧的组都包含它时，它留在 on 侧。
- **One at a time** 会关掉其他行，也就运行它们的 off 侧。一行在运行、另一行把它关掉的节点，最后仍在运行，而你打开的那一行有最终决定权。
- **一个选择存什么。** 一组保存的取值，没有 off 侧。选择只会改动它与同一卡片上另一选择不同的设置，所以某个控件上再加第三个值不需要额外做什么。挑一个只写它自己的值，它不持有的节点保持原样。选择也可以像开关那样持有节点：被挑中时它们运行，否则关闭。选择所设置的节点不能是其中之一，因为关掉它会把该选择撤销。手动设的值与任何选择都不匹配时，没有一个选择处于选中状态。带选择的卡片会保持 One at a time 开启、显示一枚药丸且不列组，所以它的 Settings 是隐藏的。
- **卡片自己安定下来的时机。** 打开 One at a time，或者在它开启时新建一个开关，如果不止一行开着，会留下一行。完全开启的行先于部分开启的行，然后是靠上的行。新建的开关让位给原有的行。改动 **Groups** 或 **Match** 新增的行保持原样，因为输进 Match 的词不该让节点停掉。点一下某行就会让它们安定。
- **药丸还是列表。** 两到四行，且名字能放进不超过 400 px 宽的卡片时，就是药丸。行更多、或者名字更长，就是列表。只有一行时卡片保持行视图。卡片上列出的组也是选择，而没有节点的行不能被挑中。
- **点一个选择** 做的是 One at a time 的事：那一行打开，其他所有行关闭，包括它们的设置和 off 侧。只有部分开启的行显示斜纹，与行视图一致。
- **Switch everything off** 在卡片显示为一枚药丸时不放进右键菜单。
- **药丸作为又一项设置存储**：在节点的 `ausboss_workflow_switches` 属性里，`"show": "pill"` 与 `"exclusive": true` 并列。`"show": "rows"`，或者没有 `show`，就是行视图。所以本包旧版本保存的工作流会以行视图打开，旧版本也会忽略这项设置。
- **off 侧存在它所属节点的旁边**，即 `nodes_off` 与 `groups_off`，与 `nodes` 和 `groups` 并列。off 侧为空时会省略它们，所以没用它的工作流保存方式与以前相同。本包的旧版本会忽略 off 侧。
- 它存下每个开关持有的节点、它记住的取值和它的设置。某一行是否开启是从节点本身读出来的，所以保存的工作流重新打开时，显示的是真正开启的状态，不管当初是怎么切的。
- 它从不运行，也没有接线。它被排除在提示之外，所以不能改变结果，也不会拖慢运行。
- 一张卡片最多 40 个开关。
