# LaMa 局部重绘

抹掉你涂抹过的任何东西，例如水印或某个物体，并填补空缺，让它与周围的内容一致。它既能处理图片，也能处理视频，遮罩之外的一切保持原样。

它使用 LaMa 模型，只需下载一次（见下文）。视频帧逐帧处理，所以长片段不需要更多显存。

## 模型准备

下载 [`big-lama.pt`](https://github.com/Sanster/models/releases/download/add_big_lama/big-lama.pt) 并放到：

```text
ComfyUI/models/lama/big-lama.pt
```

节点从不下载模型。添加或替换 checkpoint 之后，刷新浏览器或重启 ComfyUI，模型列表才会更新。在文件就位之前，列表里仍会显示 `big-lama.pt`，运行会中止，并给出提示说明该把它放在哪里。

无论你把它命名成什么，节点只打开这个文件的已知副本：上面下载的那份，或来自 [fashn-ai/LaMa](https://huggingface.co/fashn-ai/LaMa) 的那份。LaMa 模型文件在打开时可以执行代码，所以任何其他文件都会让运行中止并给出提示，且绝不会被加载。

## 控件

- **image**：BHWC 图像或视频帧。
- **mask**：BHW 遮罩，白色表示要替换的内容。一个遮罩会广播到整个批次；否则请为每张图各提供一个遮罩。尺寸不同的遮罩会被拉伸以适配图片。没有涂抹任何遮罩的图片会让运行中止并提示 "No mask painted"，而不是原样返回。
- **Model**（`model`）：来自 `models/lama` 的 `big-lama.pt` 已知副本。

## 输出

- **image**：有限的 BHWC 图像批次，保留原来的批次大小、尺寸、数据类型、额外通道，以及未被遮罩的像素。

## 预览

面板显示局部重绘的结果，运行前则退回到接入 **image** 输入的任意内容的缩略图。视频局部重绘会把每帧完成的结果流式送到面板，所以长时运行能看到进度，而不是一直空着。节点上方的小徽标会统计帧数（"frame 3/120"）；**Settings → AusBoss → Chrome → Live status** 可以关掉这些徽标。运行结束时，面板保留第一帧。

预览界面只有一处：ComfyUI 为本节点自带的结果预览会让位，以免图片出现两次——一次在面板里，一次在节点下方。

节点不发起任何网络请求。每次运行都会往 ComfyUI 的临时文件夹写入一张预览 PNG，与 `PreviewImage` 写入的文件放在一起。

图片上方工具栏右侧的小 **preview** 开关可以关掉它：图片的框会消失，节点也相应变矮，且不写入预览文件。重新打开后节点恢复原来的高度，里面是上一次的结果；如果节点是在开关关闭时运行的，它会请你重新运行一次工作流。这个开关就是节点可选的 `preview` 输入。
