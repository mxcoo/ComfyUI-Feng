# 工作流说明卡 🆎

让分享出去的工作流自己说明自己的那张卡：一个大标题、一段 Markdown 使用说明、它需要的模型（带 **Download** 按钮和各自该放的文件夹）、它依赖的节点包，以及作者的链接。卡上的每个模型文件和节点包都会对着**本机**这套安装核对，标成已安装或缺失，所以打开工作流的人一眼就知道第一次运行之前还差什么。

它不执行任何东西：节点没有输出，ComfyUI 永远不会执行它。

## 编辑

- 点卡片角上的 **✎**（或右键节点 → *Edit Workflow Note*）。对话框带表单；**JSON** 切换到卡片原始文本，方便在工作流之间复制粘贴。`Ctrl+Enter` 保存，`Esc` 取消（你改过内容的话它会先问）。
- **Title / Subtitle / Author** 构成横幅。**Layout → Banner** 只显示顶部那一块（标题，加上你填了的副标题和作者），所以同一个节点也能当某个阶段或某一列的标签。
- **Layout → Info tile** 在画布上放一个按钮。点这个磁贴可以读到完整说明，包括模型和链接。书图标表示指南，下载箭头表示模型清单。点它的铅笔可以编辑，或者在打开的说明里按 **Edit**。拖动可见的右下抓手可以在不移动磁贴的情况下改尺寸。把焦点放到抓手上，用方向键做键盘缩放；**Shift** 让每次调整更小。
- **Accent color** 给横幅条、圆点和按钮上色；留空则用本包的主题青。取值是六位十六进制，例如 `#00b4aa`。
- **How-to** 是轻量 Markdown：`#`/`##`/`###` 标题、`**bold**`、`*italic*`、`` `code` ``、`[links](https://…)`、`-` 和 `1.` 列表、`---` 分隔线、围栏代码块。只有 `http(s)` 链接会变成可点击的。

## 编排使用说明

在 How-to 字段里选中一段文字，点 **Teal**、**Green**、**Amber** 或 **Glow**。点 **Table** 插入一个可编辑的 Markdown 表格。写的时候打开 **Preview formatting**。用标题把步骤分段，用管道表格写设置或文件位置。每一行的长度保持一致。单元格里要写字面竖线时用 `\|`。

```markdown
## Choose a size

| Size | When to use it |
| --- | --- |
| 480 × 864 | [teal]First run[/teal] |
| 576 × 1024 | A larger portrait |

[green]Ready[/green] means the model was found.
[amber]Missing[/amber] means you still need the file.
```

要一段短高亮，就写 `[glow]Preview the result[/glow]`。光晕是静态的。这四个标签是 AusBoss 对 Markdown 的扩展。它们给包住的纯文本上样式。标题、列表、表格单元格和段落里都能用。围栏代码块里显示原始字符。

## 模型

要让下载有自己的按钮，选择 **Layout → Info tile**，把标题设为 **Download models**，然后在 **Models** 下添加文件。想把它们和说明放在一起，就把同样的行加到 **How to use** 说明里。把已有的卡片切换成 info tile 会保留它的模型行和链接。

[下载 Krea 2 模型磁贴示例](https://raw.githubusercontent.com/ausboss/ComfyUI-AusBoss/main/js/docs/examples/model-download-tile.json)，并把它作为工作流打开。把磁贴复制进你的图，再改它的行。

每一行是一个文件、它该放的模型文件夹、可选的体积、一个下载 URL，以及一行可选的备注（以灰色显示在文件名下）。各行按 `📂 ComfyUI/models/<folder>` 这样的标题分组，让卡片读起来像安装目录树 —— "这个该放哪儿"的问题和按钮在同一行就有答案。

- 行旁的圆点是核对结果：**青色** 找到，**红色** 缺失，**灰色** 未核对（没设文件夹，或者本机没有这个文件夹）。
- 找到的文件会把 Download 按钮换成一枚 **✓ installed** 药丸；把鼠标停在药丸上会显示找到的位置。放在子文件夹里的文件同样算数。当工作流里的加载器仍然只要裸文件名、而 ComfyUI 在那儿找不到它（会把那个加载器标红）时，这一行会写明文件实际在哪（**in LTXV 2.3/**），**Use it** 会把那些加载器指向它找到的那份副本。核对只向 ComfyUI 服务器要它自己的模型列表。
- **↻ check files** 在你挪动文件之后重新核对。ComfyUI 自己的 **R** 刷新也会触发它。
- 文件夹 `input` 用于工作流附带的示例图片或片段：它会到 `ComfyUI/input` 里找。
- 点文件名会复制它 —— 搜索加载器的选择列表时很方便。

Download 按钮就是一个在新标签页打开文件页面或直链的普通链接；浏览器把它存到下载目录去，文件夹那一行写着该挪到哪。

## 节点包

一行写一个包、链到它，并写上该包里的一个**探测节点类**（它注册的任意节点，例如 `AUSBOSS_NODES_LoraLoader`）。如果这个类在本机注册了，该包显示 **✓ installed**；否则标为缺失，并给出获取它的链接。编辑器里的 **Detect from this workflow** 会为工作流用到的每个自定义包加一行，包含子图里的。它从不删除行，所以大改之后要检查清单。

## 链接

给你的页面做的小标签 —— GitHub、Civitai、YouTube、Discord —— 想让下载工作流的人找到什么就放什么。

## 说明与限制

- 卡片会长高以显示全部文字，节点也不能拖得比这更矮。它从不自己缩小，所以你拉高过的说明会保留那块空间。
- 卡片以 JSON 存在节点唯一的 `note` 控件里，所以保存/读取、撤销、复制粘贴和 API 格式都会带上它。从别的工作流粘过来的卡片也能完整到达。
- 下载来的卡片上每个字符串都是别人的文字：它按文本渲染，绝不按 HTML 渲染，只有 `http(s)` URL 会变成按钮或链接。
- 文件核对是拿 ComfyUI 的模型清单做查表，不是哈希：同名但不同版本的文件也会通过。
- 体积是作者填的；节点不会去取。
