# Latent 尺寸 🆎

按形状和百万像素挑一个画面尺寸，或者直接拖动来调。用它代替 Empty Latent 节点：它会给出宽、高，以及该尺寸的一张空白 Latent。

- **形状：** 左侧按钮选择横向或纵向。比例芯片跟随该选择；方形会把选择保留给下一次。点击芯片会用它在约一百万像素附近的生成尺寸。在齿轮里启用 **芯片保持当前预算** 可以保留当前面积。
- **画布：** 拖动一条边改变一个维度；拖动角同时缩放两个维度。Shift 解除角上的比例锁定，Alt 去掉吸附，Escape 取消拖动。明亮的读数显示尺寸、百万像素与比例；琥珀色圆点表示尺寸不在吸附网格上，手输的尺寸可能如此。方向键把聚焦的画布按吸附步长微移，按住 Shift 则为 8 px。
- **尺寸与预算：** 拖动或输入 W、H 或 MP。手输的维度会被精确保留。交换按钮互换两个维度。**尺寸** 芯片是当前比例下现成的尺寸，由小到大。当形状是比例芯片之一时显示它们；其他任何形状只显示一个灰掉的"自定义"芯片。
- **齿轮：** 设置 **吸附步长**、编辑 **比例栏**、选择 **Latent 系列**（`latent`）与 **批次大小**（`batch_size`），以及隐藏 **点阵** 或 **MP 开销曲线**。**吸附步长**（8、16、32 或 64；起始为 32）是拖动、方向键与芯片落点的网格。**比例栏** 是比例芯片的列表，按 `1:1, 21:9` 这样输入。显示选项作用于本浏览器里的每一个 Latent 尺寸节点；Latent 系列与批次大小（1 到 64）属于本节点。
- **节点尺寸：** 拖动节点的角可以让它更宽或更高，以便与周围的节点对齐。控件随之拉伸，画布预览占用多余的高度。最窄可以是 320 像素。

## 工作流分辨率

在齿轮里选择 **此工作流 → 工作流分辨率 → 编辑列表**。每行输入一个精确的宽 × 高，最多 24 个。该列表属于本节点，随保存的工作流一起走。列表为空时编辑器保持原样。

- **推荐用法：** 关闭 **把可选择项限制在此列表**。尺寸 行显示你的快捷选项，用户仍然可以手输、拖动或选择其他形状。
- **严格模型尺寸：** 打开限制。形状 行只显示列表里存在的精确比例。选一个比例查看它允许的尺寸。例如 576×1024 与 720×1280 同属 9:16；480×864 是单独的 5:9 选项。只有列出横向尺寸时横向才可选。画布仍然可见，但不能拉伸。交换按钮只在列表里恰好有反向尺寸时生效。
- 打开限制时，未接线的尺寸若被允许就保持选中；否则选中列表里的第一个尺寸。接线的宽或高会在运行前、分配 Latent 之前检查。不受支持的组合会报错并列出允许的尺寸。视频工作流请把这些宽高输出接到视频 Latent 节点。

## 输出与连线

输出依次是 **width**、**height** 和 **latent**。节点在面板上方有四个输入插槽：width、height、latent 和 batch_size。接入 width 或 height 会锁住那些会同时改变两个维度的控件；另一个维度仍可编辑。接入 latent 或 batch_size 则从另一个节点取出 Latent 系列或批次大小，齿轮里随即将该设置显示为已接线。接线的取值在工作流运行时读取，所以预览仍然显示存在节点上的尺寸。

**Latent 系列** 是 **16ch**（8× 下采样）、**4ch**（8×）或 **128ch**（16×）。16ch（默认）用于 SD3、Flux 1、Krea 2、Qwen Image 与 Z-Image。4ch 用于 SD 1.5 与 SDXL。128ch 用于 Flux 2 Klein。以不同方式打包像素的模型，例如 Qwen Image 2.1，仍然得到你设定的尺寸：ComfyUI 会把空白 Latent 缩放去适配它。这是一个空白的*图像* Latent；视频模型应当取 width 与 height 输出，自行构建自己的音频/视频 Latent。

手输的尺寸不必能被 Latent 下采样倍数整除。整数输出保留手输的尺寸，而 Latent 的空间维度向下取整到完整单元，与核心的空白 Latent 节点一致。直接把 Latent 接线时请使用已对齐的维度。大尺寸与大批次会分配相应更大的张量。

## 限制

维度范围是 64 到 8192 像素。极端的自定义比例在所选吸附下可能在该范围内没有精确解；它们会使用有界近似。细微的自定义比例在吸附拖动时同样只能近似该比例。较长的自定义比例列表会在形状区域内滚动。

所有执行输入都是普通控件，所以 API 运行不依赖这个面板。方向与吸附偏好随节点保存。本节点没有模型下载、没有网络请求，也没有额外的 pip 依赖。
