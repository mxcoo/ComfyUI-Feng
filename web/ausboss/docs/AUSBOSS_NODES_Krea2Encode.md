# Krea 2 编码 🆎

Krea 2 的提示词节点。在这里输入提示词与负面提示词，并可选给它一张
结果要跟随的图片，全都在一个节点里。

接上 VAE 和一张参考图，参考就被附到正向输出上。两者都不接，它就是
一个普通的双提示词编码器。负面从同一个节点出来，所以以 CFG 1.0 运行
的 turbo 图仍有东西可接，而不必让第二个文本编码干坐在那里什么都不做。

用 AnyPaint LoRA 做扩图时，还要把给你图片扩边的那个节点的 **mask**
接上。没有它，深色或色彩强烈的图片回来时新区域可能仍是灰色，像一圈
灰边或一个灰角。

## 控件

- **clip**：Krea 2 文本编码器。
- 大文本框（`prompt`）：描述整张成品画布，而不只是新区域——模型生成
  全部内容，并在必须的地方与参考对齐。两个框没有标签，只有灰色的
  提示文字。
- 小文本框（`negative_prompt`）：在 CFG 1.0 下被忽略，而 turbo 正是
  跑在那里。在那里空着是常态。
- **vae**：把参考图变成 Latent 需要它。没有它，结果上不会附任何参考。
  如果 **VLM reference** 打开，文本编码器仍会看那些图片。
- **reference**：结果所跟随的图片。对 AnyPaint 来说，是
  图像裁剪 + 旋转 + 扩边 🆎 或 加载图像 + 扩边 🆎 输出的扩边后
  `image`；对 Registered Outpaint，则是 加载图像 + 扩边 🆎 未扩边的
  `reference` 输出。任何图片都可以；它会先被缩放到 16 的倍数。
- **extra_image**：第二张参考，例如风格图或角色板。
- **VLM reference**（`vlm_reference`，默认关闭）：也把参考展示给视觉
  塔，让文本编码器描述它们。AnyPaint 用扩边画布作参考时打开；
  Registered Outpaint 用未扩边的源图时关闭，因为那里的描述往往把结果
  拉向对源图的复述。Krea 2 扩图模型补丁 页面涵盖了两种配置。
- **mask**：要绘制的区域：图像裁剪 + 旋转 + 扩边 🆎 或
  加载图像 + 扩边 🆎 的 `mask` 输出，或某次局部重绘涂抹的遮罩。
  AnyPaint 要接上它。参考随后以你图片自身的颜色显示该区域，而不是
  灰色填充，模型就在那里作画。

## 输出

- **positive**：附有参考 Latent 的提示词条件。
- **negative**：负面提示词条件。

## 说明与限制

- **参考被缩小到长边 384px 并对齐到 16 的倍数。** VAE 下采样 8 倍，
  DiT 再分块 2 倍，所以一条不在 16 倍数上的边会落到不完整的分块上，
  token 网格就不再与画布网格对齐。这个上限是有意为之——参考的作用是
  说"就是这张图"，细节由画布 Latent 承载。
- 只附上参考 Latent 并不能告诉模型它们*放在哪里*。做扩图时把它与
  Krea 2 扩图模型补丁 🆎 搭配使用。
- 在没有 Krea 2 提示词模板的核心上，`vlm_reference` 仍然有效——它会
  退回到不带模板的分词。

## 技术细节：遮罩为什么重要

AnyPaint 训练时，其参考的新区域填的是画面其余部分的中位色，从不是
固定的灰色。扩边画布带的却是一块平的 `#808080` 灰。对中位色接近中灰
的图片来说这没有差别，但对深色或高饱和的图片，模型会把这块灰读成
场景的一部分并把它画回去，作为一个平的灰边或灰角。遮罩的新区域
（大于 0.5 的地方）在参考送入 VAE 与视觉塔之前，会用其余一切的中位色
重新填充。图里其余部分使用的画布保留它的灰，所以提示词撰写器和拼接
都不变。只有 `reference` 被重填；`extra_image` 保持原样。
