# 整数 🆎

一个整数。把步数、尺寸或任何别的整数设一次，接到每个需要它的节点上。

## 控件

- **数值**（`value`）：要送出去的整数。起始为 `0`。箭头或拖动每次移动 1，
  也可以点击后直接输入。它能放得下和种子一样大的数。
- 右侧的齿轮：**外观**。**normal** 是带标签的常规框。**big** 把数字放大显示在节点
  正中，两侧各一个箭头，适合每次运行都要改的设置，比如片段的长度。拖动和输入
  在两种外观下都照旧。每个节点各自记住自己的外观，并随工作流一起保存。

## 限制

把输出接到有上下限的设置上，框就会接管这些限制。接到采样器的 **steps** 上，
范围是 1 到 10000：输入 0 会得到 1。卡片会在数值旁边显示 **1–10000**。

- 经过 Reroute 接进一个框（子图）里同样有效。
- 同时接到两个设置上，它遵守两边都允许的范围。
- 断开连线，它又接受任意整数。
- 新建的框会取你第一次接上的那个设置的值，所以在接手之前连上去什么都不会改。
  你已经设过的框，或者随工作流一起打开的框，保留自己的值。

## 输出

- **int**：这个值，原样送出。

需要顺路做算术 —— 把尺寸减半、加一点边距 —— 把它接到 **数学表达式 🆎** 里，
而不是重新手打算出来的数字。

## 技术细节

- 限制来自连线落到的那个输入，和 ComfyUI 自己的 Primitive 节点取限制的方式一样。
- 建立连线时超出限制的值会被带到最近的边界值。
- 限制由节点的界面保存。直接经 API 送进来的值按原样传下去。
- 单独用时，框能到 9,007,199,254,740,991，即浏览器能精确表示的最大整数。以前停在
  2,147,483,647，而多数种子都在这个数以上。
- 外观存在节点属性里，形如 `ausboss_text_look: "big"`，和 文本 🆎 一样。它不是输入，
  所以两种外观下保存的值和节点送出的值都一样，而旧版本的本包会显示常规框。
