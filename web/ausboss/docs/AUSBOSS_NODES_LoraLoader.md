# LoRA 加载器 🆎

用一个紧凑节点把一整叠 LoRA 施加到模型上（并可选地施加到 CLIP 上）。每一行是一个 LoRA：
一个开关胶囊、一个可搜索的选择器，以及能像滑块一样拖动的强度。每个已启用行里的
触发词都从同一个插槽输出，可直接接进提示词。

## 行

- **grip**（点状手柄）：上下拖动可以重排整叠。LoRA 按行序施加，所以顺序也是配方的一部分；
  放到位置时才提交移动，中途取消则不改变任何东西。
- **toggle**：启用或禁用该行而不丢失它的设置。
- **name**：普通单击打开选择器——输入以搜索，**方向键上/下** 高亮，**Enter** 选定，
  **Escape** 关闭；列表每次打开都从 `models/loras` 刷新。在名字上左右拖动则是
  **拖动调整模型强度**，文字后面的条也随之移动。行默认只显示文件名；完整路径在提示
  （tooltip）里，选择器保留它自己的文件夹分组。名字太长放不下时会在末尾截断；齿轮菜单 →
  **长名字** → `middle` 改为截中间，这样末尾的检查点编号
  （`…_000004000`、`…_epoch_10`）在窄节点里仍然可见。选择器打开时宽度足够容纳长名字；
  实在放不下时，它会先缩短文件夹部分，保留文件名的结尾。
- **strength**：在数字上左右拖动可拖动调整，单击可输入精确值，用尖角箭头，或用方向键。
  拖动或步进时按住 **Shift** 可做 0.01 的细调。范围是 -10 到 10。
- **i**：信息卡，含预览图、基础模型、文件大小与修改日期，以及该 LoRA 的触发词。

右键单击某一行，可以在它上方或下方插入一个空 LoRA、移动、复制或删除它，或者把它放进
一个分组（见下面「分组」）。选中多行时（Ctrl/Cmd-点击或 Shift-点击），
**移除这些 LoRA** 会把它们全部移除。**移除此 LoRA** 是红色的。
**删除全部 LoRA…** 是单独的红色、带垃圾桶标记的动作，并且需要确认；它清空本节点的行，
磁盘上所有文件都保留。取消或 Escape 保留整叠。插入会把现有的行及其设置按顺序保留；
新槽位使用齿轮菜单里的默认强度（初始为 1）。
默认一个强度同时驱动
模型与 CLIP；齿轮菜单里的 **模型 / CLIP 强度分开** 开关会为每行显示第二个框。该开关
是按节点设置的——新节点总是从统一开始——而一次吸收如果导入了一行模型/CLIP 强度不等
的 LoRA，它会自动打开，好让这个差异保持可见。再关掉它，会把每行的 CLIP 强度设为其
模型强度。

## 分组

分组让长叠保持整洁，就像图像编辑器里的图层组。一个分组有带自己开关的标题，所以你可以
一键关掉再打开一整组 LoRA（比如你所有风格 LoRA）。组里的每个 LoRA 也保留自己的开关：
把组关掉再打开，还是原来那些 LoRA 为开。

- **建组：** 右键单击某一行并选择 **归入本组**。要归入多行，先按住 **Ctrl**
  （Mac 上是 **Cmd**）逐个点击每一行，或者点击一行再 **Shift**-点击另一行，把两者
  之间的行全选上。然后右键单击其中一行并选择 **把这些 LoRA 归组**。新组出现在最上面
  那一行的位置，然后输入组名。
- **加入分组：** 用 grip 把一行拖到组名上，或拖到它任意两行之间。右键 →
  **移到分组** 效果相同。
- **移出分组：** 把该行拖到分组的上面或下面，或右键 →
  **移出** 该分组。
- **折叠：** 分组开关旁的箭头会隐藏它的行，让节点变矮。折叠的行照样参与运行。
- **重命名：** 双击分组的名字。
- 右键单击分组的标题可以移动整个组、折叠它、把它的所有 LoRA 打开或关闭、解除分组
  （LoRA 留下），或连同它的 LoRA 一起移除。拖动标题的 grip 可以移动整个组。
- **用工作流开关开关一个分组：** 把开关在组开着时保存一次、关着时保存一次。
  分组的标题随后显示一把锁，由开关来开关整个组。组里的 LoRA 仍然归你开关。
  点击那把锁可以把分组收回。

右键单击行周围的空白（或 **+ LoRA** 下方）可以添加 LoRA、把你选中的行归组、
一次折叠或展开所有分组，或删除全部 LoRA。

在任何地方普通单击都会清除 Ctrl/Shift 选择，Escape 也是。
标题上的计数（`2/3 on`）显示它的 LoRA 里有几个是开的。组关闭时它显示
`group off`，组里的 LoRA 会变暗。

### 技术细节

LoRA 仍然按你看到的顺序自上而下施加；分组对整叠如何运行没有任何影响。分组只有一层深，
只要组里还有 LoRA 它就存在。每一行在保存的叠里保留它所属分组的名字，所以分组会随模板、
撤销，以及子图框上显示的行一起走。哪些分组被折叠随节点保存。关闭的分组会在保存的叠里
给它的每一行标上 `group_off`：它们都不运行，而各自仍保留自己的开关。拖进关闭分组的行
会随组关闭，拖出来的行又按自己的开关运行。重命名分组会保留它的开关状态和它的工作流开关。
节点顶部的开关会把每一行、每一个分组都打开。上移 和 下移 会让一行一次一步地走出它所在
分组的边缘，或进入旁边的分组。拖动时，如果该行会加入某个分组，落点线会带缩进。分组
最后一行的正下方就是在组外；要在分组末尾添加一行，请把它落在组名上。

## 子图框上的行

当加载器位于一个子图内部时，它的行可以显示在框本身上，这样你不必打开框就能开关 LoRA、
改变强度。

1. 打开框，按下加载器的齿轮。第一项是 **框上的行**。
2. 按 **显示**。这些行现在显示在框的正面。

每个框的副本保留自己的行，运行的也是那个副本。在内部，加载器显示「这些行设在框上」
并显示你进入时那个框的行；在那里改动会写到那个框。同一位置的 **收回** 会把行放回加载器
内部，按你进入时那个框所持有的行来放，此后该框的每个副本都运行这些行。

在框上，卡片保留行、主胶囊和 **重新检查 LoRA 文件**。模板与齿轮仍留在内部的加载器上。

工作流开关可以像任何其他设置一样设置框上的行：选中该框并保存它的开与关
（见工作流开关的帮助）。

## 由开关设定的行

被工作流开关打开或关闭的行，会在它的拖动手柄处显示一把 **锁**，并在左缘显示一条细线。
把指针悬在锁上可以看到是哪个开关在设定它。你仍然可以改变该行的强度与触发词：开关只
开关这一行，除非它保存时开用一个强度、关用另一个强度。点击锁可以把该行收回：开关忘记
这一行，从此不再管它，也不再因为它显示「已更改」。开关做的其他事都保持不变。被锁的行
仍然可以拖到新位置。

被开关开关的分组改为在标题上显示锁。组里的 LoRA 保留普通手柄，所以每一个仍然归你开关。
点击标题上的锁可以把分组收回。

## 强度条

每个有名字的行都会在名字后面画一条以中心为零的条：青绿色从中心向右生长表示正的模型
强度，暗红色向左生长表示负的，1px 的刻度标记零，更亮的 2px 端帽标记取值的边缘。整叠
共用一个刻度：字段边缘代表 **已启用** 行中最大的绝对强度，下限为 1.0 —— 所以一叠日常的
0.5 会如实地显示为半条，某一行到了 2.0 会让所有条重新缩放而不是被截断，而把那一行关掉
会把刻度交还给仍在场的最强一行（与此同时，变暗那一行自己的条在边缘处被夹住）。当前生效
的刻度写在每行的提示里。
齿轮菜单 → 「强度条」可以把它们关掉；「在名字上拖动调整强度」可以关掉名字拖动。

## 控制条

这个条骑在输出插槽带的中间空白处，所以节点把高度花在行上而不是装饰上。从左到右：

- **▤ 模板** —— 把当前这叠存成一个名字，或套用/删除一个已存的。模板保存在本浏览器里，
  由它打开的每个工作流共享。
- **主胶囊** —— 循环 *混合 → 全开 → 全关 → 回到它刚才破坏的那个混合设置*。每次手工
  切换行开关都会刷新这份记忆，所以误点主胶囊之后总能再点一下回到原样。
- **摘要** —— 有几行是开的。
- **↻ 重新连接** —— 用一份全新的 `models/loras` 列表重新检查每一行并尽量修好：
  文件换了文件夹（或曾经缺失又回来了）的行会被改写为解析出的路径。ComfyUI 自带的
  **R** 刷新会静默跑同一遍。
- **⚙ 齿轮** —— 设置，以及下面的 **吸收链上 LoRA** 动作。

**+ LoRA** 打开一个按文件夹分组的文件列表。点击文件添加一个 LoRA，或点击文件夹名添加
它的全部 LoRA，包括嵌套文件夹。要从不同文件夹添加多个文件，勾选每个文件旁边的框
（或 **Ctrl**-点击它的名字），然后点击底部的 **添加 N 个 LoRA** 或按 **Enter**。
**Shift**-点击会勾选你上次勾选的那个与你这次点击的那个之间的每个文件。搜索时勾选保持，
所以你可以从多次搜索里收集文件；**清除** 会把它们全部取消勾选。已在叠里的文件显示
**已在叠中** 且没有勾选框。用键盘时，**Ctrl+Enter** 勾选高亮文件，**Shift+Enter**
勾选到它为止的这一串。用文件夹旁的箭头可以在不添加任何东西的情况下折叠或展开它。
折叠状态记在本浏览器里。搜索会显出匹配的文件；清除搜索会带回你折叠后的视图。搜索时
也可以折叠文件夹。

每个文件夹都会显示 **全部添加** 和它的完整文件数，即使搜索隐藏了它的某些文件。新行使用
齿轮菜单里的默认强度。文件夹会跳过已在叠里的文件；已有的行保持它们的顺序、强度和开关。
不同文件夹里的同名文件算作不同的 LoRA。

这次选择算一步撤销。不选任何东西就关闭选择器不会改变
任何东西。输入文件名并按 Enter 会选中一个文件；如果想整个文件夹，先用方向键高亮那个
文件夹再按 Enter。用鼠标指向一个文件夹不会让它成为 Enter 的目标。
左/右键会折叠和展开高亮的文件夹。
点击已有行的名字仍然只替换那一行的文件。

## 键盘操作

按 Tab 直到某一行被描边。被描边的行就是你正在改的行。点击一行里两个控件之间的细缝
也会给它描边。

- **上 / 下** 在行与 **+ LoRA** 之间移动。
- **Enter** 打开该行的文件选择器，或从 **+ LoRA** 添加一个新 LoRA。
  在选择器里，照常用 上/下 和 Enter。选中文件后焦点回到它那一行；Escape 不作改动地返回。
- **空格** 关闭或打开被描边的行。
- **左 / 右** 按齿轮菜单里的强度步长（默认 0.05）减小或增大模型强度。**Shift** 使用更小的
  0.01 步长。联动模式下 CLIP 强度也随之改变。分开强度时，聚焦 CLIP 框可以只改 CLIP。
- **Tab** 照常继续在控件之间移动。在一行自带的按钮上，Enter 和空格会按下那个按钮。
  **Escape** 离开行键盘控制。点击加载器之外的地方也是一样。
- **Delete** 与 **Backspace** 在某一行、它的控件或 **+ LoRA** 上都不起作用，所以不会误删
  节点。要删除节点，先点击节点或图。

用鼠标操作不会启动键盘控制：在你点击某个开关或从列表里选了文件之后，按键仍归 ComfyUI。

在字段里打字保留它原本的编辑键。这些快捷键只在这个加载器内部生效；ComfyUI 的
Ctrl/Cmd 快捷键仍然照常传递。

## 吸收链上的 LoRA

齿轮菜单 → **吸收链上 LoRA**。会沿本节点两侧的模型链走一遍——上游经 `model` 输入，
下游从 `model` 输出出发——对它认出的每个加载器（核心的 `LoraLoader` 与
`LoraLoaderModelOnly`、rgthree 的 Power Lora Loader 与 Lora Loader Stack、JPS
Lora Loader、`PixaromaLoraLoader`、另一个 AusBoss LoRA 加载器；中转节点会穿过去）按
施加顺序把它的行抬进这一叠：上游加载器、你现有的行，然后下游加载器。只有在连接能够
保留时，原加载器才会被设为 **绕过**。重复的文件名仍然是各自独立的行，带着自己的强度
与开关。

让吸收保持忠实的一些细节：

- 遍历跟随连接，不跟画布位置，并停在未知节点与下游分叉处
- JPS 里被关掉的行保持禁用；rgthree Lora Loader Stack 的强度同时作用于模型与 CLIP
- 名字按本机安装的 `models/loras` 解析——先精确匹配，再忽略文件夹与扩展名做唯一的
  基名匹配（用于在别人机器布局上保存的工作流）；解析不出的名字原样导入，行会染红
- `LoraLoaderModelOnly` 的行以 CLIP 强度 0 导入
- 重复的 LoRA 会被保留：同一个文件施加两次本来就是原配方的一部分
- 共享的模型路径，包括藏在中转节点后面的分支，会阻止吸收，而不是去改动另一条分支
- CLIP 补丁发生移动时，CLIP 必须沿与 MODEL 相同的串联链；来自没有连接 CLIP 的加载器
  的行以 CLIP 强度 0 导入
- 已连接的辅助输出，例如触发词，会阻止吸收，因为绕过它们的来源会断掉那些连接
- 被接线的 LoRA 设置会让来源保持活动
- 已被绕过或静音的加载器不贡献任何行
- 一条提示消息会汇总导入了什么、绕过了什么、重映射了什么、跳过了什么

## 移动过与缺失的文件

行会与本机安装的 LoRA 列表核对。文件换了文件夹的行会得到一个虚线边框和一条提示，说明
运行时会用哪个文件；哪里都匹配不上的行会染红；基名有歧义的行染红并建议重新选择。
缩略图、信息卡和范围查询都用解析后的名字，所以移动过的文件仍保留它的预览图和 Civitai
数据。

运行侧也一致：过期的已保存路径在加载时按名字解析（精确 → 唯一的大小写不敏感路径 →
唯一基名，发生重映射时在控制台留一行说明）。真正缺失的 LoRA 会
**在采样任何东西之前中止运行**，错误里会点出那个文件——一张丢了 LoRA 的图比没有图更糟，
尤其是对脚本或智能体来说，它们会乐于把它当成好结果来评判。错误里还会说明那个开关在哪儿。

齿轮菜单 → **LoRA 缺失时停止**（默认开）会为本节点关掉这一行为，也会为你在这个浏览器里
之后添加的 LoRA 加载器关掉；工作流里已经保存的节点各自保留自己的设置。关掉之后，
缺失的行只会在控制台警告一次并被跳过，整叠其余部分照常施加，这适合坐在画布前、想看到
画面其余部分的人。在 API 图里，同一个开关是 `on_missing` 输入（`"error"`，默认，或
`"skip"`）；在该输入存在之前保存的图会取默认值。

文件在、但不是 LoRA 时同样会在加载任何东西之前中止运行，错误里点出该文件并说明它是什么：
一个 Draw Things 文件（导入时 Draw Things 会把 LoRA 变成它自己的一种文件，而 ComfyUI
打不开那种），一个因为下载需要登录而存下来的网页，或者一个从未下载完的文件。在那一行
重新选择原始的 `.safetensors` 文件。之后在打开过程中才失败的文件会得到同样的平实消息，
末尾附上加载器自己的错误。

## 预览缩略图

把指针悬在某一行的名字上——或选择器里的任一条目上——当 LoRA 文件旁有附属图片时，会
在光标旁浮出一个小预览（同基名：`.preview.png` / `.preview.jpg` / `.preview.jpeg` /
`.preview.webp`，或单纯的 `.png` / `.jpg` / `.jpeg` / `.webp`）。没有附属图片就没有
缩略图——什么都不出现，也不会移位。齿轮菜单的 **预览缩略图** 开关可以关掉这一行为。

**从 Civitai 取图：** 在某个 LoRA 的信息卡里点击 **获取 Civitai 信息**（或
**刷新 Civitai 信息**）。它还会把该 LoRA 在 Civitai 上的第一张图存到文件旁边，
悬停预览和信息卡随即显示它。齿轮菜单 → **Civitai 图片** 选择取哪些图：
**PG-13**（默认）跳过 Civitai 评为 R 及以上的图，**任意** 取第一张图无论分级，**关闭**
一张都不存。它绝不会替换你已经有的图。

## 触发词

信息卡从三处汇集词语：LoRA 文件自身的元数据、放在文件旁的标准 `<model>.civitai.info`
附属文件（卡片里的 **获取 Civitai 信息** 按钮会写一份；其他 Civitai 工具写的是同一种
文件），以及你自己添加的词语（按 LoRA 记住，跨工作流有效）。点击一个词可以把它切换进
该行；已启用行里选中的词会合并到 `triggers` 输出，去重，按行序排列。为某一行换了文件
会清掉你为旧文件打开的那些词。

## Civitai 信息与建议强度

- **获取 Civitai 信息** 会去 civitai.com 查这一个 LoRA。你不点击就不发送任何东西。
  随后浏览器只发送该文件的 SHA256 指纹，答案存到 LoRA 旁边为
  `<model>.civitai.info`，该 LoRA 的图存为 `<model>.preview.jpg`
  （见上面「从 Civitai 取图」）。此后按钮显示 **刷新 Civitai
  信息**，卡片上多一个 **在 Civitai 查看** 链接。Civitai 不认识的 LoRA（未发布或隐藏）
  显示 **Civitai 上未找到**。齿轮菜单 → **Civitai 查询按钮** 可以去掉这个按钮。查询失败时，
  消息会说明原因。如果它总是说连不上 civitai.com，检查 ComfyUI 是否用
  `--disable-api-nodes` 启动：该设置会阻止浏览器访问任何其他站点，包括 Civitai。
- **建议强度**：卡片底部的最低值与最高值（留空一个表示「任意」）。它只是提醒：设到
  范围外的行会把它的数字显示为橙色，提示里给出范围。按 LoRA 保存，对所有工作流有效。

## 其他齿轮选项

- **默认强度**（起始为 1）：新添加的 LoRA 得到的强度。
- **强度步长**（起始为 0.05）：一次拖动步或一次方向键点击移动多少强度。Shift 总是走 0.01。
- **触发词分隔符**（初始为一个逗号和空格）：用什么连接 `triggers` 输出。
- **隐藏文件扩展名** 与 **隐藏文件夹名**（都开）：名字在行上如何显示。完整路径留在提示里。

## 输出

- **model**：所有已启用 LoRA 按行序施加后的模型。
- **clip**：所有已启用 LoRA 施加后的 CLIP（没有连接 CLIP 时为空）。
- **triggers**：已启用行里选中的触发词，去重，用齿轮菜单里的分隔符连接（默认逗号）。

强度为 `0` 的行（模型与 CLIP 都是）在加载时被跳过，但仍然贡献它们的触发词，这样你可以
把某个 LoRA 停在零上做比较。因为文件缺失而被跳过的行什么都不贡献：那个 LoRA 不在画面里。
