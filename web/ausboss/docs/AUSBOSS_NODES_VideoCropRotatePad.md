# 视频裁剪 + 旋转 + 扩边 → 单帧 🆎

**输出一帧，不是片段。** 节点上和编辑器里的时间轴只用于找到那一帧；节点返回的是那张
单幅图像，不是重新编码的视频。

加载一个精确的视频帧，并施加与图像节点相同的 **旋转 → 裁剪 → 扩边**
变换。它返回变换后的 `image`、其生成区域的 `mask`、供局部重绘拼接用的 `stitcher`、
变换前被选中的 `original` 帧，以及输出的 `width` 和 `height`。

## 源与帧

- **输入**：选择一个输入视频（列表会在指针悬停时静音播放该片段，并随输入过滤）、
  点击紧凑源卡片里的 **加载**，或把视频文件拖到节点上。换选另一个视频会保留填充、羽化、
  **对齐**、缩放设置和点亮的比例按钮（新帧按 **适配** 的设定方式去适配它）；旋转、裁剪、
  扩边和播放头会重新开始。
- **加载** 会流式写入 input 文件夹，所以超过缓冲图像上传上限的视频也可以在这里选择或拖到
  节点上。
- **输入** / **输出**（`source_mode`：`input folder` / `local path`）：源卡片上的开关。
  输入 列出 ComfyUI 的 input 文件夹。输出 列出 ComfyUI 的 output 文件夹里的视频，最新的在前，
  刚渲染出的视频无需再次上传就能选到。两个列表都会在指针悬停时预览视频。
- **local_path**：在 输出 列表里选中的视频，按 ComfyUI 在 output 文件夹里命名文件的方式命名：
  `clip.mp4 [output]`、`video/take 3.mov [output]`。它就地读取，不产生上传副本。
  像 `/home/me/ComfyUI/output/clip.mp4` 这样的整条路径不会被读取，排队运行与编辑器的实时预览
  都如此。
- **播放 / 暂停** 在拖动条旁预览视频。在你想要输出的那一帧上暂停。
- **播放头**：节点预览正下方的那条轨道就是时间轴：按住或拖动它来
  拖动定位，或在 **FRAME** 框里输入帧号；舞台上的那一帧就是
  节点输出的帧（`frame_index`，`frame_time` 与之保持同步）。
- **裁剪、扩边与缩放**（时间轴下方的可折叠组）：把比例按钮、**适配比例**、
  **对齐** 与 **居中**、**填充** 与 **羽化**，以及 **缩放** 关 | 开 开关、百万像素预算
  和 **步进** 收进同一个抽屉，收起时在其标题上显示填充色块与实时摘要。画面下方那一行
  会像图像节点那样，逐项列出决定输出尺寸的每个步骤。
- **seek_mode / frame_time**：为那些用连线驱动位置的图提供基于时间的定位；
  编辑器本身始终以帧为单位工作。

编辑器有同样宽度的整条轨道，另有首帧/末帧、±1、±25、±50、±100、播放/暂停、键盘方向键
（一帧，按住 Shift 为 10 帧）、Home/End 以及空格播放或暂停。**保存并关闭** 保留你的编辑；
**取消** 或 Escape 把一切放回，若有改动会先询问。同一时刻只保留一个帧预览请求；
过期请求会被取消，已显示过的帧由一个小缓存提供。

## 变换与输出

旋转、裁剪、扩边、羽化、填充、**对齐**、百万像素缩放、手势、`image` 和 `mask`
都与图像节点一致。输出的批次里只有一帧。

手柄在节点和编辑器上都可用。拖动橙色角可以让画布按自身形状变大或变小
（按住 **Alt**，Mac 上是 Option，一次改动四条边），按压 填充 与 羽化 旁的 **居中**
可以让裁剪居中并让扩边左右或上下均衡。两者都与图像节点上一致。比例按钮、**适配**、
挂锁和方向按钮也与图像节点上一致：点一下把该帧扩边（打开适配时则是裁剪）到某个比例，
点亮的比例就是画布当前的形状，挂锁在你拖动时保持该形状（该行显示 **Held**）。
**重置裁剪** 恢复完整裁剪，同时保留旋转与扩边。**重置**
清掉旋转、裁剪与扩边并关掉挂锁；填充、羽化、**对齐** 与播放头保持不变。**对齐**
让宽和高能被你所选的数字整除：扩边会增加几个像素，而没有扩边的一侧则改为裁掉几个。
有些模型需要 8、16 或 32 的整除尺寸；1 表示关闭。

附加的 **stitcher** 输出在生成之后以 32 像素混合还原保留的像素。**original**
返回变换前选定的 RGB 帧，**width** / **height** 返回变换及任何缩放之后的输出尺寸。
原有的 image 与 mask 插槽位置不变。

视频元数据与预览路由会校验扩展名，并且只返回编辑器所需的信息。节点不发起远程网络请求，
也不改写源视频。
