# 图像比较 A/B 🆎

把两张图放在同一块面板上，差别就跳出来，而不是藏在
并排的两张图里。每批的第一帧被预览；`image_a` 和
`image_b` 原样穿过各自的输出，所以这个节点可以待在图
中间，而不破坏下游的任何东西。

## 输入

- **image_a**：基准批次。它的第一帧是预览 A，
  整个批次则由 `image_a` 输出带出。
- **image_b**：用来比较的批次。它的第一帧是预览 B，
  整个批次则由 `image_b` 输出带出。
- **filename**（可选）：**Erase** 保存的文件所用的名字，
  例如源图片的文件名。不接线就在
  节点上直接输入。

## 面板

先跑一次工作流把预览载入。图片下方的开关
决定面板做什么，它的标记会滑到你选的那一项：

- **Slide**（默认）：面板显示结果。把指针在上面移动
  就能比较：分界线左边出现 A，右边出现 B。把
  指针移开，结果又回来。每次新的运行也会显示它的
  结果。
- **A** / **B**：显示那张图并停住，指针怎么动都不变。
- **Erase**：手动把两张图混在一起。一张压在上面；在上面涂，
  它就被擦掉，另一张透出来。然后把混合结果保存下来。
  见下文 **Erase**。

带透明部分的图片会把它们显示在棋盘格上，和
编辑器一样。

标签跟着分界线走：**A** 就在它左边，**B** 就在它
右边，各自标在所指的那张图上。只显示一张图时，
它的标签单独待在上方正中。选定的模式，以及
锁定在哪一侧，都随节点保存，也支持旧工作流里
带的模式。分辨率显示在图片下方、开关旁边；
两张图尺寸不同时，两边分别标注各自的
尺寸。

## 多张图片

给节点一串图片，比如一个图片文件夹，它会在图片下方
显示箭头（‹ 2 / 5 ›）。点击它们可以在各对之间切换：
A 和 B 一起换。**Erase** 保存你正在看的那一对。

批次仍然只显示它的第一帧。

## Erase

当你想用一张图的一部分、另一张的一部分时用它：编辑
结果不错，但把手改坏了，于是你把原来的手涂回来。或者
你只想要新的天空。

它也能把透明的背景带回来。当下面那张图有
透明部分时——比如模型在背后补上的抠图——在那里把
上面那张擦掉，它们就重新变透明。存出的 PNG 和 PSD 会
保留它们。

在开关上选 **Erase**。图片上方会开出一排工具：

- **Erase | Restore**：画笔做什么。Erase 擦掉上面那张
  图。Restore 把它涂回来。按住 **Ctrl**，或用鼠标
  右键，按住期间就做相反的那件事。
- **Size** 是画笔的宽度，单位是图片像素。
- **Size** 旁边的圆点预览一次落笔。它随 Size 变大，边缘随 Soft 提高而变淡。
- **Soft** 是画笔的边缘：0 是硬边，100 从中间一路
  淡到最外。
- 在 **Size** 或 **Soft** 上左右拖，字、数字或
  单位都可以，就能改值。点数字可以直接输入。
- **On top: A | B** 是你从哪张图开始。选另一张，它就
  换到上面。你涂的东西留在原处。
- **ALIGN** 把 B 对齐到 A。编辑模型常把图画偏几个
  像素，或者稍微放大，于是你涂的边缘会出现台阶。
  点一下，B 就被搬回 A 上；Save 和 Copy 使用对齐后的
  B。再点一次，回到原本的 B。它修的是位移
  和缩放，不是弯了或变了形的图。B 被移出边缘的地方，
  A 补上缺口。
- **UNDO** 撤回最后一笔，或者一次 Clear。**CLEAR** 把涂的东西
  全部去掉。

画笔以青色显示在指针周围：一个与实际大小相同的圆环，
里面是它的形状，中间实心，边缘柔化的地方渐淡。
往回涂的时候它变成珊瑚色。

不用离开图片就能调画笔，用的键和
Photoshop 一样：

- **E** 擦除，**B** 涂回，和 Photoshop 的橡皮与
  画笔一样。
- **[** 和 **]** 让它变小、变大。
- **Shift + [** 和 **Shift + ]** 让边缘更柔、更硬。
- 按住 **Alt** 和鼠标右键再拖：左右
  调大小，上下调边缘（向上更柔）。画笔停在
  你按下的位置，随拖动变化，大小和柔度
  写在它下面；虚线圆环是实心中间结束的地方。一次
  拖动可以两样都做：横着走调大小，再上下转调
  边缘。在 Mac 上，按住 Control 和 Option 再拖。

这些键只在指针位于图片上时有效。ComfyUI 自己的
快捷键不动。

开关下方还会开一排，用来保存：

- **Name**：文件叫什么。留空时用 `compare`。
  字母、数字、空格、点、横线和下划线保留；名字里
  不能带文件夹。接了 **filename** 输入时，名字
  从那里来，这个框只用来显示。
- **PSD off | on**：开启后 Save 会多写两个文件（见下文）。
- **Copy** 把混合结果按原尺寸放进剪贴板，可以粘到
  编辑器或聊天里。什么都不会存。只有 ComfyUI 以
  `localhost` 打开或走 `https` 时浏览器才允许这样做；从另一台
  电脑用普通地址访问，就用 Save。
- **Save** 在最右端，把混合结果写成 PNG 存到 ComfyUI 的
  output 文件夹，例如 `compare_00001.png`。不会重跑任何东西，每次保存
  取下一个编号，所以不会覆盖已有的文件。

开启 **PSD** 时，Save 还会写出：

- `compare_00001.psd`：两张图各作一层，你的涂改作为
  上面那层的图层蒙版。在 Photoshop、GIMP 或其他
  能读 PSD 的编辑器里打开，继续在蒙版上做。
- `compare_00001_mask.png`：单独的蒙版。白色是下面那张图
  透出来的地方。

保存之后，图片下方那行会显示 **Saved**，每个文件带一个链接。
点其中一个即可下载，ComfyUI 跑在
另一台电脑上时很有用。

你涂的东西随工作流保存。新的一次运行只要图片
尺寸不变就会保留它，所以你可以换个种子再看；按 **CLEAR**
重新开始。尺寸不同的图片从干净状态开始。

## 哪张图是结果

是 B，「之后」的那张。如果你的图是从 B 的图片造出 A（B 是
你载入的图，A 是编辑后的），结果就是 A。想让一张图
无论怎样都留在上面，用 **A** 或 **B** 按钮。

## 输出

- **image_a**：`image_a` 批次，原样。
- **image_b**：`image_b` 批次，原样：你用来对照的那张图，
  通常是编辑后的那张。想保留的图是 B 时，就接它。

预览写到 ComfyUI 的 temp 文件夹，随它一起消失。按下
Erase 里的 **SAVE** 之前，output 文件夹里不会存下任何东西，
也不会发出网络请求。

## 技术细节

- 滑动时，两侧各 6% 的范围会吸附成整张图。
- 结果由连线判定：当喂 `image_b` 的节点位于喂
  `image_a` 的节点上游某处时，A 是从 B 造出来的，
  A 就是结果。两张图都出自同一个子图时，在子图内部
  做同样的判断。其余情况都是 B：两张互不相关的图、
  两张图都出自同一个普通节点，或者节点跟不下去的连线
  （例如一对 Set 和 Get）。
- Settings → AusBoss → Image Compare → **Rest on the result** 会关掉
  这个行为。面板会停在指针离开时最近的那张图上，
  新的运行也不会改它。
- **Erase 作用在每批的第一张图上**，按它的原尺寸。混合结果
  总是 A 的尺寸：尺寸不同的 B 会缩放到 A。
- **透明部分**只在图片确实有时才会保留在预览里，
  所以实心图片保存出来和以前完全一样。混合把上面那张
  像编辑器那样叠在另一张上。PSD 里每层保留自己的
  透明部分，平面图携带混合结果的那份，颜色按 Photoshop 的
  方式存在白色之上。**Align** 把两张图铺在灰色上测量，
  并带着 B 的透明部分一起移动。
- **保留的是笔画**，不是涂好的图片。面板替你把它们画出来，
  保存时服务器按原尺寸再画一遍，所以无论节点多小，
  存出的边缘都和图片一样锐利。Copy 在浏览器里
  按原尺寸画。
- **Erase 从不改变节点尺寸。** 节点窄的时候，它的几排
  会折到第二行，图片反而变矮。
- **画笔**是实心的中间加模糊的边缘。Soft 100 时，
  中间占画笔宽度的一半，模糊占八分之一。
- **Save 混合的是节点上一次运行的两张图**，ComfyUI 把它们
  留在 temp 文件夹里。重启 ComfyUI 之后就没了：再跑一次
  工作流，然后保存。浏览器发的是笔画、那次运行的一个
  键和文件名：它从不会指定要读的文件，名字在
  服务器上还会再校验一次。
- **接进来的名字会被整理**：文件夹和扩展名去掉，
  文件名装不下的字符变成下划线
  （`sets/a/photo 12.jpg` 存成 `photo 12_00001.png`）。
- **存出的文件不带工作流。** 混合是手工做的，
  没有什么是工作流能重新生成的。
- **PSD** 是 8 位 RGB、不压缩：每个像素约 12 字节，
  所以一张 2048 x 2048 的图约 50 MB。它不带颜色配置，
  和 PNG 一样。
- **限制**：一次混合 400 笔。满了的时候节点会说明。
