# 布局框 🆎

在画布上画框，并说明每个框里放什么：一样东西，或者要写进图里的字。你做出来的图
里，每样东西就在你放的位置上。用于布局类提示词，比如 MOSS-Image 的那种。

它做的事和 ComfyUI 自己的 Create Bounding Boxes 一样，给的输出也一样。它的画布在
经典节点外观下也能用，而 Create Bounding Boxes 只显示 "Node 2.0 only"。

## 怎么用

1. 在 **Canvas**（W × H）里设定画布尺寸，或者把 Latent 尺寸 的 `width` 和 `height`
   接进来，这样框和你的图尺寸一致。
2. 在画布上拖动就能画一个框。框上的标签显示它的编号和类型，例如 **1 object**。
3. 画布下面，**Box 1 is** 那一行设定选中的框里放什么：**object** 或 **text**。
   然后输入它的文字：
   - **object**：**Description** 说明框里是什么，例如 "a red bicycle leaning on a
     brick wall"。
   - **text**：**Text** 是要写进图里的字，例如 "OPEN 24 HOURS"。**Description**
     说明它们长什么样，例如 "pink neon letters"。
4. 把 `elements` 接到 MOSS-Image Layout Prompt 的 `element` 输入，并给那个节点
   同样的宽和高。

把 `preview` 接到 Preview Image，就能看到带编号和文字的框。

## 改掉图上的字

`mask` 输出在每个框内都是白色。用它只改一张图的一部分，比如招牌或衬衫上的字。

1. 把 Load Image 接进 `background` 并选好你的图。它会立刻显示在画布上。
2. 在旧字上画一个框，每一侧都比旧字宽一点（大约 12 像素），否则旧字母的边角会从
   框边露出来。把脸和手排除在外：框里的一切都会被重画。方向键可以把选中的框
   一次挪一个像素。
3. 如果字是斜的，就把框转到与字对齐：拖动框上方的圆手柄（见下文“旋转框”）。
4. 把它做成 **text** 框。在 **Text** 里输入新的字，在 **Description** 里说明它们
   长什么样，例如 "white letters on a red sign"。
5. 柔化 `mask` 的边缘，比如用 遮罩精修 🆎 设约 6 的模糊，否则框周围会出现一圈线。
   然后把它接进工作流里做局部重绘的那部分：Set Latent Noise Mask，只重画框里；
   Image Composite Masked，其余一切保持原样。
6. 用 MOSS-Image 时，把 `elements` 接到 MOSS-Image Layout Prompt。模型从框里拿到
   新的字，而你的提示词只描述这张图。

## 旋转框

招牌或衬衫上的字常常是斜的。把框转过去贴着它们，就只会重画那些斜的字。

1. 点一下框把它选中。它上边的中间会出现一个圆手柄。
2. 拖着手柄绕框转动。按住 Shift 按 5 度一档转。
3. 或者在画布下方的 **Turn** 里输入角度：正数让框顺时针转。**0°**，或者双击那个
   圆手柄，就能让框重新摆正。

框上的标签显示它转了多少，例如 **1 text 25°**。转过的框照样能移动、改大小，也能用
方向键。它的角可能伸到图的外面，所以它能盖住一直延伸到边缘的字。

转过的 **text** 框会替你告诉模型这个倾斜：它在 `elements` 里的描述会多出
"tilted about 25 degrees, running downhill to the right"（或 "uphill"），所以你不用
自己打字。

如果图在送到模型之前被缩放，遮罩也要跟着缩放：图像缩放 🆎 接收遮罩，给出同样
尺寸和裁剪的遮罩。

## 画框与移动框

| 这样做 | 得到这个 |
|---|---|
| 在空白处拖动 | 画一个新框 |
| 在某个框上按住 Shift 拖动 | 在它上面画一个新框 |
| 拖动一个框 | 移动它 |
| 拖动选中框的角或边 | 把它变大或变小 |
| 拖动选中框上方的圆手柄 | 旋转它（Shift：5 度一档） |
| 双击圆手柄 | 让框重新摆正 |
| 双击一个框 | 输入它的文字 |
| 点画布下方某个框的比例按钮（**1 text**、**2 object**） | 选中那个框，包括被别的框挡住的。框比按钮多时，**‹ ›** 逐个翻过去 |
| Delete | 删掉选中的框 |
| 方向键 | 把选中的框挪一个像素（Shift + 方向键：十个像素） |
| Ctrl + D | 复制选中的框 |
| Esc | 放开这个框，或者把你正在拖的框放回原处 |
| 拖动时按住 Ctrl（或 Alt） | 自由摆放，脱离网格 |

这些键在画布有焦点时有效：先点一下画布，或者点一个框的比例按钮。

放大或缩小整个图时，手柄和标签在你屏幕上的大小不变，而小到放不下八个手柄的框
会保留它的四个角。在图上，框是透明的、不显示文字，这样你能看清下面的东西；
选中的框的文字显示在画布下方。

**object** 框不会写出文字。如果它在是 **text** 框的时候你打过字，画布下方的一行会
说明文字被保留了：点 **text**，它们就回来。

## 框的先后顺序

第 1 个框在最底层，最后一个框在最上层，所以先画后面的东西。画布下方的两个方形按钮
把选中的框往后或往前挪。MOSS-Image Layout Prompt 的 `character_boxes` 用的就是
这些编号。

## 颜色

一个框最多可以有五种颜色，供模型用在那样东西上。**+** 增加一种颜色，点某个颜色
可以改它，右键（或它的叉）删掉它。第一个颜色同时也给画布上的这个框上色。

## 画布上方那条栏

- **Grid**：用鼠标画、移动和改大小时，框会吸附到网格。空画布上它是打开的，而
  `background` 上有图时它是关闭的，所以框可以放在图上的任何位置。点它开关；
  节点会记住你的选择。拖动时按住 Ctrl（或 Alt），这一次拖动就不走网格。格子是
  32 像素，在很大的画布上更大。转过的框不吸附：它一次移动和缩放一个像素。
- **Layouts**：从现成的排布开始：一个居中、两个并排、三个横排、上下、图上压一个
  标题、四个角。你已经有的框会移到新的位置，摆正，并保留它们的文字。
- 画布尺寸，以及它从哪来：`background` 上有图时是 **picture**，宽和高接了线时是
  **wired**。
- **Clear** 删掉所有框。
- **⚙**（齿轮）：**Grid size**，即一条网格线到下一条之间多少像素：Auto（32 像素，
  在很大的画布上更多）、8、16、32 或 64。节点会记住它。

## 输入

| 输入 | 它做什么 |
|---|---|
| `background` | 用来画图的图。它显示在框的下面，画布取它的尺寸和形状，接了 `width` 和 `height` 时也一样：框画在图上，`mask` 就在那里生成。接上图时 Canvas 那一行会变暗。 |
| `bboxes` | 作为起点的框：包围盒、提示词元素（例如另一个 布局框 的 `elements`），或它们任一形式的 JSON 文本。接上这条线的新框会在工作流运行时填满画布。之后你在画布上做的改动会保留，直到线上的框变了。**Clear** 之后，下一次运行又会用线上的框填满画布。 |
| `width`、`height` | 画布的像素尺寸。从 Latent 尺寸 接进来时，画布会立刻取那个尺寸和形状。 |

## 输出

| 输出 | 用途 |
|---|---|
| `preview` | 一张带框、编号、文字和颜色的图，用来检查布局。转过的框按转过的样子画。 |
| `bboxes` | 以画布像素表示的框（x、y、宽度、高度），供接收包围盒的节点用。转过的框给出包住它的正框。 |
| `elements` | 作为提示词元素的框。接到 MOSS-Image Layout Prompt。转过的框给出包住它的正框，而转过的 text 框会在描述里说明它的倾斜。 |
| `mask` | 每个框内为白、其余为黑，用于只改图上的那些地方。转过的框只在它转过的形状内为白。 |

## 替代 Create Bounding Boxes

布局框 的输入相同、输出相同、顺序也相同（`mask` 在它们之后），所以线可以直接搬
过去。同样的框，它给出同样的 `bboxes` 和 `elements`，MOSS-Image Layout Prompt 也用
它们做出同样的提示词。

画在 Create Bounding Boxes 上的框不会自己搬过来。要把它们带过来，就把那个节点的
`elements` 接到 布局框 的 `bboxes`，跑一次：它们会填满画布。然后删掉旧节点。

## 技术细节

- 框以文本形式存在节点上隐藏的 `layout` 输入里。每个框的位置按 0 到 1 的画布比例
  保存，所以换一个画布尺寸，每个框仍在同样的位置。API 提示词可以设置它：
  `{"v": 1, "boxes": [{"x": 0.25, "y": 0.1, "w": 0.5, "h": 0.8, "type": "obj", "text": "", "desc": "a cat", "palette": ["#ff3399"]}]}`。
  Create Bounding Boxes 自己那种形式的像素框列表也能读。
- 转过的框还带 `"angle"`：度数，屏幕上顺时针，-90 到 90，绕框的中心。`x`、`y`、`w`
  和 `h` 仍是框画出来时的样子，不含旋转。只有转过的框带这个键，没有它的框就是正的，
  所以在框能旋转之前保存的布局给出的东西和以前完全一样。旋转是在这个框画在的那个
  画布的像素上做的（`background` 上有图时就是那张图），所以不管画布什么形状，
  转过的框在那里都是真正的矩形。
- 对转过的框，`mask` 在每个中心落在转动后矩形内的像素上为白。`bboxes` 和
  `elements` 装的是包住它的正框，并裁到画布之内：那些类型只认得正框。转过 2 度
  或更多的 text 框，会在 `elements` 里的描述上，以逗号后追加、或在描述以句号结尾
  时另起一句的方式，加上 "tilted about N degrees, running downhill to the right"
  （顺时针）或 "running uphill to the right"；描述里已经说了就不加。object 框不加
  这类词。
- `elements` 每个框一个元素，按顺序：
  `{"type": "obj" or "text", "bbox": [ymin, xmin, ymax, xmax], "text", "desc", "color_palette"}`。
  位置是在画布上 0 到 1000 的网格里，`text` 只有 text 框才有，`color_palette` 在框有
  颜色时装最多五种。
- `bboxes` 是一个列表，里面装一组框列表，也就是 ComfyUI 那些包围盒节点往下传的
  形式。没有框时它是空的。
- `mask` 是一张遮罩（1 x 高 x 宽）：每个框内为 1，其余为 0，硬边。`background` 上有
  图时，它是图自己的尺寸，每个框盖住图上和它在画布上盖住的同一部分。没有图时它是
  画布尺寸，盖住的像素与 `bboxes` 相同。没有框时全是 0。
- `background` 上有图时，节点上的画布就是那张图自己的尺寸，所以方向键移动框一个
  图的像素。`width` 和 `height` 仍然设定 `bboxes` 按哪个像素计、以及 `preview` 的
  尺寸。
- `background` 来自 Load Image（直连或经过 Reroute）时，图在运行之前就显示。经过
  一个先改变图的节点，比如一次缩放，它会在运行之后显示。
- 运行之前，画布只能认得它能从来源节点读到的那种接线尺寸：Latent 尺寸、整数 或一个
  Primitive。来自其他任何节点时，画布保持自己的尺寸直到运行，然后显示那次运行
  用的尺寸。不管哪种情况，框都保持它在到达的那个尺寸上的位置。
- 和 Create Bounding Boxes 一样，它是输出节点：即使它的输出什么都没接，它也会随
  工作流运行，这样 `bboxes` 线上的新框才能到达画布。
- 背景会缩小后存到 ComfyUI 的临时文件夹里，供节点的界面显示。除此之外不写任何
  东西。
