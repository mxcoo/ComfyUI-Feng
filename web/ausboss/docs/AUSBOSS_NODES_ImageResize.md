# 图像缩放

缩放图像。新尺寸可以按这几种方式设定：精确的宽度和高度、最长边或最短边、
百万像素预算，或者一个倍数。遮罩可以一起接进来，用同样的方式缩放，
新的宽度和高度以数字输出，可以继续往后面的节点连。

新建的节点默认是**百万像素**、1 MP，**保持比例**为 fit，
**整除倍数**为 1，插值用 lanczos。

## 目标模式

**目标模式**（`target_mode`）决定用哪种方式。卡片上只显示当前模式的那一行尺寸，
其余的尺寸值一律忽略。

- **宽度 × 高度**（`width+height`）：两个**尺寸**字段，W 和 H
  （`width`、`height`）。它们的输入插槽和节点的其他输入排在一起，
  在 `image` 和 `mask` 下面；接了连线的那一个，字段会变灰。`0` 表示保留该边的
  原尺寸，只填一个时另一边按原图比例跟着算。
- **最长边** / **最短边**（`longest_edge`、`shortest_edge`）：
  缩放到该边正好等于**边长**（`edge_length`）；另一边保持比例。`0` 表示保持原尺寸。
- **百万像素**（`megapixels`）：按比例缩放，直到宽 × 高约为
  **预算**（`megapixels`）指定的百万像素数。`0` 表示保持原尺寸。
- **缩放倍数**（`scale_factor`）：两个方向都乘以**缩放倍数**
  —— `0.5` 减半，`2.0` 加倍。`0` 表示保持原尺寸。

## 保持比例

**保持比例**（`keep_proportion`）决定目标比例与原图不一致时怎么处理。
只在**宽度 × 高度**模式下有用：其他模式里，无论**保持比例**选什么，
画面都保持原有形状。

- **stretch**：直接拉伸到目标尺寸，画面会变形。
- **fit**：把目标框缩到原图的比例 —— 输出可能比要求的尺寸小，
  但绝不会出现黑边，也不会裁掉内容。
- **cover**（`cover_crop`）：完全填满目标区域，溢出的部分居中裁剪。
- **pad**：完整放入目标区域，剩下的部分用**填充颜色**
  （`fill_color`：十六进制、`R, G, B`、一个灰度数值，或 CSS 颜色名；
  节点读不出的颜色会变成中灰）填满。新加的边在遮罩输出里是 `1.0`
  —— 与包内其他扩边节点相同的“生成区域”约定，可以直接接给局部重绘节点。

## 说明

- **整除倍数**（`divisible_by`）把每个输出尺寸吸附到最近的整数倍
  （不会小于一档）—— WAN 用 `16`，多数 Latent 空间用 `8`。它优先于精确比例，
  所以某一维可能偏移最多半档。即使其他设置都说“保持原尺寸”，它照样生效。
- **只有在宽度 × 高度模式、保持比例选 pad、且 W 和 H 都填了时才会出现边。**
  其他目标模式下，目标框都由原图自身的比例推出来，没有可比对的信箱框：
  按比例的模式用一个不可见的、小于半档的缩放来落实 `divisible_by` 的吸附，
  遮罩输出保持全黑。宽度 × 高度模式里某一项填 `0`，也一样跟随原图，
  扩边不会给它加边。两项都填时，画面没有覆盖到的地方由边（在遮罩里是白色）填满。
  这包括舍入留下的一两个像素宽的窄边，例如 1000×700 的图、W 1000、H 700、
  **整除倍数** 16，结果是 1008×704，带一条 2 px 的边。
- **插值**（`interpolation`）：`lanczos`（PIL 实现，浮点计算 —— 最锐利的全能选项）、
  `bicubic`、`bilinear`、`nearest`（像素画、硬边遮罩）、
  `area`（大幅缩小时最好）。什么都不变的缩放会把张量原样透传，逐位一致。
- 遮罩输出是输入遮罩经过同一变换、再加上扩出的边。没有接遮罩时是黑色的，
  只有扩出的边是白色。IMAGE 是 BHWC，MASK 是 BHW，批次逐帧流过。

## 输出

- **图像**：缩放后的图像。
- **遮罩**：按同样方式缩放后的遮罩。
- **宽度** / **高度**：新的像素尺寸。
