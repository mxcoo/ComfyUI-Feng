# 编辑锁还原 🆎

把编辑没有改动的每一部分，都换回你自己图片上的像素。

**编辑锁 🆎** 在图片生成时把没动过的部分留在原位。这些部分照样要过一遍
VAE，细部因此会稍微柔化一点。这个节点把这些部分换回你自己的原始像素，
让它们与你的图片逐像素一致。也就是说，只有编辑的部分是新的，其余部分
和你的原始图片一模一样。

## 快速上手

1. 把它加在 VAE Decode 之后、任何放大节点之前。
2. 把解码后的图片接到 `image`。
3. 把编辑锁 🆎 的 `edit_lock` 输出接到 `edit_lock`。
4. 把 `report` 接到 **显示文本 🆎**，读一读保住了什么。

## 控件

- **image**：编辑后的图片，直接来自 VAE Decode。
- **edit_lock**：来自编辑锁 🆎。它带着你的原始图片，以及编辑改动了哪里的
  地图，所以不需要再接别的。
- **羽化**（`feather`）：你的原图融进编辑部分有多柔和，按像素计。默认值 16。
  过渡落在编辑区域之外，
  所以编辑本身永远不会和旧图混在一起。

## 输出

- **image**：编辑后的图片，没动过的部分是原始像素。
- **edit_mask**：编辑改动画面之处为白色。可以用它看清
  锁做出的是什么判断，或者把它交给后面只该碰编辑部分
  的步骤。
- **report**：一行文字，例如 "编辑锁保留了你图片 82% 的原样，
  把 18% 留给了编辑"。

## 什么都没锁住的时候

图片原样通过，遮罩全白，report 会说明原因：编辑改动了
整张图片、锁当时是关着的，或者图片和结果的尺寸
不一样。

## 技术细节

改动地图是在采样时按 Latent 网格生成的。这里，它被放大到图片的尺寸，
按羽化量加宽、再做同样程度的模糊，然后用它把解码后的图片和你的原图
混合。如果解码后的图片不是你原图的尺寸（也就是经过了放大之后），
会先把原图缩放过去再混合，原图因此损失一点锐度。
这也是为什么这个节点要放在放大节点
之前。
