# 数学表达式 🆎

对最多三个数做运算。写一个用到 `a`、`b`、`c` 的公式，得到小数和整数两种结果。可用来算宽高之和、强度渐变和帧数。

## 控件

- **f(a, b, c)**（`expression`）：要计算的算式。允许：数字，名字 `a`/`b`/`c`，运算符 `+ - * / // % **`，括号，一元负号，以及函数 `min`、`max`、`abs`、`round`、`floor`、`ceil`、`sqrt`。示例：`a * 2`、`floor(a / 64) * 64`、`min(a, b) + 0.5`、`sqrt(a*a + b*b)`。新建的节点默认是 `a + b`。`min` 和 `max` 接受两个以上的值，`round(a, 2)` 保留两位小数。
- **a**、**b**、**c**：表达式读入的值，作为节点左边缘的三个插槽，接受 `FLOAT` 或 `INT`。没接线的读作 `0`，没用到的也不产生开销；常量直接写在表达式里（`a * 2`、`floor(a / 64) * 64`）。

## 输出

- **float**：结果的小数值。
- **int**：结果四舍五入到最近的整数；正好一半时远离零取整（`2.5` 变成 `3`，`-2.5` 变成 `-3`）。表达式里的 `round()` 不一样：正好一半时取最近的偶数，所以 `round(2.5)` 是 `2`。

## 安全

表达式用 Python 的 `ast` 模块解析，再按白名单遍历 —— 从不交给 `eval`。上面语法之外的内容（其他名字、属性访问、下标、字符串、比较）会让运行停下，并指出该删掉什么，所以别人分享的工作流没法借这个节点夹带代码。除零和结果溢出是明确的报错，而不是崩溃或让 `inf` 流到下游。负数开平方和空表达式同样如此。表达式最长 4096 个字符。
