# 运行计时器 🆎

整个运行的秒表，画成一块没有标题栏、没有连线的黑色读数：它监听队列。

- 排队的提示词开始执行时开始计时，运行期间一直走 —— 琥珀色圆点。
- 运行结束时总时间定格 —— 青色圆点。失败或被中断的运行用红色显示时间，且不作为参考记录。
- 最近五次完成的运行随工作流保存，所以别人打开分享的图时，看到的是作者的时间。框里显示最新一次；右键节点可看其余的。右键 → *Reset Run Timer history* 可清空。

节点本身就是这块框，在经典画布上由节点自己绘制：任意位置都能拖动，拖角可调整大小（数字随之缩放），它没有标题栏，也没有插件包徽标。右键列出最近几次运行。打开 Nodes 2.0 后，框的高度固定，数字大小也不变。

## 说明与限制

- 它测的是*队列*的执行时间，从 `execution_start` 到运行结束，用浏览器的时钟。模型加载计入；排在别的提示词后面等待的时间不计。
- 同一张画布上的多个运行计时器都显示同一个运行。
- 点选取遮罩 🆎 会用一次小的独立运行来看新图，所以还没点，选项就先亮起来。这些查看不计时：读数保留你上一次运行工作流的时间。
- 每个节点各自的耗时是另一个功能：**Settings → 🆎 AusBoss → Chrome → Node runtime badges** 会给每个节点标上它自己的秒数。
- 想停下时听个声音？**Settings → 🆎 AusBoss → Notifications → Completion sound** 会在队列清空时响一声。
