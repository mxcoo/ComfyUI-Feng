# 对齐图像 🆎

把图像的宽度和高度对齐到你指定数字的整倍数 —— 8、16、32、64，下游模型要什么就用什么。Qwen 图像模型、VAE 和不少采样器在能整除的尺寸上表现最好（甚至只能在这种尺寸下工作）；有了这个节点，任何输入都能变成合法尺寸，不用手敲分辨率。

## 控件

- **image**：要对齐的 BHWC 批次；每一帧都按同样的方式处理。
- **倍数**（`multiple`，初始为 `16`）：输出的两边都能被这个数整除。`16` 或 `32` 适合大多数扩散模型；Latent 节点一般至少要 `8`。
- **模式**（`mode`）：怎么凑到这个倍数。每种模式自带取整方向，所以没有单独的取整控件：
  - **resize** —— 缩放到*最近*的倍数。会轻微拉伸，但每个像素的内容都保留。默认值。
  - **crop** —— 裁*到*下一个倍数。不产生形变；会在**裁切位置**说的地方切掉几个边缘像素。
  - **pad** —— 扩边*到*下一个倍数。不产生形变；新像素落在**扩边位置**说的地方，并按**扩边填充**填充。
- **裁切位置**（`crop_position`）：仅 crop 模式 —— 画面的哪一部分保留。`center` 两边均匀裁；`top`、`bottom`、`left`、`right` 固定那一侧、裁掉对面一侧。resize 和 pad 模式忽略它。
- **扩边位置**（`pad_position`）：仅 pad 模式 —— 图像落在扩大后画布的哪个位置；新像素落在对面一侧。`center` 把新像素均分。取值与 `crop_position` 相同。
- **扩边填充**（`pad_fill`）：仅 pad 模式 —— 新区域填什么。`replicate` 把边缘像素往外拉伸；`color` 用**扩边颜色**填成纯色。
- **扩边颜色**（`pad_color`，初始为黑色）：纯色填充，仅在**扩边填充**为 `color` 时显示。可以写十六进制、`R,G,B` 数值或 CSS 颜色名；节点读不出的颜色会变成中灰。

这两行 **裁切位置 / 扩边位置**，以及 **扩边填充** 和 **扩边颜色**，只在用到它们的模式下显示。

某一侧本来就小于一个倍数时，任何模式都裁不出合法尺寸，于是每种模式都会把它放大到恰好一个倍数（crop 模式下缺的部分按 `replicate` 均匀补齐，不管**裁切位置**怎么设）。

## 输出

- **image**：对齐后的批次。
- **width** / **height**：新尺寸，以 INT 输出 —— 接到空 Latent、缩放或条件节点上，数字就不会和实际图像脱节。

## 说明

每侧最多增加或减少 `multiple - 1` 个像素，所以在正常分辨率下取 16 或 32 几乎看不出来。批次保持帧数不变；取值仍在 `[0, 1]` 内。
