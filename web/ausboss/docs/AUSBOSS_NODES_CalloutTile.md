# 标注图块 🆎

工作流用的一枚紧凑标题，或一枚彩色链接按钮。从它的菜单里选 **Title tile**、**Set YouTube link tile** 或 **Set Discord link tile**。按 **Edit** 改它的文字或链接；标题也可以双击。拖动它露出的角可以调整大小。

它用和 [标注便签](AUSBOSS_NODES_Callout.md) 相同的文字、箭头和链接。**Plain callout** 回到普通便签的样子。它不运行，也没有输出。

图块以自己的节点类型保存。如果 ComfyUI 报告找不到这个节点，安装或更新 **ComfyUI-AusBoss**，重启 ComfyUI，再重新加载工作流。旧版本的包画不出正确的图块。请保留这个缺失的节点，它的文字和设置才会保住。
