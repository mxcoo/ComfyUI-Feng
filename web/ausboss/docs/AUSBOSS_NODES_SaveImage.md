# 保存图像 🆎

把一个 `IMAGE` 批次保存为 **PNG**、**无损 WebP** 或 **无损 JPEG XL**，
可以嵌入工作流，也可以刻意不嵌。名字要么在节点上用前缀加上你打开的标记组合出来，
要么由 `filename` 输入精确给出，这样一次加字幕或改写不必丢掉源文件名。`caption_text`
输入上的字幕会写出配对的 `.txt`。

## 卡片

- **文件夹**（`output_dir`）：留空保存到 ComfyUI 的 output 文件夹；填写形如
  `sets/portraits` 的名字就保存到该子文件夹，不存在则创建。保存图像从不写到 output
  文件夹之外：绝对路径、盘符、`~` 和 `..` 在运行前就被拒绝，路径预览在你按下回车或
  点击别处后就会说明这一点。**浏览** 会走遍 output 文件夹的子文件夹。
- **文件名**（`filename_prefix`）：本地名字，允许子文件夹
  （`sets/shot`）。当 `filename` 输入已接线时，该字段显示
  `{{filename}}` 并带一个小的*已接线*标记，下面的标记随即变灰、不可点击
  —— 精确名字永远不会被装饰。
  用旧的 `exact_name` 保存的工作流会显示那个名字并标为*精确*；
  清掉它就在本地组合。
  **名字标记** 在这里与 ComfyUI 自带的 Save Image 节点一样工作：
  `%date:yyyy-MM-dd%` 是今天的日期，`%KSampler.seed%` 是另一个节点的一项设置
  （它的标题或类型、一个点、设置的名称），`%width%` 和 `%height%` 是画面尺寸。
  标记也可以指代文件夹：`%date:yyyy-MM-dd%/shot`。清单见下面「名字标记」。
- **路径预览**：这次保存将产生的名字，按标记追加的顺序：
  `prefix[_YYYY-MM-DD][_HH-mm-ss][_WIDTHxHEIGHT][_#####][_b###]`。
  运行之后它显示实际写出的第一个文件。
- **标记**：**计数**（`name_counter`，默认开）为该文件夹里该主干名追加下一个
  空闲的五位数字，这样保存绝不撞名。**日期** 与 **时间**（`name_date`、`name_time`）
  打上本地时钟。**尺寸**（`name_size`）追加 `1024x1536`。**批次 #**
  （`name_batch`）在图像批次上追加 `b001, b002...`，该批次于是共用一个计数；
  不打开时每一帧各取下一个数字。关闭计数时，单张图像会复用同一路径并替换文件——
  正是数据集替换的场景——而批次仍然给自己的帧编号。
- **格式**：**PNG** 处处可存并保留 alpha。**WebP**
  （`webp lossless`）通常比 PNG 小，保留 alpha，并把工作流写进 EXIF。
  **JXL**（`jxl lossless`，无损 JPEG XL）最紧凑；它需要 ComfyUI 的 python 里有可选的
  `pillow-jxl-plugin`（也是本包的 `jxl` extra），而且很少浏览器能预览。
- **嵌入工作流**（`save_metadata`）：**开** 会把提示词与工作流存进文件
  （PNG 文本块，webp 与 jxl 用 EXIF），这样它能拖回 ComfyUI；**关** 写出干净的文件
  用于分享或数据集。服务器上带 `--disable-metadata` 启动时以它为准。
- **预览**（`preview`）：卡片下方的小开关把保存的图像显示在节点上。关闭时图像框消失，
  节点变矮；再打开，节点回到原来高度并显示最后保存的图像。它只影响显示：文件照样
  保存，队列也照样列出。一次运行保存多张图像时（一个批次，或一个列表，例如某个
  文件夹里的图像），它们会并排全部显示。开关旁的箭头（‹ 全部 5 ›）可以逐个单独查看
  （‹ 2 / 5 ›）再转回全部。一次运行超过 48 张时只逐个显示。
- **自动保存**（`autosave`，默认开）：开启时每次运行都保存它的图像。关闭时运行只在这里
  显示它们、什么都不存。此时图像上会浮出一个 **SAVE** 按钮：**SAVE ALL** 保留这次运行的
  每一张，而在箭头停在某一图上时 **SAVE** 只保留那一张。用它先做一批、看看，然后只留好的。
  图像按上面设定的名字与文件夹、选定的格式保存，**嵌入工作流** 开启时工作流也在里面。
  它们先候在 ComfyUI 的临时文件夹里，ComfyUI 重启时该文件夹被清空，所以想要的要在
  那之前存好。
- **预览步**（`step_preview`，默认关）：**预览** 左边的开关会在图像生成过程中逐步显示它，
  位置就是保存图像所在处，条上带一个 **STOP** 按钮。与其等到结束，不如在发现跑偏的头几步
  就停掉一次运行；被停掉的运行什么都不保存，并在画面上说明。图像保存后会替换掉这些步骤。
  有多个采样器时，节点显示向它供流的那个。分块放大期间它保留整幅画面并显示
  「upscaling in tiles」而不是逐块显示。仅影响显示：开或关，保存出来的文件都一样。
  细节见 [分步预览](AUSBOSS_NODES_StepPreview.md) 页面。

## 输入

- **filename**（STRING，仅接线）：来自上游的精确名字——一个 Load Image 的名字、一个字幕
  工具的 id。它的图像扩展名会换成所选格式的（`photo123.jpg` -> `photo123.png`）；
  一个批次会追加 `_001`、`_002`……接线但取值为空时中止运行，而不是用一个编出来的名字保存。
- **caption_text**（STRING，仅接线）：与每张图像同名的 UTF-8 `.txt` 存在旁边
  （`portrait.png` -> `portrait.txt`）。为空则不写附属文件。旧的 `caption` 框
  在下面仍然可用；已接线的字幕优先。

在节点上手输的名字里，带根路径和 `..` 会在运行前被拒绝。通过 `filename` 连线进来的
坏名字会让运行在这个节点中止，任何文件都不会被写出。旧工作流的 `on_existing`
凡是在保存可能落到已有文件上的地方（关闭计数、精确名字或接线名字）仍然有效。

## 名字标记

在 **文件名** 字段里输入这些。路径预览会显示它们将变成什么，唯独尺寸只有运行才知道。

| 标记 | 结果 |
|---|---|
| `%date:yyyy-MM-dd%` | 按你给出的格式表示的日期与时间：`yyyy` 年、`MM` 月、`dd` 日、`hh` 时、`mm` 分、`ss` 秒。 |
| `%KSampler.seed%` | 另一个节点的一项设置：节点的标题或类型、一个点，然后是设置的名称。 |
| `%width%`、`%height%` | 画面的像素尺寸。 |
| `%year%`、`%month%`、`%day%` | 保存时的日期。 |
| `%hour%`、`%minute%`、`%second%` | 保存时的时刻。 |

- 日期与另一个节点的设置在按下 运行 时由浏览器填写。直接通过 API 发送的运行只能得到
  尺寸与时间标记，与 ComfyUI 自带的 Save Image 节点相同。
- 通过 `filename` 输入进来的名字是另一个节点的精确名字，不会被解析标记。
- 百分号之间的其他文字按输入原样保留。

## 输出

- **file_path**：本次运行保存的第一个文件的绝对路径（每个文件都被跳过时为空），
  供那些需要文件本身的下游节点使用。
- **images**：输入批次，原样输出——先保存，再继续接线。

节点在 队列 时总是重新运行（保存器的职责就是那个副作用，所以删掉文件再排队会再存一次），
而用 `--disable-metadata` 启动的服务器会覆盖元数据开关——所有者的设定胜过控件。
