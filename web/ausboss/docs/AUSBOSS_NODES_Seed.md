# 种子 🆎

一个种子单独走一条 `INT` 连线，这样每个该共享它的采样器都共享到，
而共享的工作流也能钉住生成它那张示例图的确切种子。
卡片就是整张脸：数字、模式，以及一次运行需要的按钮。

## 卡片

- **数字** —— 点击可输入种子；**⧉** 复制它。在随机模式下标签显示 *next*：
  那就是下一次队列会用的种子。
- **随机 / 固定 / 步进 +1** —— 每次队列之后发生什么。随机掷一个新种子，固定保持不变，
  步进 +1 递增（再点一次变成 **步进 −1**，即递减）。这就是采样器自己的*生成后控制*，
  只是搬到了明面上。切到随机也会立刻掷一个新种子，而从固定切到步进会先走第一步，
  这样下一次队列绝不会重复你刚看到的那次运行（ComfyUI 会把缓存的结果还回来）。
- **新种子** —— 掷一个全新种子并钉住它（固定），接下来的运行都用它。
- **用上次运行** —— 把最近一次运行的种子放回框里并钉住。随机模式在运行入队的那一刻
  就更换了种子，所以当图像还在渲染时，框里的数字已经是*下一个*了；这个按钮就是你取回
  生成它的那个种子的办法。
- **▾** —— 本节点用过的最近八个种子，最新的在前；任选一个以同样的方式恢复。
- 下面那一行显示上次运行的种子。历史随工作流一起保存。

## 紧凑外观

数字旁边的 **齿轮** 选择外观。**紧凑** 是一行短的：数字、一个模式芯片和一个骰子。
点芯片按 随机 → 固定 → +1 → −1 循环。骰子掷一个新种子并钉住它。过长的种子会缩小显示。
把指针悬在数字上可以看到上次运行的种子。外观保存在节点上，新建的种子节点会以你
上次选择的外观开始。**完整** 会把整张卡片带回来，连同它用过的种子。

## 输出

- **seed**：种子，原样输出。

## 说明与限制

- 上次运行的种子来自后端自己的那次运行，所以即使控制模式是*生成前*而不是生成后，
  即使节点的输出来自缓存，它也是对的。
- 采样器种子最大到 2⁶⁴−1；框接受这个范围。按钮掷出的种子保持在 2⁵⁰ 以下，
  与 ComfyUI 自带随机化使用的上限相同，这样数字保持精确。
- 把取值接到 **seed** 行，框会变成只读：由连线说了算。
