# 点选取遮罩

在图片上点一下某个东西，就得到它的遮罩。不用输入名字，也不用 MaskEditor：图片就在节点上。

凡是工作流需要某个你能指出来的东西的遮罩时都可以用它：修改它、去掉它、把它抠出来，或者保留其余一切。

## 用法

1. 把图片接到 **image**。
2. 从加载 SAM 3 文件（`sam3.1_multiplex_fp16.safetensors`）的 Load Checkpoint 接出 **model** 和 **clip**。
3. 把指针移到节点上的图片上。点击会选中的东西会亮起，名字显示在指针旁边。点击即可选中它。
4. 继续点击其他东西，把它们加进来。

以青色亮起的部分就是遮罩将来的样子。满意后按 Run 运行整个工作流。

指针第一次停在图片上时，节点会去看这张图。图片下方的按钮显示进行到哪一步，**❚❚ Pause · looking 40/104**，随着进行逐渐填满。几秒后第一批东西亮起，大约 20 秒后它已经看过整张图。

你不必等它看完。指针下亮起的任何东西都能选中：点击会立刻取用它，节点还在看的时候也一样。

需要的东西已经亮起时，点击那个按钮可以暂停查看：已亮起的保持不变，你继续挑选和涂抹。它变成 **▶ Look on**；点击它从停下的地方继续看。在还没有东西亮起的位置点一下，也会继续看。

在还没有东西亮起的位置点击不会白点：一个点标出它，图片下方那行显示 **your click is in**，等节点在那里找到东西后就取用它。同一时间只有一个点击在等待；在没亮起的位置再点不会被接受，直到它被处理。

节点确信名字时，东西带着名字亮起。不确定时，东西照样亮起、照样可以选中，只是没有名字。

## 选错东西的时候

一次点击可能意味着不止一个东西：夹克，或者穿着它的人。节点取最可能的那个，并用两个箭头显示它的名字，例如 **‹ jacket · 1 of 3 ›**。按箭头可以在该处切换成下一个东西。

- 在一个东西上划过一笔也行，会取那一笔所在的东西。一笔跨过两个东西，比如两只鞋，就两个都取。
- 东西根本没有亮起？把它的名字输入图片下方的输入框，例如 "screen" 或 "earring"，然后按 Enter。
- 遮罩里混进了不该有的东西，比如你选中的人的脸或头发？点击那个输入框前面的 **+**，让它显示 **−**，输入 "face" 并按 Enter。或者按住 Ctrl 点击脸。
- 什么都不合适时，切到 **Paint** 自己涂。

## 整个主体，或者背景

图片下方，**Subject** 一次点击就选中图片的主要主体：人、动物、商品。**Background** 选中其余一切。它们和别的选择一样：继续点击其他东西可以加进来，Ctrl 点击某个东西可以把它再拿掉。

Ctrl 点击会拿掉指针下的东西，按它在遮罩里的位置。在没有选中任何东西的位置上它什么也不改，图片会说明这一点。

两者都需要 ComfyUI 的背景去除模型，见下文"细边缘用的模型"。

## 用画笔修遮罩

图片上方的开关有三个工具：

- **Pick**（键 **W**）取整个东西：点一下，或者在一个东西上划一笔。
- **Paint**（键 **B**）加入遮罩，完全照你涂的形状。
- **Erase**（键 **E**）擦掉遮罩，完全照你涂的形状。

这些字母是 Photoshop 的，指针在节点上时有效。

按住 **Ctrl**，或使用鼠标右键，可以在按住期间做相反的事：涂的时候擦，擦的时候涂。在 Pick 下，Ctrl 点击会把东西再拿掉。

画笔：

- **Size** 是它的宽度，单位是图片的像素。**Soft** 是边缘的柔和程度，对 Paint 和 Erase 有效：0 是硬边，100 从中心一路渐隐到底。在任一数字上拖动，或在它的名字上拖动，都能改。
- **[** 和 **]** 让它变小和变大。**Shift + [** 和 **Shift + ]** 让边缘更柔和与更硬。
- 在图片上按住 **Alt** 和**鼠标右键**再拖动：左右改大小，上下改边缘（向上更柔和）。虚线圆环是它实心中心的结束处。在 Mac 上，按住 Control 和 Option 拖动。图像比较 A/B 的画笔也是同样的用法。
- 指针下的画笔按它将要涂出来的样子显示：加的地方是青色，擦的地方是珊瑚色，中心实心，边缘柔和处渐隐。

## 图片下方的标签

每个区域在图片下方都有一个标签：你选中的一个东西，以它的名字，或者你涂出的一个区域。

- 与某个区域相连的涂抹会并入它的标签。没有碰到任何东西的涂抹会并入 **paint** 标签，不管涂了几笔。
- 擦除从不会产生标签：它只是擦掉现有的东西。在没选中东西的地方擦除什么也不做。
- 被你拿掉的东西（Ctrl 点击你选中的人的脸）会得到一个暖色的标签。它的**叉**可以把东西找回来。再点一次那个东西也一样。
- Ctrl 点击你选中的东西，可以把它连同标签一起拿掉。
- **点击一个标签**可以选中它：之后你涂的内容都会并入那个标签，无论涂在哪里。标签上方的箭头可以在同一位置的其他东西之间切换。再次点击它，或按 **Esc**，可以放开。
- **+ new** 开始一个自己的区域：接下来涂的内容会得到一个新标签，即使它碰到了另一个区域也一样。
- 标签上的**叉**会拿掉那个区域，连同涂在它上面的内容。
- 标签上的 **all 3** 会取该名字的每一个东西，而不是你点的那一个：全部五只鸟、两只鞋。
- 末尾的输入框会取你输入的那个名字对应的每一个东西。它前面的符号表示这个名字是加还是减：**+** 加入，**−** 拿掉。点击符号可以改变它。带减号输入的名字，例如 "-face"，无论符号显示什么都会被拿掉。选择 Erase 时，符号从 **−** 开始。

## 节点上的工具

- **Reload**（圆形箭头）显示现在进来的图片：见下文"选中的东西属于哪张图"。
- **Undo** 撤销上一次改动，或一次 Clear。Ctrl+Z 也行：那是 ComfyUI 自带的撤销，每一次改动都算一步。
- **Clear** 取消所有选择。
- **图片下方那行**说明选中了什么，以及它覆盖了图片的多少。
- **旁边的圆点**显示 Grow 和 Soften 在画笔点一下时给出的边缘。
- **眼睛**在 Undo 和 Clear 旁边，在你的选择和结果之间切换。关闭时，选中的区域在整张图片上被着色。打开时，其余一切被隐藏，你看到的就是将要输出的抠图。**Shift 点击**眼睛可以改看黑白遮罩；节点的右键菜单里也有同样的选项。
- **Esc** 丢弃你已经起笔的一笔。

## 设置

- **Grow**（`grow`）：越过选中区域边缘的像素数。小于零会收缩。0 保持精确轮廓。局部重绘通常需要几个像素。
- **Soften**（`soften`）：柔和边缘的像素数。0 保持硬边。它每步移动半个像素；按住 **Shift** 是十分之一。如果图片下方那行显示 **faint mask**，说明 Soften 比你选中的范围更宽：把它调小。
- **Fine edges**（`fine_edges`）：用于头发和毛发。打开时，图片主要主体的轮廓会被一缕一缕地跟随，抠图会去掉旧背景的颜色。关闭时保持 SAM 3 找到的边缘。它需要多一个模型文件，见下文"细边缘用的模型"。它处理新的选择时，图片角落显示 **Working on the fine details…**。
- **More → Smooth**（`smooth`）：按这么多像素把毛糙的轮廓修圆。
- **More → Fill small holes**（`fill_holes`）：封住选中区域内部的针孔。较大的开口保持敞开，比如马克杯的把手。默认关闭，所以你选的洞还是洞。
- **More → Invert**（`invert`）：把遮罩翻转过来。打开时，遮罩就是你选中内容之外的一切。
- **More → If nothing**（`if_nothing`）：**stop the run** 或 **empty mask**，见下文。
- **More → New picture**（`new_picture`）：**keep picks** 或 **start over**，用于换了另一张图片进来时。见下文"选中的东西属于哪张图"。
- **More → Free VRAM**（`free_vram`）：搜索一结束就把 SAM 3 从显卡内存里取出来，好让下一个模型有位置。在工作流里这个节点之后要加载大模型时打开它。

Grow、Soften、Smooth 和 Fill small holes 在你调整时会在图片上显示出来。着色始终保留你选中的形状；点击**眼睛**可以看到边缘最终的确切样子。

## 细边缘用的模型

Fine edges、**Subject** 和 **Background** 使用 ComfyUI 自带的背景去除模型（BiRefNet，约 445 MB，MIT 许可）。如果你用过 ComfyUI 的 Remove Background 模板，那你已经有了。

1. 从 Hugging Face 页面 `Comfy-Org/BiRefNet`（文件夹 `background_removal`）获取 `birefnet.safetensors`。
2. 把它放到 `ComfyUI/models/background_removal`。
3. 在 ComfyUI 里按 **R**，然后把 **Fine edges** 设为 **on**。

已经打开 Fine edges 的工作流会告诉 ComfyUI 它需要哪个文件，因此 ComfyUI 会把它列在 **Missing Models** 下并给出下载按钮。

值得知道：

- Fine edges 作用于主要主体的轮廓：人贴在墙上的头发、草地旁的狗毛，浅色和深色背景上都行。散乱发丝之间露出的背景也会去掉，头发深处也一样。
- 主体内部的边缘保持 SAM 3 找到的样子：头发贴着脸、脖子上的项链、手里的杯子。不属于主要主体的东西也一样。
- 边缘干净硬朗的东西，比如马克杯，出来还是原样。
- 主体上其他位于你的选择和背景之间的东西可能被带进来：耳机旁边的一缕头发、衬衫下的一条裙子。用 Ctrl 点击或 **Erase** 把它去掉，或对这一选择关掉 Fine edges。
- 你用画笔涂的内容保持你涂的精确形状。
- 它需要 ComfyUI 0.21 或更新版本。

## 什么都没选中时

默认情况下运行会在这里停下，给出一个简洁的提示，这样这个节点之后的任何东西都不会在空遮罩上运行。在节点的图片上点一个东西，或在上面画，然后重新运行。

把 **If nothing** 设为 **empty mask**，就可以用一个空遮罩让运行继续。

## 选中的东西属于哪张图

选择属于它们被做出来的那张图。当另一张图片进来时，**New picture**（在 More 下）决定它们会怎样：

- **Keep picks**（默认）：你的点击和涂抹会按相同位置移到新图片上。图片尺寸不同时，它们会被缩放以适配。点击会在那个位置找现在有什么；涂抹保持原样。按 **Clear** 从头开始。
- **Start over**：节点显示新图片，什么都没选中。如果在你重新选择之前工作流就运行，运行会中止并说明这些选择是在另一张图片上做的。新图片此时会显示在节点上，可以直接开始选。

- **重新加载按钮**（Undo 旁边的圆形箭头）显示现在进来的图片。在改动了这个节点之前的图片之后用它，例如做了一次编辑。它只运行这个节点和它之前的部分。

- 直接接入加载图像，或经由 Reroute 节点接入时，你一选好文件图片就会出现。
- 直接接入 **图像裁剪 + 旋转 + 扩边 🆎** 或 **加载图像 + 扩边 🆎** 时（途中的 Reroute 也算直接），它也会自己出现，在你选好文件或改变裁剪之后片刻。节点为此会运行加载器，所以你看到的是加载器交出来的图片，裁剪什么的都包含在内。刚打开的工作流显示的则是 **Show picture**：打开工作流不会启动任何东西。
- 前面接的是其他任何东西时，节点显示 **Show picture**：它得先运行前面的部分才能知道图片。
- 节点还在看上一张图时又选了另一张图，它会放开那次查看，从新图片开始。
- 重新打开的工作流会显示一次 **Show the picks**：按它，或运行工作流，你保存的选择就回来了。
- 如果图片来自采样器，把它的种子设为 **fixed**。每次运行都变化的种子会让每次点击都生成一张新图片。

## 输出

- **mask**：选中区域为白色。每张图一个遮罩。
- **cut_out**：除选中区域外全部透明的图片。保存为 PNG 才能保留透明部分。打开 **Fine edges** 时，半透明的像素（一缕头发）会带上那个东西自己的颜色，所以换到新背景上不会出现亮边或暗边。
- **names**：你选中的东西的名字，文本形式，例如 "sweater, cup"。把它接到提示词里，说明遮罩是什么。节点对名字不确定的东西会被省略，Subject 和 Background 也省略。

## 节点看图的时候

节点对每张新图片看一次，持续几秒，这样东西才能亮起来。指针停在图片上，或你第一次点击时，它开始。想让它不自己启动，打开 ComfyUI 的设置，**AusBoss → Mask by Touch → Look**，选择 **only on a click or the Look button**。此时来自本包某个加载器的图片还要等按下 **Show picture**。

节点被关掉时（被绕过或静音，手动或用工作流开关卡），它什么都不看。重新打开它，把指针移到它的图片区域上：这期间换过的图片会在那时被查看。

## 技术细节

### 如何询问 SAM 3

- 长边超过 2048 像素的图片会在长边为 2048 的副本上询问。SAM 3 反正都按 1008 像素读取每张图片，并在显卡上按给它的尺寸返回每个答案：在 8192 像素时，一个有很多匹配的词需要超过 27 GB。答案会被带回图片自己的尺寸，所以遮罩、抠图和你的点击都保持在图片的像素上。涂抹从不缩放。在一张 3840 像素的图片上、用五个词测得：新遮罩与旧遮罩的区域重合 95% 到 99.6%，边缘中位数相差 0 到 2 像素，一次查看用时 31 秒而不是 53 秒。
- 搜索用的是 ComfyUI 自带的 SAM 3：SAM3 Detect，按点询问，或按 CLIP Text Encode 读出的词询问。两者都用 ComfyUI 自己的设置（阈值 0.5，两次边缘遍历）。节点需要 ComfyUI 0.20 或更新版本，在旧版本上会说明这一点。
- 不是 SAM 3 的模型或文本读取器会失败，并给出一行说明该接什么。

### 随工作流保存的内容

**`touches`** 以 JSON 保存选中的内容，所以没有浏览器也能从 API 使用：

```json
{"v": 1, "key": "...", "items": [
  {"t": "tap",   "op": 1, "x": 160, "y": 1450},
  {"t": "name",  "op": 1, "w": "jacket", "x": 412, "y": 900},
  {"t": "all",   "op": 1, "w": "bird"},
  {"t": "subject", "op": 1},
  {"t": "find",  "op": 1, "r": 30, "pts": [[150, 1240], [230, 1010]]},
  {"t": "paint", "op": 0, "r": 45, "pts": [[640, 120], [760, 170]]}
]}
```

- `touches` 没有接线，下面的 `ask` 也没有：是节点的图片写入它们。从 API 使用时，把它们作为值发送。
- 一个 `paint` 触摸可以带 **`"s"`**，即画笔边缘当时有多柔和（1 到 100）；没有它时画笔是硬的。柔和的画笔会让遮罩边缘带有 0 到 1 之间的值。
- 一个添加性质的触摸可以带 **`"g"`**，即它在节点表面上所属标签的编号。节点自己不会读它。
- 坐标是图片的像素，`r` 是画笔半径，`op` 为 1 是添加，0 是拿掉。条目按顺序应用。最多 200 个条目和 20,000 个点。
- **`tap`**：SAM 3 在该点找到的东西。什么都没找到的点击什么都不改。
- **`name`**：该点上名为 `w` 的东西。SAM 3 会被询问该名字的每一个东西，最多 16 个（单独一个词只会返回一个）。在包含该点的那些里取最小的；一个都不包含时，这个触摸什么都不改。词里的逗号、冒号和括号会被去掉，并截到 60 个字符。
- 一个 `name` 触摸可以带 **`"q": 1`**：节点的图片没有显示那个词，因为 SAM 3 对它不确定。东西照样以同样的方式选中，它的词会从 `names` 输出里去掉。
- **`subject`** 和 **`background`**：背景去除模型眼中的图片主要主体（像素的半数或更多），或其余一切。没有点也没有词。**Fine edges** 关闭时，如果有 `birefnet.safetensors` 就问它，否则问文件夹里的第一个文件。
- **`all`**：图片中所有名为 `w` 的东西，合并成一个区域。询问 SAM 3 的方式与 `name` 相同，所以最多 16 个东西。没有叫这个名字的东西时，这个触摸什么都不改。
- **`find`**：一笔之下的东西。会两次询问 SAM 3：一次是沿这一笔分布的四个点，一次是两个点。取四点的答案，除非两点的答案小于它的一半且仍覆盖这一笔的大部分。短于图片长边 5% 的一笔只用两个点询问。答案中只保留下这一笔碰到的部分。空白处则使用这一笔自己的涂抹。
- **`paint`**：正是这一笔自己的区域。不问 SAM 3。
- **`key`** 指明这些选择是在哪张图片上做的：它的尺寸，以及每个像素的指纹。在另一张图片上做的选择会被移到进来的那张上，从它们 key 里的尺寸缩放到它的尺寸，并把移过来的触摸发送给界面。当 `new_picture` 设为 `start over` 时，它们会被忽略。
  手写 `touches` 时请省略 `key`。

### 区域如何整理

- SAM 3 返回的结果会去掉零散碎点：面积不到该区域像素 1% 的孤岛会被丢弃，除非它在点击处之下。
- SAM 3 在一个词下找到两次的东西（重合 80% 或更多的两个区域）只算一次。
- 边缘设置按这个顺序生效：填洞、平滑、细边缘（打开时）、生长或收缩、柔化。**Fill small holes** 只在洞的像素数最多为选中区域的 1% 时封住它，所以一个环还是环。

### 细边缘

- 模型是 ComfyUI 自带的背景去除模型，通过 ComfyUI 自己的节点（Load Background Removal Model、Remove Background）加载和询问，像工作流那样。不额外安装任何东西。一张图的主体只问一次并记住。
- 模型只认识主要主体。它分不清头发和脸，还会把一个女孩连同她手里的杯子一起取走。所以由 SAM 3 决定选中什么，模型只在选择的边缘就是主体自身轮廓的地方使用：沿边缘看，选择这一侧是主体（80% 或更多）而另一侧不是（25% 或更少）的地方。在那里，模型的柔和轮廓取代硬轮廓，最多到选择之外 68 像素、之内 40 像素（在以 1024 像素长为边的副本上，所以这个范围随图片放大），并在最后三分之一渐隐，因此不会停出一条线。在选择之外，只有与它相连的才算：一缕头发与头发相连，远处的碎点不算。
- 边缘的另一侧在不再次穿过选择的情况下读取。选择中狭窄的缝隙里，缝隙显示的就是另一侧：敞开外套前襟里的衬衫不会跟着外套进来。
- 主体上的选择内部，SAM 3 一并取来的背景，在选择这一侧大部分是主体（60% 或更多）的地方会被去掉：发丝之间的墙、头发旁的一小条墙。
- 整体上是主体（75% 或更多）且有实体（某处深于 12 像素）的一部分选择，算主体上的一个东西：头发、一个人、一件外套。对它另有两条规则。它的边缘很细的地方，比如卷发之间透出路灯，只要那段边缘有五分之一是主体且外面没有主体，发丝之间的背景就会去掉。它内部的一处背景小口袋，无论多深都会整个去掉——条件是这块口袋最多占图片的 0.6%：隔着头发看到的光。更大的、模型看不见的部分保持不动。手镯或链子没有实体，所以完全按选中的样子保留。
- 选中的背景会反向得到同样的轮廓，只沿轮廓进行。它内部实心的一块"主体"（深于 4 像素）会保留：在模型看来毛衣上的一朵花有一部分是主体，而它仍然是那朵花。
- 其余地方的边缘保持在 SAM 3 放的位置。涂抹保持原样。
- 如果结果会失去选中区域 40% 以上，它会被丢弃，区域保持原样。
- **Grow** 移动普通区域并覆盖在细边缘上：区域到新的线为止是实心的，比这更长的发丝仍然显示。小于零时它把细边缘切回到新的线。**Soften** 随后把整体模糊。
- 颜色：像素有一部分是那个东西的地方，两遍处理（一遍宽一遍窄）从它周围的像素和图片在该像素显示的内容，算出那个东西自己的颜色。**Grow** 让遮罩显示出的像素比东西覆盖的多时，颜色回到图片自己的。
- 打开 **Invert** 时，颜色是针对选择之外的一切算的。
- 节点的图片也会显示细边缘。每次改动后大约三分之一秒，节点会把它发送出去。
- 缺失的模型文件，或不是背景去除模型的文件，会让工作流的一次运行中止，并给出一行说明该怎么办。你在节点上点击时，会改为显示普通边缘，同一行提示也会显示。
- **Free VRAM** 也会卸载这个模型。

### 亮起来的东西

- 节点按这个顺序询问 SAM 3：指针下的位置、40 个日常词汇、图片上分布的 48 个点、64 个词，然后大约 350 个点（小图上更少）。
- 一次查看在一次运行里走完整个列表。运行期间它大约每 1.5 秒告诉节点的图片它找到了什么，所以东西一被找到就亮起。
- ComfyUI 队列里有别的任务在等时，一次查看会立刻结束，所以点击或运行从不等它：它会做完手头的问题，下一次查看从那里继续。实测：一个任务排在它后面之后，一次查看在 0.2 到 0.4 秒内结束。
- SAM 3 用词叫出的每个东西，是一个带该名字的片段，以及 SAM 3 对它的确定程度。两个词几乎指同一区域（重合 80% 或更多）时算一个片段，用 SAM 3 更确定的那个词。当命名的片段区域几乎相同时，点找到的结果会被丢弃。
- 来自点的片段，占图片不到 0.2% 或超过 90% 时不显示。命名的片段无论多小都保留。超过图片 90% 的片段，只有在 SAM 3 至少有 0.95 的确定度时才保留：问一百个没人输入的词时，它有时会把整幅人像叫成 "mirror"。你自己输入的名字不会因此被丢弃。
- 名字从 0.8 分起显示，占图片 30% 或更多的东西从 0.9 分起显示。低于这个分数时，东西亮起但没有名字。在 22 张图、1,137 个名字上测得：0.6 以下的名字有 43% 是错的，0.7 到 0.8 之间有 20%，0.8 以上有 4%。用了这条规则后，错误名字下的面积从一张图的 10.3% 降到 1.4%，正确名字下的从 66% 降到 61%。
- 最多 120 个片段。超过时，先去掉来自点的片段，最小的先去掉，然后是 SAM 3 最不确定的名字。
- 点击一个亮着的片段，返回的正是那个片段。命名的片段为此有自己的点：它内部最深处、且不在同名的更小东西里的位置。
- 在还没亮起的位置点击会等待查看，查看随即从这次点击开始。一旦它下面有命名的东西（整体的人和背景不算），或者列表里每个词都被问过，或者最迟 45 秒后，它就被取用。没有这个等待，它只能得到 SAM 3 在那一个点上找到的东西：点击夹克却得到整个人。同一时间只有一个点击在等待：多个点击会在查看完成时依次被取用，每个取它所在位置的下一个东西。
- 点击已经亮起的东西从不等候，无论节点对它的名字知道多少：亮起什么，点击就取什么。在该位置等待中的点击由它来回答。
- 在一台机器上测得（RTX 5090，约 1.5 兆像素的图片，显卡其余空闲）：前 40 个词在 5 到 9 秒内完成，整张图在 16 到 25 秒内完成，一次查看，72 到 120 个片段。小东西很多的图片最慢。

**第一批词：** person, face, hair, hand, shirt, t-shirt, tank top, jacket, coat, sweater, dress, skirt, pants, jeans, shorts, shoe, sneaker, hat, eyeglasses, bag, backpack, phone, cup, bottle, plate, food, chair, table, sofa, bed, pillow, lamp, plant, flower, car, dog, cat, window, door, sign.

**其余的词汇：** arm, leg, foot, eye, lips, eyebrow, beard, ear, neck, sleeve, shirt collar, fur collar, bag strap, scarf, glove, sock, boot, sandal, blouse, hoodie, vest, suit, bra, swimsuit, belt, necklace, earring, bracelet, watch, sunglasses, handbag, suitcase, headphones, laptop, television, screen, book, drinking glass, bowl, fork, spoon, knife, vase, teddy bear, toy, chandelier, neon sign, vending machine, mirror, curtain, rug, blanket, shelf, cabinet, desk, tree, bird, bicycle, motorcycle, truck, poster, sky, wall, floor.

SAM 3 有时会给正确的区域配错词（夹克也被叫作 "dress"）。所以才要把指同一区域的两个词并成一个片段。

### 一次查看是安静的

- 一次查看是没人按 Run 的运行，所以它不向 ComfyUI 的页面发送进度报告。没有这一点，一次查看会发送大约 1,000 条（SAM 3 在每个问题后都报告），进度条、标签页标题和节点轮廓会一直闪。
- 在一张图上测得：之前是 5 次运行、1,024 条 `progress` 和 1,036 条 `progress_state` 消息。现在是 1 次运行、没有 `progress` 和 4 条 `progress_state` 消息。那 4 条是 ComfyUI 在说加载图像和本节点已开始、已结束。
- 工作流的普通运行照常报告进度。查看结束时报告会重新打开，失败或被停止时也一样。
- 一次查找到的内容以事件 `ausboss.mask_by_touch.look` 传给请求这次查看的浏览器标签页。它带有节点的 id、运行结束时返回的同一段说明，以及 `end`——最后一条为 true。
- 在进度发送方式本节点不认识的 ComfyUI 上，查看仍然有效。只是不再安静。

### 记住的内容

- 答案按图片和模型记住，对所有点选取遮罩节点通用：一个点找到了什么、一笔找到了什么，以及一个词匹配到的一切。改变边缘设置或增加选择时，只就新内容询问 SAM 3。保留约 256 MB 的区域，最旧的先去掉。
- 文本读取器对一个词的解读也会记住。它对每张图都相同，所以每个词只读一次。
- 最近四张图的片段会被保留。

### 快速询问

- ComfyUI 的 SAM 3 节点在每次提问时读取整张图片，并且每次都检查模型是否已加载。本节点运行期间，图片只读一次，检查也只做一次。
- 使用前会先验证，点和词分别验证：第一次用某个模型运行时会用两种方式问同一个问题，只有两个答案逐像素相同时才继续这样用。如果某个问题以这种方式失败，就用普通方式重新询问，快速方式保持关闭。
- 在一台机器上测得：144 个点普通方式用了 22 秒，这种方式 1.9 秒。匹配不到任何东西的词用了 0.10 秒和 0.02 秒；只有一个匹配的词 0.18 和 0.07。144 个点中的 144 个、309 个词中的 309 个，遮罩完全相同。

### 其余

- 批次里有多张图时，同样的选择会向每一张询问，节点表面显示第一张。
- **Free VRAM** 会卸载 SAM 3 及其文本读取器，用的是 ComfyUI 自己的单模型卸载，且只在工作流运行之后。在节点上点击和悬停会让 SAM 3 保持加载，否则每次点击都要重新加载。
- **Invert**（`invert`）在边缘设置之后翻转遮罩：除你选中的之外处处为白。抠图跟随遮罩。什么都没选中时遮罩保持为空，如果 **If nothing** 这么说，运行仍会中止。批次里，没选中任何东西的图片保持它的空遮罩。
- **names** 是第三个输出：选中的东西的名字，文本形式，按选中的顺序，每个一次，例如 `jacket, hat`。只有 `name` 和 `all` 触摸有名字；没有名字的点击、笔画和涂抹什么都不加。当一个名字下选中的每个东西都以同一个名字被拿掉后，这个名字也会被去掉。批次时，它描述第一张图。
- **`ask`** 是节点自己的图片请求一次运行的方式：`scope` 查看图片（从上次查看停下的地方继续），`scope:x,y` 这样做并从指针下开始，`look` 只发送图片和已选中的内容。设置了 `ask` 时，运行不会因为选择为空而中止。它从不随工作流保存。
- 它是输出节点，所以它自己的图片可以单独运行它。因此即使它的输出什么都没接，它也会运行。
