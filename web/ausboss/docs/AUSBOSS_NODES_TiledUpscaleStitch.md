# 分块放大拼接

你的模型重绘完分块之后，把它们重新拼在一起，按你在 **分块放大 🆎** 里要求的尺寸给出成图。

把重绘后的分块接到 `tiles`，把分块放大给出的 `stitcher` 接到 `stitcher`。它要的就这些。

## 一次处理多张图

给分块放大一个图片列表，例如一个图像文件夹，拼接也会返回一个列表：每张图一张成图，顺序相同。它后面的节点，例如保存图像，每张图运行一次。不需要循环。

## 保留颜色

**保留颜色**（`keep_colors`）在分块拼合之前，把每个分块与你的图中同一位置的分块对齐。

- **1** 保留你的图的颜色。它还会让各分块彼此协调，所以不会有哪一块比旁边那块浅一档。
- 更低的值让模型自己的颜色透出来。
- **0** 关掉它。当要求模型改变颜色时用这个。

老照片里的颗粒和色彩噪点不会让它失准，褪色的照片回来还是褪色的。

## 技术细节

- 相邻分块在它们共有的条带上混合，从一块渐入另一块，所以接缝没有硬线。
- 回来时尺寸不同的分块会先被适配到它的位置。
- 分块上的透明通道会被丢弃：结果是普通 RGB。
- 分块可以一个接一个到达，也可以按同样顺序作为一个批次到达。分块数量与拼接器期望的不一致时，运行会中止并说明收到了多少个。
- 有图片列表时，分块放大对每张图运行一次，所以分块按图片顺序一个列表一个列表地到达，每张图对应一个拼接器。每个拼接器从列表前端取走自己那份数量的分块。
- 当图片被重绘得小于你要求的尺寸时（小图，见分块放大里的 Redraw limit），拼合后的重绘结果会按普通方式放大到那个尺寸。
- 保留颜色在小的平均副本上，把每个重绘分块与它自己的源分块比较，用各一条直线拟合亮度与两个颜色通道（LAB）。拟合跟随两张图共有的部分，所以源图里的噪点不会被当成颜色。在十一张带已知原图的噪点测试照片上，结果的颜色分布与原图的差距保持在 3% 以内；而去匹配分布本身（如 **颜色匹配 🆎** 对展示其他内容的参考图所做的那样）平均超出 47%。
