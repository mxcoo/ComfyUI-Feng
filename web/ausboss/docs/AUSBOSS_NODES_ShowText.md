# 显示文本 🆎

在节点本身上显示从连线到达的内容：一段提示词、一条 LLM 回复、一个
文件名、一个数字。把它接到你想在工作流运行时读取的任何东西上。

文本原样透传，所以这个节点可以待在连线的中间，而不是终点。

## 控件

- **text**：要显示的内容。它接受任何连线：文本、整数、带小数的数、
  开关值、列表。

## 输出

- **text**：被显示的文本。进来的文本原样传下去。数字以文本形式输出
  （`1024`），所以这个节点也能为需要文本的节点把数字变成文本。

## 面板

面板填满节点，所以把节点拖高就能一次读更多。文本可以在节点上直接
选中和复制，角落的 **⧉** 会复制全部；空白面板区域仍可拖动节点，
滚轮仍可缩放节点图。

最后显示的文本随工作流一起保存，所以重新加载的图会重新打开并显示
上一次的结果。很长的文本在显示中会被截断（并有一行说明）。输出连线
始终携带全部内容。

## 技术细节

- 列表或字典以 JSON 显示。
- 图片、遮罩或 Latent 按尺寸显示，例如
  `tensor 1 x 1024 x 768 x 3, float32`，因为它的数字会塞满面板。
  用 **图像尺寸 🆎** 把图片的宽和高取成数字。
- 发出值列表的节点会让 显示文本 每个值运行一次，面板为每个值显示
  一行。
- 其他任何东西按 Python 打印的样子显示。
- 节点不发起任何网络请求。
