# 加载图像

载入一张图，并在同一个节点里定好它的尺寸，工作流就不用在加载器后面再挂一个缩放节点和一个尺寸节点。

在 **来源** 里选一个文件，点 **载入** 上传一张，或用下面的箭头在 ComfyUI 的 input 目录里逐张翻。箭头旁边那行显示文件的尺寸，尺寸被改动时显示最终出来的尺寸：

`912 × 1632 → 1144 × 2048`

这是真实的输出尺寸，运行前就算好了。

那行下面是两张小图：进来的文件和出去的画面。第一张上留下的一块是亮的、被切掉的部分是暗的。两张中间，节点会标出形状（`3 : 4 → 1:1`）和实际发生了什么（`77% size`、`cuts 449 px of height`）。

## 尺寸

**尺寸**（`size`）决定这张图怎么缩放。每个选项只显示它自己用到的数字。

| 选项 | 做什么 | 用哪个数 |
|---|---|---|
| **off** | 图按文件原样输出。 | 不用 |
| **megapixels** | 把整张图缩到给定的总像素，形状不变。 | **百万像素**（`megapixels`）：1.0 约等于 1024 × 1024 |
| **longest side** | 定长边，另一条边跟着走。 | **最长边**（`longest_side`），单位为像素 |
| **scale** | 两条边同时乘。 | **缩放**（`scale`）：0.5 是一半，2 是两倍 |
| **fit inside** | 把图放进一个框里，尽量大且不切掉东西。 | **宽度** 与 **高度**（`width`、`height`） |
| **crop to fill** | 把框盖满，多出来的切掉。 | **宽度** 与 **高度** |
| **crop** | 从图里切出一块这么大的区域，不缩放。 | **宽度** 与 **高度** |
| **crop to ratio** | 从图里切出该形状（如 16:9）能取到的最大一块，不缩放。 | **宽高比**（`ratio`） |

**倍数**（`multiple`）把新的宽和高取整到这个数的倍数。多数模型要 8 或 16；填 1 就保持原数。尺寸为 off 时它不起作用。

## 留下哪一块

三个裁剪类选项会多出 **裁剪位置**（`crop_from`）。它决定保留图里的哪一块：`center` 两边平均切，`top` 留上面、从下面切，`bottom left` 留左下角，依此类推。

也可以直接点第一张小图：点它的上边就留上边，点角就留那个角。亮的区域会跟着走，能看出结果是哪一块。

**宽高比** 里的 `width : height` 用宽度和高度两个框里的数算出比例，应付列表里没有的形状（1600 和 900 就是 16:9）。

## 更多

- **方法**（`method`）：像素怎么重采样。`lanczos` 对照片最锐，`nearest` 能让像素画保持硬边。
- **允许放大**（`enlarge`）：打开时小图会被放大到你要的尺寸；关闭时只会缩小——本来就没达到目标的图按自己的尺寸出去，`crop to fill` 也只在它里面切出框的形状，不会先放大。

## 节点上的画面

设置下面那张图是 ComfyUI 自己的预览，和官方 Load Image 显示的是同一张。把文件拖到节点上、或粘贴一张，就能上传；右键节点可以打开遮罩编辑器、复制与粘贴。

## 输出

- `image`：新尺寸下的图。
- `mask`：图透出来的地方是白、实心的地方是黑，与官方加载器一致。没有透明区域的图给一张全黑的遮罩。尺寸永远和 `image` 相同。
- `width`、`height`：出来的尺寸。
- `filename`：文件名去掉目录和扩展名（`shots/hero.png` 给 `hero`），可以直接给保存节点的前缀用。
- `original_width`、`original_height`：缩放之前文件本身的尺寸。想把结果带回原来的大小就用它们。

## 用哪个加载器

- **加载图像**（本节点）：载入一张图并定尺寸。
- **Load Image + Pad**：在图的四周加空白，为扩图（outpaint）准备。
- **Image Crop + Rotate + Pad**：手动转、裁、扩。

## 技术细节

- 动图（逐帧文件）的每一帧都当作一个批次进来，全部用同一个新尺寸。手机照片按 EXIF 里的方向摆正。
- 尺寸为 off 时像素就是文件自己的，一位都不差，**倍数** 也不生效。
- 取整会把每条边挪到最近的倍数，形状最多差半档；`fit inside` 改为向下取整，结果永远不会超出那个框。
- `crop to fill` 先把图放大到盖住框，再按 **裁剪位置** 指定的那侧把框切出来。遮罩走同一套缩放和同一刀。
- `crop` 与 `crop to ratio` 只切不缩。比图还大的框会被裁到图能给的尺寸，**倍数** 向下取整让切出的一块留在图里；这两项不受 **允许放大** 影响。
- 两张小图画在同一个比例尺上，缩小一半的图就画成一半大。
- **允许放大** 关闭时，取整结果向下取，不会超过文件本身的尺寸。
- 节点上那行尺寸用的是和运行完全相同的算法；本包的测试用一张用例表把两边钉在同一组答案上。
- 文件只从 ComfyUI 的 input、output、temp 目录读取。`photo.png [output]` 这种名字读的是 ComfyUI 自己产出的图。
- 磁盘上的文件变了、或某个设置变了，节点会重新运行。
