# 局部重绘裁剪 🆎

把你遮罩住的那部分图，连周围一圈一起切出来，模型就只对这一块按完整细节重画，
而不是把整张图缩小了重画。配合 **局部重绘拼接 🆎** 用，它会把结果贴回原来
一丝不差的位置。**Extend** 那几行（`extend_*`）在图的一侧加出新空间，这对节点
就是这样做扩图的。

## 控件

- **image**：围绕遮罩裁剪的 BHWC 图像或视频帧。
- **mask**：白色标出要局部重绘的区域。多帧遮罩会并成一个裁剪窗口，所以整段视频
  共用一个拼接器；空遮罩选中整张图（并原样拼接回去）。图上没有画遮罩会以
  "No mask painted" 中止运行，并说明怎么画（这种情况下核心 Load Image 会送来
  一张小的空白替身）。遮罩与图尺寸不同也会中止运行，消息里给出两个尺寸。
- **上下文**（`context_factor`）：按这个倍数对称放大遮罩的包围盒。放大后的窗口
  会先被挪回画面之内。当它比图还大时，由**保持在图内**决定怎么办。
- **保持在图内**（`keep_inside`，默认打开）：让裁剪留在图内。上下文会越过某条边
  时（遮罩很大，或图很小），裁剪就停在那条边上，于是模型只看到真实的画面，
  而在**目标**重新缩放之后，它会把新加的部分画得更大更锐利。关闭是旧的行为：
  裁剪越过边缘，多出来的空间用边缘像素拉伸后填满。打开时有一个注意点：
  模型会看到你遮罩周围更多的东西并把它延续下去，所以要遮住遮罩边缘你不希望
  保留的残留。
- **混合**（`blend_pixels`）：羽化宽度，*只在贴回时*使用：粘贴遮罩按这么多像素
  加宽并模糊。送给局部重绘器的采样遮罩仍然保持硬边，所以羽化从不削弱模型
  看到的东西。`0` 用原始遮罩粘贴。
- **整除倍数**（`output_multiple`）：裁剪的尺寸向上取整到这个倍数。Qwen Image 2.1、
  Flux 和多数较新的模型保持 `32`（默认）。它们的 VAE 会把不是 16 或 32 倍数的
  图裁掉一点，而裁过的结果再拉伸回裁剪上，看起来会比原图稍大。发生这种情况时
  局部重绘拼接 会在控制台说明。
- **目标宽度 / 目标高度**（`target_width` / `target_height`，在 **Target size, extend**
  折叠区里）：把裁剪重新缩放到采样器要的固定尺寸。`0` 保持裁剪的原生尺寸；
  只设一个维度时，另一个由裁剪的宽高比推出来。这里显式给出的值优先于
  `target_megapixels`。裁剪被重新缩放时，裁剪区域会在一侧多纳入几个像素的上下文，
  好让它正好是目标尺寸的形状，而图在两个方向按同样的量缩放，从不拉伸。

### 塑造遮罩

- **扩展**（`mask_grow`）：把采样遮罩膨胀这么多像素（负数收缩），让局部重绘器
  画到画出的边缘之外。这改变的是被画的部分，和 `blend_pixels` 不同 —— 后者只
  羽化贴回。
- **模糊**（`mask_blur`）：柔化采样遮罩边缘的高斯 sigma，用于认可软遮罩的模型。
  `0` 保持硬边。
- **反转遮罩**（`invert_mask`）：重绘黑区而不是白区 —— 即画出的区域之外的一切。
  在扩展或模糊之前应用。

### 定裁剪尺寸

卡片上，**Target size, extend** 折叠区放着这几行，**目标宽度 / 目标高度** 和
**Extend** 那几行。

- **额外上下文**（`context_pixels`）：在 `context_factor` 放大之后，围绕遮罩框
  再加的固定像素上下文。
- **目标**（`target_megapixels`）：为采样器重新缩放裁剪，使其面积约为这么多百万
  像素 —— `1.0` 适合 SDXL 一档的模型，`0` 保持裁剪的原生尺寸。显式的
  `target_width`/`target_height` 优先。
- **重新缩放**（`rescale_algorithm`）：采样器来回两趟用的缩放滤镜。`bilinear` 是
  稳妥的默认值，`bicubic` 让放大稍微更锐利，`area` 适合大幅缩小，`nearest`
  从不发明像素。

### 扩图

- **向左扩 / 向右扩 / 向上扩 / 向下扩**（`extend_left` / `extend_right` /
  `extend_up` / `extend_down`）：把图本身在那一侧加宽这么多像素。新增的带用边缘
  像素拉伸填满，总是会被绘制（即使打开了**反转遮罩**），并成为拼接输出的一部分
  —— 什么都不画时，光这些扩出来的带就会被局部重绘。

## 输出

- **image**：裁剪出的区域，尺寸按采样器需要。
- **mask**：与之匹配的硬边采样遮罩（只有 `mask_blur` 说了软的地方才软）。
- **stitcher**：局部重绘拼接 把结果放回去所需要的一切。

## 接线

```text
Load Image ── Crop For Inpaint ── image ──> LaMa Inpaint ── image ──> Stitch Inpaint
                   │  └── mask ─────────────────┘                          │
                   └── stitcher ───────────────────────────────────────────┘
```

任何局部重绘采样器都能以同样的方式夹在这两个节点之间 —— 把裁剪的 `image` 和
`mask` 接到它上面，再把它的输出接到 局部重绘拼接 的 `inpainted` 输入。

带透明部分的图会成对地保留它们。ComfyUI 的 Load Image 把它们分到 `mask` 里；
把它的 `IMAGE` 和 `MASK` 接进 **Join Image with Alpha**，在裁剪之前把它们合回去。
采样器拿到的是颜色，局部重绘拼接 再把透明部分还给结果。

## 技术细节

- 起始值：上下文 `1.2`，混合 `16` px，整除倍数 `32`；扩展、模糊、额外上下文、
  目标那几行和 Extend 那几行都从 `0` 开始。
- 没有设目标尺寸时，裁剪仍会向上取整到**整除倍数**，所以在**保持在图内**打开时，
  它仍然可能越过边缘几个像素（最多 整除倍数 - 1）。
