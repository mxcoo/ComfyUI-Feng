# 标注便签 🆎

画布上的便签。写一两行，文字会自动撑满便签，别人不用放大就能看清。输入 ⬆️ 这样的箭头表情，指向你正在说的那一块。

用它来解释你分享的工作流里的某一步。它从不运行，也没有连线。

## 图块预设

右键点击标注便签，选 **Title tile**，现有文字就会带上一块黑色标题栏和一条青色装饰。**Set YouTube link tile** 和 **Set Discord link tile** 会填入 AusBoss 的链接和按钮文字。点击文字可打开链接，拖动图块可移动它。选 **Plain callout** 会带着当前文字回到标准样式。

- 在图块上按 **Edit** 打开更大的编辑器。链接图块的 **Button text** 和 **Link address** 是两个独立字段。已有的混合文字留在文本框中。
- 双击标题即可编辑。**Save** 或 `Ctrl+Enter` 保存改动；**Cancel** 或 `Esc` 保留原文。
- 拖动右下角可见的把手可调整大小。也可以聚焦把手后用方向键；按住 **Shift** 步长更细。调整大小时图块位置不变，且支持撤销。

## 书写

- 在普通便签上双击便签，或按 **Edit**，即可输入。点框外保存文字。**Esc** 丢弃刚输入的内容。
- 空行开始新的一条。每条旁边会有一条细青色线。
- 词两边加两个星号可强调：`**Resize is on.**`
- 补充细节时，把一行做成**小字**：光标放在该行，按文本框下方的 **Small**。它会以小字排在上一条下面，第一条仍然足够大，离远了也读得清。再按一次 **Small** 恢复常规。
- 以 `##` 开头的行与不以它开头的行一样处理，所以给核心 Markdown Note 写的便签可以直接粘进来。
- 拖角改变大小。文字会随之放大或缩小。

## 箭头

输入箭头，它会在行内变成青色箭头。

- 可以用箭头表情：⬆️ ⬇️ ⬅️ ➡️ ↗️ ↘️ ↙️ ↖️。手指 👆 👇 👈 👉 和普通箭头 ← ↑ → ↓ 也可以，`->` 和 `<-` 同样可以。
- 也可以在编辑时按文本框下方那一行箭头。
- 把便签放在它解释的那部分旁边，让箭头指向它。

### 把箭头连到节点

编辑时先点一下画布上的节点，再按箭头。这个箭头就连到了该节点。之后点击已连的箭头，画布会把节点带到视野里，和 Workflow Switches 里的取景按钮一样。悬停箭头可以看到它指向哪个节点。

文本里已连的箭头写成 `➡️#12` 这样，其中 12 是节点的编号。去掉 `#12` 就是普通箭头。节点被删掉后箭头会留下、变淡，并且不再起作用。

## 链接

便签可以链接到网页，也可以链接到工作流的某一部分。

- **连到网页：** 选中文字，按文本框下方的 **Link**，粘贴地址。也可以选中文字后直接把地址粘贴覆盖上去。之后点击这些文字，页面会在新标签页打开。文字后面的小 ↗ 表示它会离开 ComfyUI，悬停可以看到它去哪。
- **连到节点或组：** 编辑时先点画布上的节点或组，选中文字后按 **Link**。之后点击这些文字，画布就会把它带到视野里。箭头也可以指向组：点一下组，再按箭头。
- 整张便签只有一条链接时，它就是这条链接的大按钮：文字填满便签。

文本里的链接写成 `[the words](https://example.com)`；节点 12 是 `[the words](#12)`，组 3 是 `[the words](#g3)`。

## 技术细节

- 文字存在节点唯一的隐藏 `text` 输入里，所以保存、撤销和复制与普通节点一样。除此之外不保存别的东西。
- 便签与它链接所指的节点、组一起复制时，链接会指向副本。指向没被复制的东西的链接保留原来的编号。
- 文本里，小字是以六个 `#` 加一个空格开头的行：`###### Off, your words go in as typed.` 小字是便签字号的 62%，且不小于 11 px。
- 小字功能之前写的便签看起来一样。旧版本的包会像处理其他标题符号那样丢掉这六个 `#`，所以带小字的便签在旧版本里仍然读得通，只是每行一样大。
- 字号是 12 到 30 之间能放进便签的最大整像素值。最小的字号也放不下的超长文字会在底部被截掉：把便签拉高。
- 只有 `http` 和 `https` 地址会变成链接。圆括号里的其他内容让文字原样保留。链接在新标签页打开，便签本身从不打开它：只有你点击才会。
- 别人工作流里的链接会去作者指定的地方。点击前先悬停看清地址。
- 旧版本的包会把链接连同方括号和地址原样显示，所以那里仍然能读到并复制地址。
- 字体是本机的 IBM Plex Sans，没有就用系统字体。节点不加载字体，也不发网络请求。
