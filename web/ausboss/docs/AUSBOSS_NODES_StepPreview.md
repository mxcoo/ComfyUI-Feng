# 分步预览 🆎

在图片生成的过程中就显示它，一步一步来，带一个 **Stop** 按钮。如果图正往坏的方向走（姿势、构图、多出一条胳膊），你可以在头几步就看出来并停掉这次运行，不必等到最后一步。

放在画布的任意位置。它不需要接线：它显示当前工作流里正在出图的那个采样器，图片下方的说明写着进度（"step 3 of 8"）。

## 按钮

- **STOP**：立刻停掉这次运行。采样器之后的东西都不跑，所以什么都不保存。队列里的下一次运行照常开始。
- **STOP ALL · N**：队列里还有运行在等时出现。它清空队列并停掉这次运行。

运行一保存好图片，完成的图就取代模糊的最后一步，并留在节点上直到下次运行开始。栏右边的词说明这次运行怎么结束：done、stopped 或 failed。被停掉的运行保留它走到的最后一步。

分块放大会一次只处理图的一小块。这些小块不会当成整图显示：节点保留最后一张完整图，并显示 "upscaling in tiles"，同时给出正在处理的那一小块的步骤。

## 保存图像和保存视频也能做

保存图像 🆎 和 保存视频 🆎 各有自己的 **steps** 开关（默认关闭）。打开后，保存节点的画面区域会显示它即将保存的那张图的步骤，带同一个 Stop 按钮。反正都要看结果时，用保存节点的开关；想要更大的视图，或者用一个视图管住有多个采样器的工作流时，用本节点。

## 更清晰的步骤图

步骤图又小又模糊。用来判断姿势和布局足够了。有些模型带小的预览解码器（TAESD 文件），能让它们更清晰：把它放进 ComfyUI 的 `models/vae_approx` 文件夹，ComfyUI 就会用上它。

## 技术细节

- ComfyUI 只有在预览方式不是 `none` 时才生成步骤图，而全新安装默认就是 `none`。当排队的工作流里有本节点，或者有打开了 steps 开关的保存图像 / 保存视频时，本包会为那一次运行请求 `auto` 方式。
- 它绝不覆盖你已经做过的选择：如果你在 ComfyUI 的 **Live preview method** 设置里选了方式，或者用 `--preview-method` 启动了 ComfyUI，就用那个。命令行里的 `--preview-method none` 视为"未选择"，因为那是默认值。
- `auto` 在装有时使用 `models/vae_approx` 里模型的 TAESD 解码器，否则用一个快速的色彩估计（latent2rgb）。有些模型两者都没有（比如 SeedVR2），那就没有步骤图。
- 步骤图长边最多 512 px（`--preview-size`）。它们不改变结果：同一个种子，显示或不显示步骤图，出的是同一张图。
- 它们几乎不花时间。在一台桌面上用 Qwen Image 2.1 实测：8 步时关掉 8.50 s、打开 8.40 s，25 步时 17.62 s 与 17.64 s，每次都是同一张图。
- 预览打开时，位于工作流顶层（不在框里）的 ComfyUI 采样器也会在自己界面上显示步骤，就像在 ComfyUI 里打开预览时那样。节点会长高以容纳图片，并在运行结束后保留最后一步。
- 从别的工作流标签页排队的运行不在这里显示。
- 用视频模型时，步骤图是片段的第一帧。
