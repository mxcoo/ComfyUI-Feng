# 图像文件夹 🆎

选一个文件夹，勾选要用的图片，逐张跑工作流。

同一件事要在很多张图上做时用它：统一改一处、打标、缩放、配对做训练集。

## 用法

1. 把文件夹带进来。从文件管理器拖到节点上。或按 **Browse**，再选 **Copy a folder from your computer**，挑一个文件夹。里面的图片会复制到 ComfyUI 的 `input` 文件夹，并以图块显示。
2. 已经在 ComfyUI 的 `input` 或 `output` 文件夹里的文件夹，用 **Browse** 选。
3. 点图块可以取消或重新选上这张图。**Shift + click** 会从上次点的图块到这一块全部处理。**All** 和 **None** 作用于整个文件夹。
4. 把 **image** 接进你的工作流，把 **filename** 接到保存图像的 `filename`，这样每个结果都沿用原图的名字。
5. 按 **Run**。

## 电脑上任意位置的文件夹

节点只读 ComfyUI 自己 `input` 和 `output` 文件夹里的文件夹，别处不读。其他位置的文件夹会先复制进来：

- **拖到节点上**，或用 **Browse → Copy a folder from your computer** 或 **Add → A whole folder** 选择。后两种会打开系统的文件选择框。
- 在文件选择框里选文件夹时，**浏览器会先问一句**。它显示自己的问题，例如 "Upload 74 files to this site?"。这个站点就是你的 ComfyUI，上传就是复制到它的 input 文件夹。节点改不了这些字。拖到节点上的文件夹不问，直接复制。
- 里面的图片进到 `input/<the folder's name>`，其中的子文件夹也一样，节点随后切到这份副本。
- **特别大的文件夹会先问一句。** 超过 300 张图或超过 1 GB 时，节点会说明有多少张、多大，然后等你确认。复制会再多占同样多的磁盘空间。
- 再次导入同一个文件夹会覆盖它的副本，不会越堆越多。
- 在**文件夹**里手动输入或粘贴的路径，只有在 ComfyUI 的 input 或 output 文件夹内才有效。其他路径节点会明确提示，并给一个打开文件选择框的按钮。

## 一次跑完，还是一次一张

**运行**决定图片怎么过。

- **all in one run**：按一次 Run 就依次处理所有勾选的图片。某张图把工作流卡住，它后面的都不会做。
- **one per run**：每次运行加载一张，运行入队时**位置**前进一格。把 ComfyUI 的运行次数设成图片数量，它们会一次全部入队。某张图失败只跳过它自己。带白圈的图块是下一张，双击某个图块也能把它设为下一张。

最后一张之后，**放到末尾**要么提示一句并停止，要么从第一张重新开始。选 **start over** 时，位置回到 1，图片按顺序循环，你排多少次就重复多少次。

## 卡片

- **源**（`source`）：ComfyUI 的 **input** 文件夹；想用你做出来的图就选 **output** 文件夹。
- **文件夹**（`folder`）：其中的子文件夹。留空就是 input 或 output 文件夹本身。**Browse** 会列出那里的文件夹。
- **子文件夹**（`subfolders`）：连同里面各文件夹的图片一起取。
- **排序**（`sort`）：按名称，或最新优先、最旧优先。
- **运行**（`run`）：见上文。
- **位置**（`position`）：一次一张时，下次运行加载的勾选图片，从 1 开始计。
- **运行后**（`after_run`）：**next** 让位置前进，**stay** 一直加载同一张，**random** 跳到勾选的任意一张。
- **放到末尾**（`at_the_end`）：最后一张之后，**stop the run** 提示后停止，**start over** 回到第一张继续。

## 图块

- 图块上方那行说明勾选了多少张；一次一张时还会说明下一张是哪张。
- 勾选的图块是亮的，带勾和编号。其余是暗的。
- 青色背景的编号表示这张图在你打开工作流之后跑过。
- **Add** 从你的电脑把图片或整个文件夹复制到 ComfyUI 的 input 文件夹。
- **↻** 重新读取该文件夹。

## 输出

- **image**：每张勾选的图片，一次一张。后面的节点对每张各跑一次。
- **mask**：图片透明处为白。没有透明部分的图片，给出的空遮罩与加载图像一致。
- **filename**：不含扩展名的文件名。
- **index**：这张图在勾选图片里的序号，从 1 开始。
- **count**：勾选了多少张。

## 技术细节

- **只认 ComfyUI 自己的文件夹。** 节点只读 ComfyUI input 或 output 文件夹内的内容，别处不读。指向其他位置的路径会被拒绝，这两个文件夹里指向外部的链接同样被拒绝。没有任何设置能改变这一点。
- 勾选的图片以名字列表（`pictures`）存进工作流。留空表示全部，所以之后往文件夹里加的图也算在内。文件夹里已经没有的名字会跳过。它不需要连线：节点上的勾选就会写入。
- 支持的图片格式为 PNG、JPG、WebP、BMP、GIF（第一帧）和 TIFF。竖着拍的手机照片会转正。文件名以点开头的文件会跳过。
- 按名称是按人的习惯排序：`photo_2` 在 `photo_10` 之前。
- 打开**子文件夹**时，图片的 `filename` 会带上所在文件夹（`trips/beach.png` 得到 `trips_beach`），同名的两个文件就不会互相覆盖。
- **image**、**mask**、**filename** 和 **index** 都是列表。图片各自保持原尺寸，不会被缩放，也不会拼成一个批次。
- 位置的推进由编辑器在运行入队时完成。通过 API 提交的工作流精确加载 `position` 指定的那张图。
- 选 **start over** 时，超过最后一张的位置编号会从第一张绕回计数。用这种编号保存的工作流会加载那张图，并从那里继续。
- 勾选的文件被新增、删除或改写时，节点会重新运行。
- 一个文件夹最多列出 5000 张图；导入文件夹时最多复制 3000 张。
- 导入文件夹由你的浏览器通过 ComfyUI 自带的上传完成。服务端永远不会打开 ComfyUI input 和 output 文件夹之外的路径。
- 在 MaskEditor 里画的遮罩不属于文件夹里的图片。改用按名字取遮罩 🆎，或用单图加载节点加载那张图。
