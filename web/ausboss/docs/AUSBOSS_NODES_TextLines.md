# 文本行

文本的每一行都会让后面的节点运行一次。输入五条提示词，每行一条，按一次运行，
就得到五张图。

可用于你手打的提示词清单，也可用于别的节点写出来的清单，例如让文本模型给出
“五个不同的姿势”。

## 怎么用

1. 在框里逐行输入，或者把文本连到**文本**。
2. 把**行**连到原本放一条提示词的位置，例如文本编码器的提示词。
3. 运行。它之后的每个节点都会为每一行运行一次，末尾的保存图像会为每一行各存一张图。

空行会跳过。不依赖行的模型和图片只加载一次，而不是每行加载一次。

## 控件

- 文本框（`text`）：每次运行取一行。
- **分隔方式**（`split`）：**each line** 让每一行各自成为一次运行。**blank line**
  把行留在一起，遇到空行才开下一次运行。一条提示词跨好几行时选它。
- **去掉序号**（`remove_numbering`）：**remove** 会把行首的编号或项目符号去掉，例如
  `1.`、`2)`、`-` 或 `[prompt 3]`。文本模型写的清单通常带这些。**keep** 保留每行的原样。
- **上限**（`limit`）：最多运行多少行。0 表示全部运行。当文本模型可能写出比你要求更多的行时设置它。

## 输出

- **行**：每一行，一次一行。
- **序号**：这一行在清单中的位置，从 1 开始。用数学表达式（`a + b`）把它加到种子上，
  就能给每一行自己的种子。
- **数量**：会运行多少行。

## 说明

- 一行都没有时，运行在这个节点停止，并给出说明。
- 除非你把**序号**加上去，每次运行都用同一个种子。不同的提示词仍然给出不同的图。
- 像 “2 women on a beach” 或 “1.5x zoom” 这样的行会保留它的数字：只有数字后面跟句点、
  括号或冒号才算编号。

## 技术细节

**行**和**序号**是 ComfyUI 的列表（`OUTPUT_IS_LIST`），和图像文件夹输出图片的方式一样。
ComfyUI 会为每个条目把后面的节点各运行一次，并按顺序保留结果。一次接收整个列表的节点，
例如核心的 Rebatch Images，会一次性拿到全部条目。

会被去掉的编号：方括号、圆括号或中日韩括号里的数字，前面可以带一个词（`[prompt 1]`、`(2)`）；
一个词加数字、后面跟冒号、句点、括号或连字符（`Shot 3:`）；单独的数字后面跟句点、括号或冒号、
且紧接其后没有数字；以及 `-`、`*`、`•` 后跟一个空格的项目符号。每行只去掉一个标记。
