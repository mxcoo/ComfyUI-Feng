# 合并批次 🆎

把两个 `IMAGE` 批次并成一个，**a** 的帧在前 —— 用来重新组装被拆开的
批次、给一次运行追加一条对比条，或者把片段串起来。

## 控件

- **a**：第一个批次；它的帧排在结果前面。
- **b**：第二个批次，接在 **a** 的帧之后。
- **不一致时**（`on_mismatch`）：两个批次的尺寸不同时怎么办：
  - **match a**（`resize to a`，默认）：**b** 的帧按
    双线性缩放到 **a** 的尺寸。
  - **match b**（`resize to b`）：改为把 **a** 的帧缩放到 **b**
    的尺寸。
  - `error`：停下，并报出两个尺寸 —— 适合那些悄悄缩放会掩盖 bug
    的图。

## 输出

- **images**：一个批次：**a** 的帧接着 **b** 的帧。

尺寸一致时，无论哪种策略都原样拼接、不做改动。通道数
必须事先一致（3 通道对 3 通道，4 对 4）：悄悄造出或
丢掉一个 alpha 通道不是这个节点该决定的事，所以不匹配
就报错。
