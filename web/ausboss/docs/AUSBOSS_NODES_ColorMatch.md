# 颜色匹配 🆎

让一张图的颜色与另一张对齐。局部重绘或拼接出来的一块贴着原图时偏暖、偏冷、
偏暗或偏亮，就用它。四种方式从轻微修正一路到精确匹配，另有一个首帧模式把视频
的每一帧都匹配到第一帧，可以减少帧与帧之间的颜色漂移。

## 控件

- **image**：要修正的图像。
- **强度**（`strength`，起始为 `1`）：`0` 原样返回输入，`1` 应用完整匹配；
  两者之间的值线性混合。
- **reference**（可选）：要照抄其观感的图像。拼接式局部重绘，把原图接在这里。
  单张参考会广播到整个批次；数量匹配的批次则逐帧配对。除非**参考**
  （`reference_mode`）为 **first frame**，否则这一项必需。
- **方法**（`method`）：颜色怎么移动。
  - **lab** —— 在 LAB 里做逐通道的均值/标准差偏移。符合感知，也是稳妥的
    默认选项：修正整体偏色和对比，而不去挪动单个色相。
  - **rgb** —— 在原始通道里做同样的均值/标准差偏移。
  - **mkl** —— 映射完整的颜色协方差；色相被旋转而不只是偏移时最好用。
  - **hist**（`histogram`）—— 精确匹配每个通道的分布。最强，也最不留余地。
- **mask**（可选）：把匹配限制在白区 —— 既包括在图像上统计的量，也包括修正
  落下的位置。黑像素**逐位相同**地通过。参考的统计始终取自整张参考帧。
  没有遮罩时匹配整张图。遮罩与图像尺寸不同会中止运行。
- **反转遮罩**（`invert_mask`）：把遮罩的黑区当作要修正的区域，而不是白区。
- **参考**（`reference_mode`）：目标统计从哪里来。**reference** 使用接进来的
  参考图。**first frame**（`first_frame`）用批次自己的第一帧作为每一帧的目标，
  不需要参考；`reference` 输入会被忽略。这能减少帧与帧之间的颜色漂移；
  它不会稳定运动。

## 输出

- **image**：颜色匹配后的图像；遮罩之外的像素保持原样。

## 说明

- 节点收遮罩但故意不输出：遮罩只用来限定修正范围，并原样穿过你的图 ——
  把你原来的遮罩继续往下接。
- 和 **局部重绘拼接 🆎** 搭配：先拼接，再把 局部重绘拼接 的 `blend_mask` 接到
  **mask**、把原图接到 **reference**。这样正好把贴上去的那块匹配回原图。
- 颜色在帧间漂移的视频，把**参考**设为 **first frame**，每一帧都会匹配到片段
  开头的颜色。它不能稳定运动，而内容发生变化的帧，比如摇镜到更暗的场景，
  同样会被拉向第一帧的颜色。
