# 遮罩精修

一个节点完成遮罩清理：扩大或缩小、填补空洞、平滑块状边缘、柔化边缘。可以用在分割节点
输出的遮罩或随手画的遮罩上，在遮罩送进局部重绘节点之前处理。它还能把边缘吸附到引导图像，
并调整遮罩的色阶。精修后的遮罩和它的反转都会输出，不需要再单独接一个反转节点。

节点运行后，面板直接显示精修后的遮罩，不用在旁边接预览节点就能看到设置的效果。
批次或视频显示第一张遮罩。图片上方栏右侧的**预览**小开关可以关掉它：图片框消失，
节点相应变矮，也不再写预览文件。重新打开后，节点恢复高度并显示上次的结果；
如果关闭期间运行过，它会提示你再运行一次工作流。这个开关就是节点可选的 `preview` 输入。

## 按钮

- **AUTO** —— 读取面板上遮罩的尺寸，为它设定一个合理的**扩展**和**模糊**起点。
  羽化是画面的一定比例，而不是固定的像素数：在 576 高的片子上能盖住水印边缘的 8 px 扩张，
  在缩略图上是一团糊，在 4K 画面上又看不见，所以数值随遮罩的短边缩放。它们只是供你微调的
  起点，不是正确答案 —— 遮罩需要扩多少取决于分割有多紧，这一点无法从画面上读出来。
  需要先运行一次，因为面板是在那时才知道遮罩尺寸的。
- **MORE** —— **模糊**下方卡片上的折叠区，用于显示或隐藏高级行。节点打开时只有
  **扩展**和**模糊**，其余的都隔一次点击。隐藏的行保留数值，所以设置过它们的工作流不受影响；
  这个选择按节点记忆。

## 控件

- **遮罩**：BHW 遮罩；白色为选中区域。
- **扩展**（`expand`）：扩大（`+`）或缩小（`-`）的像素数。软输入值会被保留。
- **模糊**（`blur`）：高斯羽化强度，单位为像素；`0` 保持硬边。

### 高级（在 **MORE** 后面）

- **填补空洞**（`fill_holes`）：在羽化之前，填补遮罩内部完全封闭的空隙。
  接触画面边界的空隙不动。
- **最大空洞尺寸**（`max_hole_size`）：**填补空洞**会填补的最大空洞，按画面百分比计。
  当你在一块想保留的东西周围涂了遮罩时使用它：设为 `2` 时，随手画笔留下的小空隙仍然会填上，
  而你没有涂到的人、宠物或物体保持原样。默认值 `0` 不管多大都填。
  只在**填补空洞**打开时有用。
- **平滑**（`smooth`）：按这么多像素融化阶梯状锯齿，同时保持硬边 —— 遮罩被二值化、模糊、
  再二值化，所以不会产生羽化。`0` 表示关闭。用于块状的分割结果；真正想要软边时用**模糊**。
- **黑场** / **白场**（`black_point` / `white_point`）：最后应用的色阶重映射。等于或低于
  `black_point` 的值变成全黑，等于或高于 `white_point` 的值变成全白；之间的范围线性重映射。
  把 `black_point` 稍微调高可以清掉灰色雾边，把 `white_point` 调低可以压实核心。
  默认值（`0.0` / `1.0`）不做任何改动。
- **边缘精修**（`edge_refine`）：`off`、**guided**（`guided filter`）或 `matting`。
  两种精修都会把遮罩边缘吸附到相连的**引导图像**上，并且逐帧运行，所以视频批次随时可以中断：
  - `guided filter` —— 用引导图像对软遮罩做快速的边缘感知滤波。滤波半径随**扩展**缩放。
  - `matting` —— closed-form alpha matting：按边缘半径腐蚀后的二值遮罩算作确定前景，
    膨胀标出确定背景开始的位置，两者之间的过渡带对着引导图像求解。
    配合色阶重映射来整理求出的 alpha。
- **引导图像**（可选输入）：遮罩所属的 RGB 帧，尺寸与遮罩一致；一帧会广播到整个遮罩批次。
  `edge_refine` 不为 `off` 时必填。

## 可选安装

上面的一切都能在包内的固有依赖上运行，只有两档 `edge_refine` 例外：

- `guided filter` 需要 opencv-contrib：`python -m pip install opencv-contrib-python`
- `matting` 需要 pymatting：`python -m pip install "pymatting>=1.1"`

用运行 ComfyUI 的那个 Python 来装（Windows 便携版用
`python_embeded\python.exe -m pip install ...`）。

它们以 `guided-filter` 和 `matting` 两组列在包内 `pyproject.toml` 的
`[project.optional-dependencies]` 下。没有安装时，选择那一档会报出缺少的包名；
节点的其余部分不受影响。

## 输出

- **遮罩**：精修后的 BHW 遮罩。
- **反转遮罩**：`1 - mask`，用于针对背景的操作。

各操作按固定顺序执行 —— 扩展、填补空洞、平滑、模糊、边缘精修、黑白场 ——
所以羽化过的边缘不会被后面的步骤重新变硬，色阶重映射总是对最终结果收尾。

## 技术细节

**最大空洞尺寸**是在**扩展**移动过遮罩之后，按该图整幅面积的比例来度量每个空洞，
所以同一个设置在任意分辨率下都适用；批次里每张图各算各的。正好等于上限的空洞会被填补。
`100` 及以上和 `0` 一样填补所有空洞。接触画面边缘的未涂区域在任何设置下都不算空洞，
因为遮罩没有在它周围闭合。

在测试遮罩上，0.25 到 16 百万像素，随手画笔在笔画之间留下的空隙和漏掉的点最多占画面的
1.3%，而未涂的主体（一个人、一只狗、一只鞋、一只猫）至少占 18%。单独保留的一张脸是
2.1% 到 5.3%：`2` 能保住四分之三身或更近的脸，而全身照里的脸更小，仍然会被填掉。
用大笔刷很松地涂，笔画之间可能留下超过 2% 的长条：调高设置，或者把它涂上。
