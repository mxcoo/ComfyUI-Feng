# 浮点数 🆎

带小数的数字。把某一处强度、缩放倍数或 CFG 设在这里，接给每一个需要它的
节点，改的时候只改一个地方。

## 控件

- **数值**（`value`）：要送出去的数字。初始为 `0`。框里显示它的步进
  所用的小数位（`0.00`），最多保留三位，所以手输的 `0.125`
  仍然是 `0.125`。
- 右侧的齿轮：**外观**。**normal** 是带标签的常规输入框。
  **big** 把数字大字显示在节点中央，两侧各有一个箭头，适合每轮
  都会改的设置，例如片段长度。拖动和键入的效果一样。每个节点
  各自记住自己的外观，
  并随工作流保存。

## 限制

把输出接到带有取值范围的设置上，输入框就接管这些范围。接到
采样器的 **denoise** 时，它只在 0 到 1 之间，再往外不行：输入
1.5 得到的是 1。卡片上数值旁边会显示 **0–1**。

- 经过 Reroute、进到框（子图）里也一样有效。
- 接给两个设置时，它遵守两者共同允许的范围。
- 断开接线，它又能接受任意数字。
- 新的输入框取你第一个接上的设置的值，所以接好线并不会改变什么，
  除非你动它。已经设过值的输入框，或者随工作流一起载入的输入框，
  保留自己的值。

## 输出

- **float**：这个数值，原样送出。

路上要算一下 —— 缩放、用 `min`/`max` 夹取 —— 就把它接到
**数学表达式 🆎**，不必重新手打算出来的数字。

## 技术细节

- 范围来自接线落到的那一端输入，和 ComfyUI 自带的 Primitive 节点
  取范围的方式一样。几个输入在步进上一致时，细步进（Shift）
  就是那个步进。
- 接线建立时，落在范围外的值会被带到最近的
  那一端。
- 框里保留三位小数，或者接管来的步进所需要的位数。它显示的是
  箭头步进能达到的位数（至少一位），只有用到更多位的值才会超出：
  接 denoise 的 `1.00`、接 CFG 的 `8.0`、以及手输 0.855 得到的
  `0.855`。
- 范围由节点界面来遵守。直接经 API 送进去的值
  原样传下去。
- 只接给彼此没有共同取值的输入时（一个到 1 为止，另一个从 2
  开始），输入框不保留任何范围。
- 外观存在节点属性里，写作 `ausboss_text_look: "big"`，和
  文本 🆎 一样。它不是输入，所以两种外观下，保存的值和节点送出的
  值完全相同；旧版本的包会退回显示常规
  输入框。
