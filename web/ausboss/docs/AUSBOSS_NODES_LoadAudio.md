# 加载音频

加载声音文件，只输出你选中的那一段。可用作配音片段、歌曲，或任何视频模型、保存节点
接受的音频；当你只需要文件中的某一段而不是全部时使用。

节点把整个文件画成波形，一眼能看出响的部分在哪。输出的那一段是亮的。拖动白色的
**IN** 和 **OUT** 手柄设定起止位置，拖动亮的部分整体平移，或在波形上别处点击把它移过去。
也可以在波形下方输入时间，单位为秒（`12.5`）或分秒（`1:02.5`）。

按 **▶** 只试听输出的那一段。**LOOP** 会反复播放。

## 最大秒数

把**最大秒数**设为下一步能接收的最长声音，例如你正在做的视频长度。起点不动，
超出限制的部分变红，并在截断处画一条虚线。在 OUT 旁边，节点显示输出声音的长度，
例如 `15.0 s`。选中的部分被截掉时它会变红；把鼠标停在上面可以看到被截掉多少，
点一下它就把 OUT 移到截断处。播放到截断处就停，听到的就是输出的内容。`0` 表示不限制。

最大秒数可以连线。当连线来自数字节点（例如浮点数 🆎）时，波形会显示那个数值对应的
截断位置；否则长度的提示文字显示 `max wired`，运行时仍按连入的长度截断声音。

## 控件

- **音频**（`audio`）：ComfyUI 的 input 文件夹里的声音文件。**上传** 可以添加一个。
  视频也会列出，取其声音。
- **最大秒数**（`max_seconds`）：声音允许的最长时长，单位为秒。`0` 表示不限制。
- **IN**（`start_seconds`）：声音开始的位置。
- **OUT**（`end_seconds`）：声音结束的位置。`0` 表示文件末尾。

## 输出

- `audio`：你选中的那一段，可接到任何接受 `AUDIO` 的节点。
- `seconds`：这段声音的时长。

## 技术细节

- 只解码选中的部分：窗口填满就停止解码，所以从长录音里取一小段依然很快。
- 声音保持它自己的采样率和声道。
- 起点超过文件末尾时运行停止，并给出说明。
- 波形由浏览器根据文件本身绘制；工作流里除上面四个数值外不额外保存任何东西。
