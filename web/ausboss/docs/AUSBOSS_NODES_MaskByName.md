# 按名字取遮罩 🆎

在图片上写下要找什么，就得到它的遮罩。不用涂。

凡是工作流需要某一样东西的遮罩时都可以用它：改动它、去掉它、
把它抠出来，或者保留其余的一切。

## 用法

1. 把图片接到 **image**。
2. 从加载 SAM 3 文件（`sam3.1_multiplex_fp16.safetensors`）的
   Load Checkpoint 接出 **model** 和 **clip**。
3. 在 **Find** 里用几个平常的词写下要找的东西："the dog"、"the red
   jacket"。要找几样东西，用逗号隔开："the hat, the
   bag"。
4. 按 **FIND**。只有这个节点运行，节点上的图片会显示找到的东西，
   染成青色。

遮罩对了，就按 Run 运行整个工作流。

## 什么都没找到的时候

默认情况下，运行会就地停下并给一句平实的说明，所以这个节点之后的
东西都不会在空遮罩上运行。节点自己也会说明这一点：
**0 found**，以及图片上方那句提示。

换个名字试试，或者打开 **More** 把 **Sureness** 调低。小的东西，
例如嘴唇或包带，往往需要 0.6。

把 **If nothing** 设成 **empty mask**，就能让它带着一张空遮罩
继续跑下去。

## 卡片

- **Find**（`name`）：要找什么。可以从文本节点接进来。
- **If several**（`several`）：有不止一个东西匹配时，遮罩 **它们全部**
  还是只遮 **最大的那个**。
- **Grow**（`grow`）：越过东西边缘的像素数。0 保留精确的
  轮廓。局部重绘通常需要几个像素。
- **Soften**（`soften`）：软边的像素数。0 保持硬边。
- **If nothing**（`if_nothing`）：**stop the run** 或 **empty mask**，见上文。
- **More → Sureness**（`threshold`）：SAM 3 必须有多确定才算匹配。
  小东西漏掉时把它调低。它抓到了不是要找的东西
  时把它调高。
- **More → Fill holes**（`fill_holes`）：填补完全落在遮罩内部的
  空隙，例如 SAM 3 在头发或布料里留下的小洞。打开后得到实心形状。
- **More → Free VRAM**（`free_vram`）：搜索完立刻把 SAM 3 从显卡
  显存里拿走，好让下一个模型有地方用。关掉则让它留在显存里，
  下一次搜索会快一点。如果你要搭工作流，见下面的说明。
- **FIND**：只运行这个节点和喂给它的部分。
- **1 found · 96% sure**：匹配到了几个东西，以及 SAM 3 对最好的那个
  有多确定。数字偏低意味着：看看图片，它可能抓到了
  别的东西。
- **Preview**：关闭后隐藏图片，也不再写预览文件。

## 输出

- **mask**：东西所在之处为白色。每张图片一张遮罩。
- **cut_out**：除了那个东西，其余都透明的图片。存成 PNG 可以
  保住透明部分。
- **found**：第一张图片里匹配到了几个东西。

## 用它搭工作流

- 这个节点之后要加载大模型时，例如编辑模型或视频模型，
  存工作流之前把 **More → Free VRAM** 打开。这样 SAM 3 会在那个模型
  需要显存之前离开显卡。
- 单独使用这个节点，或者连续按很多次 FIND 时，
  让它关着。SAM 3 留在显存里，每次搜索都快一点。

## 技术细节

- **为什么 Sureness 从 0.7 开始。** SAM 3 很宽容：在一张没有自行车的
  图里要找自行车，它往往照样给出自己最好的猜测。在 16 张测试图上，
  正确的名字得分 89 到 99。小的真实物体（嘴唇、
  鞋、包带）得分 67 到 79。图里没有的名字，有一半时候得分
  超过 50，80 次里有 2 次超过 70。ComfyUI 自带的默认值
  是 0.5。
- 每个名字最多可以匹配 16 个东西。否则 SAM 3 每个名字只返回一个
  匹配，两条围巾只能找到一条。
- 搜索用的是 ComfyUI 自带的 SAM 3（CLIP Text Encode，然后 SAM3 Detect，连同
  它的两次边缘遍历）。节点需要 ComfyUI 0.20 或更新版本，在旧版本上会说
  明这一点。
- 遮罩是图片的尺寸。想对边缘有更多控制（闭合
  空洞、平滑、吸附到图片），后面接遮罩精修。
- **Grow**、**Soften** 和 **Fill holes** 就是遮罩精修用的扩展、模糊和填补，
  顺序也和那个节点一致：扩展、填补、柔化。Fill holes
  会填补每一个封闭的空隙，也包括想要的空隙，例如圆环的中间。
  遮罩精修可以按尺寸限制它。
- **Free VRAM** 只卸载 SAM 3 和它的文本读取器，用的是 ComfyUI 自己的
  单模型卸载。其他模型都留在显存里，SAM 3 还留在
  系统内存里，所以它回来得很快。下一个模型需要显存时，ComfyUI 也会
  自己把模型挪出去；这个开关是给"你想让 SAM 3 立刻出去"用的，
  也包括一次什么都没找到的搜索之后。在一台机器上实测：
  回收约 1.7 GB 显存，一次搜索用了 0.8 秒，
  而不是 0.5 秒。
  它需要 ComfyUI 0.23 或更新版本。在旧版本上这个开关什么也不做，
  运行照旧继续。
- 批次里有多张图片时，每一张各自搜索。没有那个东西的
  图片得到空遮罩，只有当所有图片都没有它时，
  运行才停下。
- 计数是匹配到的数量，即使 **the biggest** 只留下其中一个。
- 它是一个输出节点，所以 FIND 可以单独运行它。因此输出什么都没接
  的时候它也会运行。
- 不是 SAM 3 的模型会失败，并给出一行说明该接什么。
