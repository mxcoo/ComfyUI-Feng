# 文本

一个文本框。提示词、说明文字或任何其他文本，写一次就能喂给所有需要它的节点——在一处修改，它们全部跟着更新。

## 控件

- 文本框（`text`）：要输出的文本。换行和空格都会保留。把节点拖高可以得到更大的框。
- 右上角的齿轮：**Look**。**normal** 是普通的文本框。**big** 会在框的正中用大字显示你的文字，所以像 "jacket" 这样一两个词很容易看见，例如在每张图片旁各放一个小文本节点时。框一开始很小，大约两行，把节点拖高时框会变大。每个节点各自保留自己的外观，并与工作流一起保存。
- **Ctrl + Up** 和 **Ctrl + Down** 改变光标所在词的权重，或你选中的词的权重，与 ComfyUI 自带的提示词框相同：`(red hair:1.1)`。按一次变化多少由 ComfyUI 的设置 "Ctrl+up/down precision" 决定。

## 输出

- **text**：正是你输入的文本，不做改动。

节点完全不进行处理：不去掉首尾空白、不展开模板、不做替换。框里看到什么，下游收到的就是什么。

## 技术细节

外观以 `ausboss_text_look: "big"` 存进节点的属性；普通外观的节点没有这个属性。它不是输入，所以两种外观下节点保存的值和它发送的提示词都相同，旧版本的包显示的仍是普通框。big 外观下的长文本会在框内滚动。
