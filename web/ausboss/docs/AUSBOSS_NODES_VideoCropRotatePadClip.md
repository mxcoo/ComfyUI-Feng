# 视频裁剪 + 旋转 + 扩边 → 片段 🆎

**输出整段片段。** 一次 **旋转 → 裁剪 → 扩边** 变换作用在
裁剪窗口的每一帧上。时间轴选出那个窗口，播放头
挑出你调整变换时用的那一帧。

用它从视频里切掉一条边框、一个 logo 角或者一点倾斜，或者
在它周围长出填充色带做**视频扩图**：`mask` 输出标出这些
色带（以及旋转角），可以直接交给 Crop For Inpaint，或交给
会在黑色区域作画的上下文视频模型。

## 来源与窗口

- **输入**：选一个已有的输入视频（列表会静音播放指针下的片段，并随输入过滤），点 **Load**，或者把视频文件拖
  到节点上。旧的来源控件仍与已保存的工作流兼容，但
  现在由这张紧凑卡片驱动。换另一个视频会保留画布
  设置——填充、羽化、**Align**、缩放、每隔 n 帧、帧对齐、最大帧数——并
  把新片段适配到亮起的比例按钮，也就是 **Fit** 的设定方式。旋转、裁剪、
  扩边、IN/OUT 和播放头重新开始。
- **输出**（`source_mode` / `local_path`）：从 ComfyUI 的 output 文件夹里选视频，
  比如刚渲染出来的那个。列表最新的在前，并预览指针
  下的视频。视频就地读取，不复制一份上传。写进 API 提示词时
  它按 ComfyUI 在那里的命名方式写：`clip.mp4 [output]`。像
  `/home/me/ComfyUI/output/clip.mp4` 这样的整条路径不会被读取，排队运行和编辑器的实时
  预览都一样。
- **播放 / 暂停** 在拖动条旁边，预览选中的帧，到 OUT 停下。在 OUT 按 **Play** 会从 IN 重新开始。
- **时间轴**（就在预览和尺寸行下方）：节点上的轨道和编辑器里的是同一条时间轴。在它上面任意处按下或
  拖动即可擦动**播放头**，长度开或关都行；舞台显示
  那一帧。拖 **IN** 或 **OUT** 手柄来裁剪：播放头跟着手柄走，所以你看到的
  就是这次运行保留的第一帧（IN）或最后一帧（OUT），松手后
  它就停在那里。IN 和 OUT 是帧号，吸附到源视频的帧格上；轨道下方的
  输入框接受帧号，`start_seconds` / `end_seconds` 由它们推出
  （OUT 不含在内，0 表示源视频末尾）。手柄上的方向键移动一
  秒，Shift 移动一帧。**OUT 总是落在这次运行输出的最后一帧上**，所以
  手柄和亮条一起结束；开了每隔 n 帧或帧对齐时，它会跳到
  运行实际保留的帧上，暗淡的尾巴标出窗口包含但运行会
  丢掉的帧。在编辑器里，**Set IN** / **Set OUT**（或 **I** / **O** 键）在
  播放头处设一个裁剪点，**Full clip** 重置窗口。编辑器还
  有第一帧和最后一帧的按钮，1、25、50、100 帧的步进，以及
  **Play**。方向键走一帧（Shift 走 10 帧），Home 和 End 跳到
  两端，空格播放或暂停。**Save & close** 保留你的修改；**Cancel** 或
  Escape 全部还原，有改动时会先问一句。
- **裁剪、扩边与缩放**（时间轴下方的可折叠分组）：把比例
  按钮、**Fit to ratio**、**Align** 和 **Center**、**Fill** 和 **Feather**，以及
  **Resize** 开关、百万像素预算和 **Step** 收进一个抽屉。收起时，
  它的标题栏显示填充色块，以及当前比例、羽化、对齐和
  缩放设置的实时摘要。这些正是视频扩图模型所依赖的——LTX IC-LoRA 在取整到 32 的尺寸上
  画**纯黑**——所以错误的值会在这里暴露，而不是浪费一次
  渲染。羽化只柔化遮罩和拼接；帧与填充之间始终是
  硬边相接。图片下方那行会写出每一步设定尺寸的过程
  （`576×1024 → pad 1821×1024 → resize 1280×704`），并在 Step 把图片拉伸超过 1% 时
  用琥珀色警告（`Resize makes the picture 2.2% wider`）；提示框里会给出能避开它的 Step，扩边模式下 **Pad to keep shape**
  会多加几个像素的边，这样什么都不会被拉伸。拖动过程中，那条琥珀色
  提示不动，松手后再按新尺寸回来。色带用真实的
  填充色画出，带一层淡的斜纹，所以黑带在黑底舞台上看得见。新建的片段节点
  以黑色和羽化 0 开始，编辑器的 **Reset transform** 会回到这两个值；
  图片节点则保留它们的灰底和羽化遮罩。
- **最大帧数**（`max_frames`）：另一个设定片段长短的方式。**关**
  （默认）：由 OUT 结束片段。**开**：从 IN 起算的输出帧数；
  OUT 位于 IN 之后那么多帧处，拖 IN 时跟着走，拖 OUT 或
  输入数字则会改变长度。要整体移动片段，拖 IN 或者保留部分
  中间的小把手（长度关闭时，这个把手也能滑动裁剪后的
  窗口）。长度等于整段片段时没有可移动的余地，那一行会说明：
  "= the whole clip. Shorten it to move IN." 换视频时长度保持
  不变，所以为 97 帧搭的工作流仍然取 97 帧。打开或关闭它
  从不移动任何东西：计数变成 OUT，或者 OUT 变成计数。
  如果源视频先结束，页脚会说明还剩多少帧。**To start** 把 IN
  移到源视频开头。
- **每隔 n 帧**（`every_nth`）：抽薄批次。`fps` 输出会相应做除法
  以匹配 every_nth，所以下游片段仍按真实时间；长度数的是保留的帧。
- **帧数**（`frame_snap`）：保留视频模型能接受的帧数：
  **LTX (8n+1)**（49、97、121）或 **Wan (4n+1)**。**any** 保留窗口里的每一帧。
  OUT 拖动和长度都会按这些数值步进。
  开着它时，`frame_count`、`duration`、音频窗口和拼接器都与
  采样器交回的片段一致，所以把 `frame_count` 接到空 Latent 的长度上
  永远不会让拼接拿到比生成帧更多的源帧。
- **frame_index / frame_time**：播放头。它是一个预览位置，不是裁剪
  点：擦动它不会让排队的片段失效，它也会随
  工作流保存。

裁剪的方块、扩边的菱形、橙色的角和旋转手柄也能
直接在节点预览上操作。角能按自己的形状把画布放大或缩小，
例如在视频扩图前均匀地缩小；按住 **Alt**
（Mac 上是 Option）可以一次改四条边。**Center** 在填充与
羽化旁边，把裁剪居中到源图上，并在选定轴上平衡扩边。
生成的遮罩跟随裁剪与扩边。
滚轮缩放和中键平移仍然归整张图。
点一个比例可以把片段扩边到它（开了 **Fit** 时则是裁剪到它）；再点亮着的比例
就回到整帧。亮起的比例就是画布当前的形状：
把手柄拖成另一个形状，它就变暗，那一行显示 **Custom**，新的
片段也不会再按它扩边。已经是这个形状的片段（相差
约 1% 以内）不会加任何东西，尺寸行会说明
（"already 9:16: pick another ratio or turn it"）；否则它会写出动作处亮起的比例（`pad to 16:9
1821×1024`）。挂锁在你拖动时保持形状，新增的色带
平均分配，那一行显示 **Held**；Reset 和点亮着的比例会关掉它，
对未动过的片段它什么也不做。**Fit** 可以在选比例之前先设好。
方向按钮把形状侧过来
（16:9 变 9:16），直接拖图片本身可以在扩边里移动它：
光标和小箭头会显示它能往哪些方向走。
**Reset crop** 恢复完整裁剪，不改旋转、扩边或裁剪窗口；
开着挂锁时，它也会去掉锁加上的色带。
**Reset** 在节点上清除旋转、裁剪和扩边，并关掉挂锁；
填充、羽化、**Align** 和时间轴保留。
编辑器里的 **Reset transform** 重置旋转、裁剪、扩边、填充、羽化以及
**Align**；它保留来源、当前帧、裁剪窗口、长度、缩放和拼接
设置。**Align** 让宽和高能被你选的那个数
整除：扩边会长出几个像素，没有扩边的一侧则被裁掉
几个。有些模型要求尺寸能被 8、16 或 32 整除；1 表示关掉。

**Load** 按钮和拖入文件走的是一条流式路由，直接写进 ComfyUI 的 input 文件夹，
所以带缓冲的图片上传大小限制不会挡住长视频上传。

编辑器的侧栏用节点自己的比例行、挂锁和 **Fit** 开关，
旋转是一个数字框（Shift 走 0.1°）。选比例会替换旧的裁剪和
扩边，保留旋转与缩放设置。
像素取整可能让相对的两条色带差一个像素。**Align** 和
缩放的 **Step** 会略微改变最终的宽高比。

## 变换与输出

旋转、裁剪、扩边、羽化、填充、**Align** 以及编辑器里的手柄，
都和图片节点一致。编辑器里的 **Resize output** 把成片缩放到
百万像素预算，并带一个分辨率步进（32 保留 LTX 和 Wan 的尺寸），和
核心的 Scale Image to Total Pixels 节点是同一套三件。帧单独缩放，
填充在之后加到它们周围，所以片段和它的色带之间
仍然是一条干净的线。

输出：`frames`（BHWC）、`mask`（BHW，每帧一张）、同一窗口的 `audio`
（源视频没有音轨时是静音）、`frame_count`、`fps`、`width`、`height`、`duration`、
一个 `stitcher`，以及 `original`：空间变换与缩放之前的
同样的源帧。已有输出插槽的位置保持不变。

## 局部重绘与拼接

`stitcher` 输出直接接进 **局部重绘拼接 🆎**：视频模型画完
扩边色带（或旋转角）之后，Stitch 把源帧逐位放回，
只在生成区域内采用生成结果，所以不再需要单独的
Crop For Inpaint 节点。编辑器的右侧栏放着这些设置：

- **混合**（`stitch_blend`）：生成的像素淡入源图的斜坡，单位是
  输出像素。它和扩边的**羽化**是两回事，后者决定遮罩
  输出——黑带扩图用羽化 0 加几十像素的混合效果
  很好。
- **显示混合** 用粘贴遮罩本身给舞台着色：生成区域（扩边、旋转角）、变换羽化，然后是经过任何缩放、按输出像素套用的扩展与混合——后端那套遮罩算法在预览分辨率下跑一遍。
- **高级 → 扩展粘贴**（`stitch_grow`）先移动粘贴边界：几个
  正的像素可以让生成结果重画源图边缘，如果接缝仍然可见。

拼接器是用最终缩放后的帧搭起来的，所以它和
采样器在这个节点的 `width` × `height` 下交回的东西对齐。
帧会分批变换，所以长片段不会让内存翻倍，队列的
进度条和取消操作全程有效。

这个节点不发起任何远程网络请求，也不改写源视频。


## 连接进来的时序输入

左侧、编辑器上方有五个可选插槽：

| 输入 | 含义 |
| --- | --- |
| `force_rate` | 在每隔 n 帧之前按这个 fps 采样。0 保留源帧率。丢帧或重复帧以保持播放速度。接受 FLOAT 或 INT。 |
| `start_frame` | 从 0 起的源起始帧。覆盖时间轴的 IN。 |
| `end_frame` | 不含在内的源结束帧。0 表示源视频末尾。覆盖时间轴的 OUT。 |
| `fixed_frames` | 从 IN 起精确的输出帧数；源视频必须够长。接上后它决定长度：OUT、长度和帧数都让位。 |
| `frame_load_cap` | 速率换算和每隔 n 帧之后、帧数之前的最大帧数。0 表示不限。接上后它代替长度决定长度。计数已知时，拖 IN 会在能装下保留帧的最后一个起点处停下。 |
| `last_seconds` | 只从片段末尾（或 OUT 之前部分的末尾）加载这么多秒。0 加载全部。用它接着一个片段往下做：长片段这时和短片段占的内存一样多。 |

帧边界用源视频的帧率格，与 `force_rate` 无关。
页脚把 **Source fps** 和 **Output fps** 分开标注。直接的
数值速率连线（包括经过 Reroute 的）可以在运行前就显示；
计算出来的速率标为运行时才确定。`force_rate` 是
每隔 n 帧之前的采样率：24 配每隔 n 帧 2 输出 12 fps。
把节点的 `fps` 输出接到 `CreateVideo.fps` 或 `Save Video.fps`，
这样下一个节点用的是实际速率，而不是改变播放速度。
例如起点 24、终点 72，从 24 fps 的源里选出两秒。
强制 12 fps 会返回 24 帧；上限 10 则只保留其中前
10 帧。音频和时长跟着返回的批次走。

接上的起点或终点会锁住那个手柄，以及节点和全屏编辑器上
对应的 IN/OUT 框。悬停可以看原因。断开后恢复
本地控制。时序输入接着的时候，预览把本地裁剪
当作参照显示，也不会在连线上的值于运行时求出之前
声称一个输出帧数。

**接上的长度输入会接管长度。** 把计数接到
`fixed_frames`（精确）或 `frame_load_cap`（至多），OUT 手柄就
消失，OUT 和长度变灰，只剩 IN 可设：片段从
IN 开始，由那个输入决定在哪里结束。字面的 Integer/Float 节点（包括
AusBoss 卡片和 Reroute）会在运行前把结果帧数显示在轨道上；
计算出来的计数显示 "at run time"。旧工作流若存了
Fixed frames 数字却没有连线，会按长度读；在这里做第一次
修改就把它变成一个长度。
