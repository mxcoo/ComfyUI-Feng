# 选择帧 🆎

从 `IMAGE` 批次里取出一张原样不动的图像。帧号从 1 开始，所以 `1` 是第一帧，最后一个合法值是批次大小。负数从末尾数：`-1` 是最后一帧，`-2` 是倒数第二帧 —— 批次长度会变时（视频常常如此）很好用。`0` 两个方向都非法。

## 控件

- **frames**：BHWC 图像批次，通常是视频加载器的帧输出。
- **Frame**（`frame_number`）：要返回的那一帧，从 1 开始；负数从末尾数（`-1` 是最后一帧）。超出范围的取值会带着可用范围停下报错，而不是悄悄夹取。

## 输出

- **image**：选中的帧，作为只含一张图的 BHWC 批次。

## 预览

面板显示被选中的那一帧，所以不必另接预览节点也能检查挑的帧。第一次运行之前，它显示喂给节点的图片或视频，还不是你选的帧。它随图运行而更新 —— 单独改 **Frame** 不会让它重绘，因为该帧的像素只存在于服务器上。

节点不发任何网络请求。它每次运行往 ComfyUI 的临时文件夹写一张预览 PNG，位置与 `PreviewImage` 相同，并随本次会话的临时文件一起被清掉。

画面上方那条栏右边的小 **preview** 开关可以关掉它：图片的框消失，节点就这么矮一截，也不写预览文件。再打开，节点恢复高度并带着最后一次结果；如果开关关着的时候节点跑过，它会让你重新运行工作流。该开关就是节点可选的 `preview` 输入。
