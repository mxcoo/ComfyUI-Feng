# 加载图像 + 扩边 🆎

在一个节点里加载图像，并在它周围搭出扩图画布。节点上画出的画布就是控制面：**拖动虚线最终矩形的任意一条边**，该侧的扩边就会增长——整条边都是手柄，角上抓取较近的那条边。第二个输出是一张正好覆盖扩边区域的遮罩，可直接交给局部重绘节点。

控件卡片上有 来源 与 上传、填充、颜色 或 背景、羽化、
倍数 以及 预算。**精确扩边**会为每一侧展开一条独立的拖拽行。
每一行都能接入连线；被连线的控件会变暗，它们的取值与连线随工作流一起保存。卡片下方
仍然保留画布，用于拖动边界。
被连线的侧由上游控制；拖动它们的边界不会改变已保存的扩边值。

## 节点上的画布

- 每条有扩边的侧都会在色带上显示 **"+N px"** 计数；色带太窄看不清时，标签会跳进
  图像内部变成一个小胶囊。被 **倍数** 裁掉的侧改为显示 **"−N px"**，并把被切掉的
  那条图像涂上阴影。
- 角上的徽标才是准数：经过画布倍数与百万像素换算后的**最终输出尺寸**，与
  `width`/`height` 输出所说的完全一致。
- 只要有扩边可清，右上角就出现 **重置扩边**；它会把每一条不由连线驱动的侧设回 0。
- 点击画布的空白处会穿透过去，所以节点照旧可以拖动。
- 隐藏的 `pad_left/top/right/bottom` 控件保存着真实取值——画布只是它们的遥控器，因此
  撤销、保存/加载以及 API 格式看到的都是普通的 INT 控件。

## 保证

- 原始像素**逐位一致**地落在原位（只有设定了百万像素目标时才会缩放——而且是*先*缩放
  再扩边，这样遮罩接缝始终保持一个像素宽、边缘干净）。
- 你未做扩边的那些边绝不会被加上色带；见 **倍数**。
- 遮罩在每个扩边像素上为 `1.0`、在源图上为 `0.0`，只在 **羽化** 指定的地方做渐变。

## 控件

- **来源**（`image`）：从 ComfyUI 的 input 文件夹选择或上传；列表会在指针对准时预览
  图像，并随输入过滤。ComfyUI 生成的图片也可以加载，名字形如 `photo.png [output]`，
  与核心的 Load Image 节点一致。
- **source_image**（可选插槽）：把另一个节点的图像接到这里，就会扩边这张图而不是
  文件；连线接上时 来源 行会变暗。画布只能在运行之后显示接线的图像，所以在此之前
  它画一个轮廓，之后显示它上次扩边的那张图及其真实尺寸。扩边作用于到达的每一张
  图像，因此每次运行只送一张图的加载器，会用同样的方式扩边整个文件夹。
- **填充** / **颜色** / **背景**（`mode` / `fill_color` /
  `backdrop_blur`）：五种填充——`color`、`edge`、`edge pixel`、
  `pillarbox blur`、`mirror`。**颜色** 在 `color` 时显示，**背景** 在
  `pillarbox blur` 时显示。`mirror` 会把画面在每条边上向外反射（包含边缘像素，
  并继续延伸到画面自身尺寸之外），于是扩边看起来像更多的场景：给编辑模型留出漂移
  余地的边距，拼接器接到 **与源图重新对齐（实验性 🧪） 🆎** 上。在 Qwen
  Image 2.1 的重新风格化里，镜面边距引诱模型放大并填满画布的情况，比边缘像素
  或纯灰扩边少得多。
- **羽化**（`feather`）：把遮罩沿图像边缘向*内*渐变，作用于每条有扩边的侧
  （渐变宽度以图像尺寸为上限），这样采样器会融合接缝。`0` 保持接缝硬边。扩边本身
  始终是实心的。
- **倍数**（`canvas_multiple`，起始值 `8`；`1` 表示保留每一个像素）：
  最终画布向上取整到这个倍数。多出来的像素并入你做过扩边的一侧（两侧都扩边时并到
  右侧或底部那一侧）。如果左右两侧都没扩边，或者上下两侧都没扩边，那里就什么也
  不加：沿一条你没碰过的边加色带，等于多出一条边让模型去画，而细细一条往往画得
  平、跑偏色。设了 **预算** 时改为缩放源图来适配，保持它的形状（完全不扩边时，
  每一条边各自吸附）；没设预算时它就丢掉这几个像素，从两侧各丢一半，其余部分
  保持逐位一致。
- **预算**（`target_megapixels`）：`0` = 关闭。重新缩放**源图**，使扩边后的画布
  正好落在这个百万像素数上，然后再按倍数取整——这是给小图或超大图做扩图、又想要
  采样器友好尺寸的办法。

## 输出

- **image**：扩边后的画布。
- **mask**：扩图遮罩（白色 = 扩边，按 `feather` 羽化）。
- **width / height**：最终画布尺寸——徽标上的数字，以 INT 输出，
  可直接接到 Latent 节点。
- **stitcher**：连同采样结果一起交给 **局部重绘拼接 🆎**，只保留新扩出来的边并
  逐位一致地还原原始像素——采样器在源图区域里做了什么都会被丢弃。它还会记录源图
  在画布上的位置，**Krea 2 扩图模型补丁 🆎** 读取它来放置参考图，
  **与源图重新对齐（实验性 🧪） 🆎** 读取它来只取回在扩边画布上所做编辑中属于
  画面的那块区域。
- **reference**：只有源图、没有扩边，缩放到 16 的小倍数——供
  **Krea 2 编码 🆎** 及其他参考条件使用。它每次运行都会生成；没有地方用就留空不接。
